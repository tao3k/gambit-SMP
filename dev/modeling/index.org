[[file:verification-responsibilities.org][Exclusive verification responsibility]] is the current admission policy:
declare each semantic obligation once in SysML, assign one verification owner,
and check the partition through ASCENT. Quint owns schedules and permit
lifetimes; Lean owns algebra/data properties. The LLM is the working environment,
not an extra service. Existing historical studies require explicit role review;
paired QNT/Lean links alone do not establish compliance.

[[file:../architecture/runtime/control/control-refinement.org][The control refinement study]] applies the partition to actual source writers,
generated/native consumers and target-scoped execution cases. Its ASCENT DSL
distinguishes source mapping from proof and source/profile/case-bound native
acceptance; the unchanged QNT/Lean endpoints are reused by hash.

Start with [[file:component-model-design.org][SysML component/QNT/Lean/ASCENT correspondence]] and [[file:component-model-map.org][its derived mapping]]. Each component has explicit model purpose, source/symbol references, state/event projection and unresolved premises. Runtime bindings remain at their original owner; build components share one new formal set.

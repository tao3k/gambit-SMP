** Row contract and review questions

#+NAME: rev-matrix-fields
| Field | Meaning / refusal condition |
|-------+-----------------------------|
| id | Stable, unique row identity |
| kind | measurement, control, accounted-cost, structural or unmeasured |
| metric / unit / direction | Explicit quantity and preferred direction; unit mismatch refuses |
| baseline / candidate | JSON pointers to typed evidence records; literal report numbers refuse |
| workload | Actual input, manifest and resource scope; reviewers must assess comparability |
| method | Sampling, source-accounting or structural-count method |
| evidence | Nonempty durable repository paths, bound by SHA256 |
| limitation | Sample/causal boundary, exclusions and remaining unknowns |

Each quantity contains value, unit, samples and an origin path/pointer. The curated
document must bind baseRevision, sourceTree and profileSha256. Its raw origin must
bind the same context and agree with the recorded value; copying an unrelated
number into a current-looking report does not qualify it. Absolute, escaping,
missing or cache-only evidence is refused. Evidence is re-read before admission
and commit; drift invalidates the reviewed packet. Each row records its own
evidence digests, in addition to the audit-wide artifact binding.

** Separate observations from benefits

#+NAME: rev-matrix-kinds
| Kind | Samples | Permitted interpretation | Forbidden inference |
|------+---------+--------------------------+---------------------|
| measurement | Actual positive count | Signed observed change for this workload | Automatic causal/statistical speedup theorem |
| control | Actual positive count | Context/control observation | Treating control time as callback improvement |
| accounted-cost | Zero; not benchmark samples | Source-derived space/operation cost | Calling layout bytes measured RSS |
| structural | Zero; not benchmark samples | Retired alias, authority or unsafe crossing count | Turning a structural count into throughput |
| unmeasured | No baseline/candidate values | Explicit open measurement | Invented zero, ratio or gain |

Delta is candidate minus baseline. Percent is delta / baseline * 100 and the ratio
is candidate / baseline. A zero baseline has no defined percentage or ratio.
Regressions retain their sign. A single sample remains one observation. The
validator always sets generalized_performance_claim=false; source/profile binding
does not itself prove identical scheduling, causal isolation or sufficient samples.
LLM review must answer whether the claimed mechanism fits these limits. It cannot
supply missing measurements or turn a favorable row into a general theorem.

** Submission and rejection boundary

The matrix travels with the original responsibility, retired, validation, benefits,
costs, process, checklist, models and open fields. The audit digest binds that
packet; Matrix-SHA256 in the generated commit body identifies its normalized rows.
Missing/stale packets, missing row fields or evidence and invalid values prevent
ASCENT admission. These are audit obligations, not another GC state machine or
mathematical semantic law: existing QNT and Lean duties are unchanged.

Published commits retain their original audit contract. A later matrix is labeled
as a supplement, with subject revision and original audit digest; it never rewrites
the published commit or retrospectively asserts a new gate passed before it existed.

** Semantic module package
Every module has an Org entry, owned requirements, a D2 view, SysML structural model and explicit behavioral/proof indexes where applicable. A missing Quint transition or Lean theorem is an OPEN obligation, not a reason to invent a trivial model that resembles coverage.

Existing formal sources have a single maintained location under repository ~models/~. Local indexes refer to exact symbols and current hashes. Shared libraries are actual imported semantics; indexes do not automatically make a model a dependency of another.

** Relation fields
#+NAME: required-relation-fields
| Field | Required content |
|---+---|
| ID / semantic owner | Stable requirement and interface identity; who can change meaning |
| producer / consumer | Who establishes and relies on each guarantee |
| artifacts / symbols / source identity | Exact files, definitions and SHA256 bindings |
| source / target domains | Identities, epochs, sets, values and units; bounded domains explicit |
| state projection | Meaning of every mapped field; omitted state and aliasing |
| event projection | Guard, before/after state, stuttering and atomicity boundary |
| assumptions | Source coverage, quiescence, memory ordering, ownership and fairness |
| guarantee | Exact conclusion and where it can be consumed |
| mismatch / counterexample | Failure trace and reason a tempting shortcut is invalid |
| status / receipt | Proposed relation, source correspondence, explored model, checked proof or native acceptance |

** Composition rule
For every allowed producer transition, either its projection stutters in the consumer or it matches a permitted consumer step. Initial states must map; identities and epochs must agree; shared actions must synchronize; a hidden action must preserve the neighbor's rely condition. Prove guarantees from noncircular assumptions. Fairness and termination must survive hiding separately from safety.

An assume/guarantee graph with a cycle is not a proof: discharge the cycle using an established base invariant, a joint transition proof or a well-founded phase/ownership argument. Otherwise the dependent guarantees stay unresolved.

** Change and invalidation
Changing a field's meaning, writer set, source hash, epoch scope, action guard, theorem premise or observation boundary invalidates dependent relations and receipts. A D2 label/layout change invalidates its rendered view, not a runtime proof. A SysML diagnostic pass does not refresh Quint exploration or Lean proof receipts. An upstream manual update requires a fact/interpretation review, not silent adoption.

** Native tool ownership before custom adapters
:PROPERTIES:
:CUSTOM_ID: native-sysml-tool-boundary
:STATUS: native-views-checked-fl-ascent-adapter-open
:END:

Use the installed ~sysml~ executable for loading/resolution, strict diagnostics,
structural constraints, model queries, views and supported table/matrix exports.
Do not implement a second model loader, graph interpreter, rule evaluator or D2
renderer in Python. The T0TargetGraph uses actual reference parts and typed
connections in the owning SysML, so the tool can render its structure directly.
Connections represent architectural dependencies; they do not prove a runtime
handoff protocol, scheduling order, progress or safety.

#+NAME: native-t0-frame-view-commands
#+BEGIN_SRC sh :eval never
sysml -strict -validate -json dev
sysml -strict -render '#interconnection:GambitRuntimeComposition::T0TargetGraph' -render-form d2 -o dev/refactoring/modern-c/diagrams/t0-foundation.d2 dev
sysml -strict -render '#tree:GambitFrameContract::FrameAdmission' -render-form d2 -o dev/architecture/runtime/interfaces/diagrams/frame-contract.d2 dev
sysml -strict -render '#table:GambitRuntimeComposition' -render-form csv dev
#+END_SRC

The default native table is a structural inventory, not the seven-lane benefit
matrix and not a result of evaluating the target requirements. Use a declared
native query/view for tailored columns when its contract is qualified; never
silently reinterpret the default inventory as evaluated metadata values.
The installed help advertises D2/CSV/TSV and document output, but does not advertise
Org or ASCENT output. Any needed format bridge must only transport qualified
native results and bind identities; semantic decisions and architectural rules
stay in SysML, QNT/Lean and the existing evidence DSL.

Keep authored Org arguments, formulas and disproof conditions distinct from
native structural views. QNT explores the owning transition system; Lean proves
its explicitly stated laws; ASCENT relates source, models and evidence. Passing
SysML structural validation supplies none of those behavioral/refinement results.
The fine-grained FL association adapter remains OPEN. An experimental projection
was withdrawn rather than retained as a second maintained model processor.

The older documentation adapter below remains for its existing 72 outputs;
this task restores its entry bytes and adds no maintained Python extension.
Its eventual replacement requires native equivalents for its current consumers
and explicit Org/ASCENT transport and source-identity checks. Existing receipts
are historical evidence, not permission to delete unrelated tooling wholesale.

** Existing adapter migration boundary and fail-closed derivation
[[file:../organization.sysml][The organization model]] owns semantic areas and artifact associations.
[[file:../architecture/runtime/interfaces/models/sysml/model-relations.sysml][Runtime-owned relation metadata]] owns contract participants, dependencies, selected symbols and obligation dispositions. Org owns detailed arguments and evidence interpretation. Existing QNT/Lean source is neither copied nor synthesized from status metadata.

[[file:tools/sync-views.py][The documentation-only view tool]] reads OpenSysML's structural API JSON export, resolves literal metadata and typed Dependency endpoints, and derives Org indexes, D2 and source-hash receipts. It does not regex-parse a second pseudo-SysML language, run model behaviors, invoke a prover or modify runtime/formal source. Default mode checks for drift; writing is explicit.

#+NAME: derived-model-view-maintenance
#+BEGIN_SRC sh :eval never
python3 dev/modeling/tools/sync-views.py --write
python3 dev/modeling/tools/sync-views.py --check
#+END_SRC

The installed exporter labels its RDF/API mapping experimental and subject to change. The view tool accepts only the structural fields it understands, rejects missing/duplicate owners, references, symbols, unsupported metadata or dependency cycles, and retains the raw export/diagnostics. Export schema/tool changes require requalification; there is no silent fallback to hand-maintained indexes. A clean drift check closes document derivation only, not semantic refinement or native wait freedom.

** Target refactoring is distinct from existing model evidence
Root location models/ denotes unique formal ownership, not automatic proof of current behavior or the future architecture. DEV owns target refactoring structure and precise QNT/Lean refinement obligations. Reuse existing bindings with their exact evidence scope; do not duplicate a current GC model or promote a conditional slice to the new GC/SMP design. See [[file:../refactoring/modern-c/t0-foundation-design.org][T0 foundation]] and [[file:../architecture/runtime/interfaces/frame-contract-design.org][FrameSpec interface]].

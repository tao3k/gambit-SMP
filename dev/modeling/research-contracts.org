** CONTRACT Managed service and immutable provider
:PROPERTIES:

[[file:models/sysml/research-service.sysml][Service architecture]] assigns ownership and retirement obligations.
The seal covers SDK connected-model runtime files, =uv.lock=, the official
service digest and executable role, the existing framework closure, and the
ASCENT admission policy. The connected profile includes =opensysml=, =grpcio=,
=protobuf= and grpcio's =typing-extensions= dependency. Isolated workers run
with =-I -S -B=; an undeclared dependency fails rather than importing host
site-packages. Downloads, signing and arbitrary action execution are outside
this profile. A service update requires a new seal and equivalence run.

The existing capability module owns two task-registered children, service and
RPC client. A fresh request binds nonce, model bytes, part, provider and original
monotonic deadline. A five-second cleanup reserve and two-second parent reserve
consume the original stage; they never renew it. The state path is
=planned → starting → listening → client-complete → stopping → closed/retained=.
The service startup address is protocol framing, not parsed model output.
The client always uses =auto_start=False= and a release/capability handshake.

Publication requires both exact birth-bound child identities, actual waits,
controlled unforced service stop, unchanged binary, matching request/provider
and full-field oracle equality where declared. ASCENT rejects any contradictory
row for the same identity; a missing row has no qualifying answer. Failure,
interruption or unknown wait leaves durable task custody and no admitted result.
This does not prove OS-wide process reclamation under arbitrary asynchronous
failure, cancellation or machine loss. The reviewed stop profile is Darwin arm64;
other platforms require their own admission evidence. Loopback client selection
does not assert that the service listener is network-sandboxed.

The =ServiceAdmissionLaw= is a necessary architectural condition, not a
synthetic satisfaction claim. Its concrete ASCENT projection is explicit:

| SysML observation | Actual producer / DSL expression |
|-------------------+----------------------------------|
| providerMatches / requestMatches | Sealed provider hash / fresh nonce equality |
| closed | Lifecycle phase equals closed after actual waits |
| clientSucceeded / serviceSucceeded | Client exit 0; service exit 0 or controlled SIGTERM in the reviewed platform profile |
| serviceReaped / clientReaped | Actual managed wait or bounded client transport completion |
| controlledStop / forcedStop | Stop path observation; kill fallback cannot qualify |
| binaryStable | Service bytes checked before launch and after stop |
| childrenBound | Distinct managed spawn tokens and recorded child birth identities |
| contradictoryRow | Any sdk_bad_row for the same id prevents sdk_qualified |
| admitted | Caller requires exactly its one qualified id and no denied id; absence cannot pass |

Org references repository source, models and retained observations. Local build
directories are execution state. Their addresses, inodes and availability cannot
serve as reproducible documentary inputs. Internal build tools may maintain
temporary state; a maintained replay entry point must recreate its own inputs
or declare the missing prerequisite.

The [[file:tools/sync-views.py][existing view synchronizer]] rejects local execution-directory references in
both maintained Org and generated Org before writing views. This check prevents
that reference class; it does not certify every other external dependency or
claim that a clean native bootstrap has been reproduced.

* Reproduce archived-byte verification :evidence:
:PROPERTIES:
:EXECUTION: read-only-record-verification
:NATIVE_EXECUTED: false
:END:

Run from the SMP repository root with Ruby supplied by the environment:

#+NAME: verify-copy-authority-records
#+begin_src sh
ruby dev/modeling/tools/check-root-worker-exit.rb --verify-records \
  evidence/research/worker-role-handoff/copy-header-load-closure/receipt.json
#+end_src

The verifier reads the inventory and its compressed records. It never opens an
original observation path, executes archived code or follows a build route.
It rejects missing records, archive paths outside the packet and byte hashes
that do not match. Verification can therefore run with no original local
workspace present. Its output explicitly grants no runtime or commit admission.

* Source relocation and execution remain different obligations

A byte-preserving source relocation changes its documentary location, not its
meaning. Source needles and line coordinates remain tied to the retained bytes;
the SysML source reference changes with the Org view. Old receipts keep their
original identities. They are not reissued as fresh source/model executions.

Native re-execution still needs the exact source lock, original build profile,
admitted toolchain/SDK, generator provenance and execution budgets. A compressed
receipt is not a completed bootstrap artifact. Missing cold-build prerequisites,
unsupported platform combinations and unclosed GC/FFI obligations remain open.
No runtime implementation or additional QNT/Lean model is introduced by this
documentary custody correction.

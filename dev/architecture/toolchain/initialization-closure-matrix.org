** Freeze gates

| Gate | Qualified | Requirement |
|---+---+---|
| sourceCut | false | Complete executable and reachable-state closure, including displaced phases, readers and captures |
| capabilities | false | Every eval/reader/native/FFI callback is mediated or explicitly refused |
| stableInputs | false | Positive and negative resolution facts, bytes, readtable, hooks and environment remain stable |
| identity | false | Canonical bindings, context aliases, marks and original module-instance scope are preserved |
| initialized | false | All required initialization has completed successfully; partial or unknown setup is not success |
| writes | false | Frozen cut has no reachable unowned writers; mutable provider state stays behind an owner |
| lifetime | false | Generation-bound publication and borrower pins prevent revoke/reclaim races |
| nativePolicy | false | Native addresses, constructors, globals and callbacks are admitted per process/VM domain |

** Work and cost boundaries

| Family | Potential removed work | Mechanism | Added work / boundary |
|---+---+---+---|
| foundation | Repeated isolated decoding/validation | Frozen recipe/image plus owned overlays | Closure audit, publication and pin bookkeeping; existing batch reuse is baseline |
| reader | Repeated read/parse only for equivalent admitted observations | Cache read result with input and reader identities | Mediated I/O, readtable/args/locations and failure evidence; opaque readers remain executable |
| native | Repeated lookup/phase load within an admitted domain | Keep code availability and instance readiness distinct | OS/module setup and process globals cannot be copied as immutable bytes |
| stateful | False serialization outside provider access | Parallel independent consumer work around one effect owner | Owner queue, continuation/dynamic-parameter handoff, reentry and dependency-order proof |
| reclamation | Redundant generation reconstruction | Reuse current qualified cut until inputs change | Revocation closes new pins, drains old borrowers; unknown effects retain custody |

Observed source closure: false.
Net work requires actual avoided baseline repetitions to exceed validation, maps, overlays, owner handoff and pin/drain; necessary stateful initialization is retained. Parallel span is a separate quantity.

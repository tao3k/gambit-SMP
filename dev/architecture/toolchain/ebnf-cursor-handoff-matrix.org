** Net work

| Family | Potential removed work | Mechanism | Added cost / limit |
|---+---+---+---|
| resetConstructors | Baseline T=sections+actions character-stream and token-stream constructor calls | Keep one coherent cursor domain only after mode-specific equivalence | Cannot credit removal before token/location/error consumers and continuation aliases are migrated |
| tokenReplay | Avoid repeated token construction only where source consumer no longer needs it | Preserve canonical tokens or stable raw spans without re-lexing | Span storage, token identity and trivia/handler history; some work is mandatory |
| parallelConsumers | Remove false serialization for independent input domains | Owner-scoped cursors and qualified immutable reader definitions | Pins, epochs, owner handoff and unknown-result settlement; shared physical input remains serialized |
| acceptedBehavior | Quote loss has a source-derived accepted-reader witness | Choose an explicit behavior-repair decision before corrected buffered reading | Correctness repair is not an automatic speedup or equivalence claim |

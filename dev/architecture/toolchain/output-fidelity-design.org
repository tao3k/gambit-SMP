* RESEARCH A precise proposed encoding and its admitted domain
:PROPERTIES:
:CUSTOM_ID: gsc-datum-codec-domain
:END:

There are two separate encodings: file bytes to rawC, and the actual parsed
Scheme datum to linkDatum. [[file:../../../vendor/gambit/gsc/_host.scm::760][Port creation]] selects a standard preserving-case
readtable with keywords enabled. [[file:../../../vendor/gambit/gsc/_host.scm::787][The writer helper]] disables quote-style read
macros in its string-output port. [[file:../../../vendor/gambit/lib/_io.scm::1086][Input port settings]] select the configured
readtable. Actual port encoding, newline conversion and reader state still
belong to the qualified context; text character count is not file byte count.

For rawC, read the complete immutable file as bytes b in Fin 256, retaining
order and length. Widen each byte exactly into the mathematical QNT integer
sequence. byteEncodingInjective proves this widening injective. It does not
prove that a native acquisition adapter returns the right file, that a hash is
collision-free, or that a target machine integer can represent every datum.

The lexical sketch below motivates type separation. The current recursive
wire syntax and checked inverse use the uniform body-length frames in
[[file:recursive-codec-design.org][the recursive codec study]]; this sketch is not a second normative wire format:

#+NAME: gsc-datum-token-grammar
#+BEGIN_EXAMPLE
nil             := [0]
boolean b       := [1, b]                       b = 0 or 1
integer z       := [2, z]                       mathematical signed integer
character c     := [3, code(c)]                 admitted Gambit character domain
string s        := [4, n, code(s[0]), ..., code(s[n-1])]
interned symbol := [5, n, exact-name-units...]
keyword         := [6, n, exact-name-units...]
pair a d        := [7] ++ encode(a) ++ encode(d)
vector xs       := [8, n] ++ encode(xs[0]) ++ ... ++ encode(xs[n-1])
#+END_EXAMPLE

Tags, length units and scalar domains are schema-bound. Code points must map
injectively to the admitted Gambit character values; do not silently substitute
UTF-8 byte length for character count. Interned symbols/keywords need their
identity discipline under the same producer context. Uninterned symbols,
cycles, shared graph identity, floating-point forms, opaque objects and unknown
metadata values are unqualified until their actual consumer semantics and
encoding are specified. No claim is made that real GSC can emit only this
subset. Unsupported values refuse this typed profile; a separately proved
whole-file observation profile may be more conservative.

A decoder must consume exactly one full value, reject malformed tags, invalid
lengths, incomplete payloads, invalid scalar ranges and trailing tokens, and
satisfy decode(encode(d)) = Some(d) on the admitted domain. Structural induction
must cover pair and vector framing and termination. Two additional bridges
remain: actual parser output belongs to that domain, and its encoding equals
the QNT observation. This is a codec design, not a new parser implementation.
framedAtomInjective and atomTagsSeparate prove only the framed atom layer;
admittedCodecInjective derives injectivity if the domain round-trip law is
supplied. The recursive codec and actual parser law remain open.

[[file:../../../vendor/gambit/gsc/_t-c-1.scm::1419][targ-write-escaped]] emits protective Scheme block comments around marker names.
Those comments are not extra datum values. Record positions 0--11 represent
compiler, target, module name, supplies, demands, modules/flags, symbols,
keywords, three global-resource classes and meta-info. Preserve dotted pairs,
symbol versus string identity, duplicates and order. Do not assume the original
in-memory meta-info equals its read-back value; prove serialization adequacy
on an admitted domain, or compare the actual parsed outputs directly.

** Order and consumer factorization
[[file:../../../vendor/gambit/gsc/_t-c-1.scm::906][targ-link]] maps inputs in order; resource set construction preserves an
encounter order, and combine-meta-info uses assq and ordered accumulation.
The last effective script-line and ordered linker/pkg-config options matter.
[[file:../../../vendor/gambit/gsc/_t-c-1.scm::1086][targ-get-mod]] appends caller flags before each module's stored flags.
Equality of sorted sets or module names therefore cannot substitute for the
complete ordered input observation.

Consumer context also includes extension mode, target/compiler, ordered base
and sibling observations, resolved file names, logical output/root/linker name,
flags, warnings policy and governed state/effects. A proof that a return value
factors through a datum does not establish equivalence of warnings or side
effects. Define Result to contain every admitted observable result, or prove a
separate permitted diagnostic/effect projection. The current Lean cutoff
lemma supplies no concrete factorization for targ-link.

#+NAME: gsc-clean-origin-obligation
#+BEGIN_EXAMPLE
I = sealed source + generated-input closure + resolver negative answers
K = code/tool/profile + reader/port/ABI + semantic and consumer context
P(I,K) = independently specified successful producer relation
OldOrigin(g) : a qualified previous P(I_old,K_old) completion and group lease
Clean(I,K)   : P(I,K), independent of reusable-token equality
ActualObs(g) = exact actual consumer read and complete governed result
Fidelity(g,a): actual read/domain and encoding witnesses give model observation a
#+END_EXAMPLE

A future clean control uses fresh physical output storage and isolated compiler
state under the same I and K, without inherited generated products. Preserve
the logical output name: file comments, source locations and link root/name
can affect output. Moving a physical directory is not permission to strip
paths or normalize generated C. Qualification must prove any logical/physical
mapping and all native consumer path effects. Both comparison attempts need
stable complete dynamic inputs, not just equal source files.

A reference need not be physically rerun for every hit if a qualified old origin,
closed deterministic producer relation and validated adaptive replay theorem
already entail its result. That entailment must be independent of the proposed
cache equality. Two cache entries agreeing with one another, or the same parser
being called twice, is not an independent clean oracle. Nondeterministic or
uncontrolled effects require an explicit admissible result relation or refusal.

[[file:../../../vendor/gambit/gsc/_front.scm::436][compile-program]] invokes target.dump, then optionally dump-c-intf. Required
.gvm/.cfg/.dg/FFI or other enabled products belong in the mode's manifest;
normal primary-file close alone cannot establish a successful group. This
study runs neither the clean control nor the incremental candidate.

* RESEARCH Failure mapping and custody
:PROPERTIES:
:CUSTOM_ID: gsc-failure-to-qnt-mapping
:END:

#+NAME: gsc-outcome-mapping
| Outcome | Actual source boundary / required witness | Reuse rule |
|---+---+---|
| Success | Qualified complete producer and consumer validation; settled lease | Still requires full fidelity, clean origin and current context |
| Missing | Resolver exhausted candidates; open failed/false after permitted fallbacks | No successful empty datum; retain negative answers |
| Rejected | Marker/version/target mismatch or mixed backend rejection | Preserve fallback/diagnostic behavior; no success credential |
| Malformed | Reader syntax/shape/domain error or later vector/field access failure | Shallow header acceptance cannot override it |
| IoFailure | Open/read/write/close/provider error with actual result | Retain partial group and borrowed-handle custody until settled |
| ProducerFailure | Compiler abort #f or qualified nonzero/signal delivery | Preserve prior successful files as history, not current products |
| Cancelled | External cancellation accepted but completion/cleanup must settle | No credential from partial output or unknown exit |
| Unknown | Missing delivery, ownership or process outcome evidence | Refuse; do not guess success from file existence |

These are semantic outcome classes, not numeric errno values. A failed trial
inside target/extension search is not necessarily overall failure. Record each
negative answer and the actual final resolution. [[file:../../../vendor/gambit/gsc/_utils.scm::426][with-exception-handling]] uses a
compiler continuation; [[file:../../../vendor/gambit/gsc/_utils.scm::506][compiler-abort]] transfers #f. Reader/native exceptions and
OS process delivery are additional paths, not proven equivalent to that #f.
The shown normal-return closes/target-end calls are not an exception-unwind
cleanup guarantee. Do not replace the original exception semantics during
credential extraction. Cancel/process mapping is a proposed outer service
obligation, not demonstrated cancellation support in this source slice.

The fifth QNT module gives these eight outcome tags and explicit linkEligible,
linkCutoff, cCutoff, failureBlocks and malformedBlocks predicates. It is a
specification, not an execution machine or a concrete adapter. cCutoff here is
a conservative observation for this admitted linker chain, not the universal
minimum precondition for compiling arbitrary C. Existing four modules remain
unchanged. No state exploration is claimed.

The issuer requires Success, shallowHeader, fullRecord, codecFaithful,

all modes and the other named consumer inputs. Equality of an incomplete
context token cannot satisfy this obligation; that concrete encoding is open.

#+NAME: gsc-fidelity-benefit-matrix
| Mechanism / change | Conditional avoided work | Necessary extra work / counterexample |
|---+---+---|
| Qualified generation replay | One selected _host generation attempt on a valid hit | Complete macro/reader/native context and successful origin; unknown effect defeats hit |

| Typed ordered linker observation | At most this selected library composition when all its base/sibling/context observations agree | Parse/domain/codec/context validation; malformed header-only or changed preload order defeats cutoff |
| Changed C body, same link observation | May spare selected metadata-driven composition | Changed _host object/native link still requires its own work; no whole-build cutoff |
| Failure-aware issuer | Prevents invalid reuse and stale output publication | Settling partial groups and unknown delivery can require more work, not less |
| Shared modern C owner | Can eventually replace duplicate acceptance/existence/dirty decisions | Zero old paths retire until all callers and failure edges migrate; existing Scheme reader/emitter retained |
| Optional Zig | No additional saving established by this encoding design | Same parser, origin, effect, cleanup and reflection duties; a second maintained owner increases obligations |

The source slice remains 34 generation + 34 native compilation + six composition
= 74 actions; the selected protocol has ten actions and 64 omitted actions.
These are inventory counts, not timings. A no-change eligible cohort aims for
zero producer recipes but still pays validation. A shared macro change exposes
34 generation candidates; equal output can be known only after valid origin
revalidation or actual regeneration, whose work cannot be erased.

Use one cost unit or an explicit resource vector when evaluating:
avoided recipes/consumer work must exceed acquisition + dependency/context
validation + parsing/encoding/comparison + effect/custody support + retries.
No hypothetical speedup, person-day estimate or measured positive net benefit
is claimed. Typed comparison should be chosen only where it saves more than a
qualified exact-byte observation after accounting for these extra obligations.

[[https://simon.peytonjones.org/assets/pdfs/build-systems-jfp.pdf][Build Systems a la Carte]] defines correctness via unchanged inputs and
consistency with recomputation; its deterministic model does not supply this
GSC producer relation. [[https://www.mathematik.uni-marburg.de/~seba/publications/pluto-incremental-build.pdf][Pluto]] allows consumer-specific stamps and explicitly
assumes builders register dependencies; its consistency argument does not
prove this reader/codec or snapshot issuer. Its stamp-cost tradeoff motivates
keeping validation cost in this matrix. These are mechanisms to learn from,
not transferable Gambit qualification results.

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| retirement | Old route reclamation need not wait for unrelated threads to mask under the qualified atomic gate | Permanent shell plus tagged gate and active pins | A selected pre-CAS handler may be denied after route retirement; every legacy bypass must first migrate |
| latency | Owner can continue old-roster GC while coordinator awaits handler/work closure | Nonblocking retirement state machine, native reason mailbox and finite-wait fallback | Progress requires handler termination, scheduler/OS fairness and prior wake protocol; no measured speedup |
| ownership | Avoid fd/route ABA and silent late-signal reassignment | Generation overflow policy, reason custody and typed failures | O(R+H+T) route/active-handler/thread-policy metadata; process shell cannot be reclaimed by individual VM |
| language | Modern C preserves Scheme semantics and C portability with generated typed adapters | C atomics, stable shell, semantic reason dispatch and source proof | Zig cannot remove signal ABI, root lifetime, grace or semantic ownership proofs; no mandatory incremental benefit established |

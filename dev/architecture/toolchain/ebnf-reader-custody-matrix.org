** Work and added cost

| Family | Avoided work boundary | Mechanism | Added cost / limit |
|---+---+---+---|
| grammar | Only additional cross-session reinitialization/decode can be removed; current module reuse is baseline | Immutable qualified grammar definitions with original singleton identity | Alias audit and publication; derivative result allocation is still required unless separately optimized |
| streams | False serialization between independent ports can be removed | Resource domains with per-invocation buffers and callbacks | For normal section/action paths T = sections + embedded actions: T char-stream and T token-stream constructor calls remain baseline; also pins, owner stack and callback tracking |
| readerResults | Repeated reads/parses only if exact consumer observation is equivalent | Qualified result/effect snapshot with input/readtable/identity evidence | Locations, exceptions, callbacks and cursor state can invalidate reuse; data-only AST equality is insufficient |
| continuations | Avoid holding physical locks while control leaves a reader | Retain logical resource lease and roots across suspension; reenter with original dynamic bindings | Lifetime retention, closed-port observations and multi-shot semantics; no replay/rollback saving credited |

Actual reader admission: false. Existing module/grammar reuse is baseline. Net work must subtract ownership, identity, root retention and capability validation; independent-port parallel span is separate from work reduction.

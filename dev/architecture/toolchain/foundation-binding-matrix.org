** Actual baseline and conditional net work

| Work family | Current baseline | Removed work boundary | Added cost or counterexample |
|---+---+---+---|
| quotePrograms | Generator already lifts and memoizes quotes/marks within compilation; batch registry can reuse loaded modules | Only repeated program decode/load across separately admitted requests can count as removed work | Origin-map validation, initialized constants and binding reconstruction; R can be zero in current batch |
| phaseQueries | Current lazy phase links are cached on live contexts | Qualified finite phase images can prevent duplicate per-worker materialization relative to isolated workers | Phase-cut validation, image publication and fallback overlays; no new saving credited when the current batch already shares the cache |
| useMarks | Source allocates a fresh mark per user macro application | No elimination of required fresh mark identities; optimize representation only under the same observable identity contract | N admitted applications still need N fresh use identities; collapsing them changes cancellation/binding behavior |
| moduleInit | Current module registry/delayed evaluation can initialize one instance for several consumers | Keep the same module-instance effect scope; parallelize independent domains around it | Stateful initialization cannot be erased or reset per consumer; serialized owner adds queue/drain bookkeeping |
| definitionLookup | Current contexts and sticky optimizer state already share work | Retain that reuse in an immutable image plus owned overlays while removing false serialization | Reference completeness, deep freeze, canonical object lifetime and overlay costs; positive work requires independently established R greater than added costs |

** Net work rule

Current registry/sticky caches are the baseline. Count only avoided repeated plan/decode/validation work; subtract reconstruction maps, canonical identity bookkeeping, overlays, fresh initialization, effect-owner scheduling and pin/reclamation. Stateful module initialization is not removable work.

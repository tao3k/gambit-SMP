The Make rules already permit some within-phase parallelism. The target improvement is precise readiness and one weighted host budget across nested orchestration, not claiming current Make is purely serial. Parent jobs must either retain a justified execution resource or yield credits before awaiting children; cancellation is only a request until child effects settle.

** State, transitions and necessary invariant
Running phase and used credits -> host-owned budget; nested children require a disjoint token partition.

ready/start/finish/cancel/discard; cancellation request does not establish physical completion.

Required: Used equals running weight, is bounded, and each terminal release is counted once.

Abstraction boundary: Unit-weight ten-node slice does not prove weighted host population, parent-await-child progress, OS cancellation or fairness.

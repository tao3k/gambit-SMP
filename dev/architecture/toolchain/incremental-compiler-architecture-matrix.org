** Gate

| key | qualified | condition |
|---+---+---|
| observational-semantics | False | Clean-build equivalence includes binding identity, expansion, diagnostics, exceptions and relevant effects; arbitrary syntax/macro heap serialization is not admitted |
| tracked-inputs | False | All dynamic reads, negative lookups, compiler/tool descriptions and source epochs tracked; opaque native/time/random/network effects deny reusable credentials |
| session-isolation | False | Deep expander/optimizer/loader/phase instance state owned or proven immutable; lock deletion follows caller migration |
| projection-cutoff | False | Each consumer names exactly the interface/support/IR/native observations it consumes; unchanged signature cannot hide changed transformer code |
| scheduler-publication | False | Single-flight keys, suspension/resource release, cycle diagnostics, unknown/cancel custody and atomic result groups refine to actual code |
| backend-cohort | False | Modern-C runtime/GC/SMP and generation/compile/link cohorts qualified independently; binary GC maps do not prove dead registers or build acceleration |
| production-refinement | False | Eight-node model refines actual module/phase/action population; observed avoided work, critical path and added overhead must establish benefit |

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| no-change | Re-execution of unchanged demanded compiler/native stages | Trace validation, file/absence validation and result materialization | Zero recomputation only for admitted unchanged queries, not zero filesystem or validation work |
| leaf-edit | Unrelated module expansion/native generation and unnecessary whole-module barriers | Invalidate affected trace closure; compare consumer-visible outputs | Unchanged wg may already be skipped today; no new gain credited for that alone. New opportunity is finer phase cutoff and less import/support reconstruction, pending actual baseline evidence |
| macro-edit | Downstream work after genuinely unchanged consumed projections | Recompute changed macro support; invalidate both consumers when transformer semantics change | An unchanged interface alone is insufficient; no false early cutoff |
| parallel-span | Waiting for unrelated runtime object completion before independent consumer expansion | Owned sessions/processes, memory budgets, IPC and broker contention | T >= max(W/P,S); reducing span S differs from reducing total work W; no claimed 12-core speedup |
| shared-support | Duplicated immutable phase-program preparation across otherwise isolated sessions | Program serialization/validation and fresh per-session instance/identity work remain | Positive work saving only if avoided work R exceeds H_validation + H_instantiation + H_transfer; current sticky reuse is baseline |
| native-cost | Repeated generated-C/native work for unchanged semantic/native keys | ABI/header/compiler-specific keys and atomic manifests; emitter refactoring can affect GCC work | Darwin macro tracking costs and frontend dependency costs are separate; 5x observation is unverified here |

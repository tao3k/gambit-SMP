** Benefits, overhead and retirement

R > H: removed repeated work must exceed validation, isolated-session initialization, IPC and publication work; no measured speedup

| Case | Condition | Work boundary | Added cost | Retirement gate |
|---+---+---+---+---|
| noChange | All complete consumed keys match; no requested new live activation | 0 compile families | Validation and manifest lookup; fresh activation charged separately | Timestamp-only reuse authority retires only after complete cuts and successful-origin parity |
| runtimeBody | Only certified runtime-only body projection changes | 2 compile/link families (7,8); consumer expansion families spared | Projection validation; runtime-only nonempty split remains unproved | Whole-module wait can retire only for consumers proved independent of that body |
| optimizer | Consumer-visible optimizer projection changes | 5 families (3,4,5,6,8) remain eligible | Optimization metadata identity and invalidation edges | Do not retire optimizer-dependent invalidation on interface-name equality |
| macroHelper | Executed transformer/helper projection changes | 8 families (0-6,8) remain eligible in selected model | Transitive phase closure and immutable program storage | Unchanged runtime-only output may cut off; this is not a claim of eight real source commands |
| parallelConsumers | Common phase closure ready; other imports fixed; isolated effects | 2 independent consumer expansion jobs, not 12 | Fresh sessions, IPC or in-VM isolation and global CPU/memory admission | Shared import lock retires only after every protected state mutation has a new owner |

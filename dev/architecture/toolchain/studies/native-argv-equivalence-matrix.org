*** 1. What Equivalence Must Compare
:PROPERTIES:
:ID: 25896150-1098-5b8e-8c69-a937cdddae6c
:CUSTOM_ID: 1-what-equivalence-must-compare
:END:

Each future case needs an exact source/profile pair and immutable inputs.
Legacy and managed arms must receive matching child environment, tools, cwd,
source/output spellings and metadata; foreign frozen-driver receipts cannot
stand in for a different configured tree. Observe the old arm at the final
process boundary, not by asking a new renderer to predict both expected and
actual argv. A capture adapter alone tests command construction; it does not
qualify actual compiler/linker/runtime behavior.

For supported input, compare program and prefix, every argv element and order,
child env presence/values, cwd, resolution actions and their order, selected
metadata/diagnostics, output roles/paths, and delivered success/failure status.
Account for query/tool/version/helper invocation effects: remove a helper only
when it is an implementation detail with no required observable effect.
Unsupported-input rejection is *restricted admission*, not an equivalence pass.
Structured errors versus ~/dev/tty~ warnings require a declared transport/status
contract; arbitrary stderr masking cannot establish parity.

Native artifacts need independent format/symbol/relocation/runtime checks under
the existing qualification rules. Object byte identity can be useful where
reproducible, but is neither universally necessary nor sufficient for semantics.
Do not erase source/path/debug differences to force a comparison to pass.
The matrix's oracle is the pinned old producer/driver route plus independent
expected invariants; the shared new renderer cannot serve as its sole oracle.
No case below has been run in this study.

The [[file:independent-equivalence-evidence-plan.org][independent evidence design]]
now specifies B0-B6 boundaries, L0-L3 evidence lanes, fixtures and negative
controls for every E row. The [[file:../../../refactoring/modern-c/studies/native-caller-retirement-plan.org][caller plan]]
identifies actual upstream paths and M2-M8 capability dependencies.

*** 3. Actual Retirement Gates
:PROPERTIES:
:ID: 258683a7-73ec-5642-8d30-d279cc347edf
:CUSTOM_ID: 3-actual-retirement-gates
:END:

“Retire” below means unreachable from admitted managed callers. Shared legacy
functions remain while other callers need them. Each gate needs concrete
implementation evidence and the relevant E rows; *none is closed today*.

| Gate | Retirable responsibility | Must be true before caller retirement | Must remain / whole-file deletion condition |
|-
| R2 / M2 | Repeated native string flattening/splitting in Gerbil | Native emitter preserves phase/debug/static filtering; every string ingress tagged/decoded or rejected; E02-E04/E11/E14-E19/E24/E31-E32 | Semantic GSC options stay Gerbil-owned; delete helper only after all native/other callers accounted for |
| R3 / M3 | Native gsc -obj delegation and direct-GCC dispatch duplication | Every selected object/exe call issues typed intent to the same executor; E05/E07-E10/E13/E25/E29-E30 and semantic-link barrier pass | GSC -c/-link semantic generation remains; no executor nesting gsc -obj or runtime bypass |
| R4 / M4 | Darwin env BUILD_DYN_* bundle protocol | Separate object/bundle intents, source-bound metadata and producer-bound aliases; E07/E20/E24-E25/E29-E30 pass | Static path/copy and symbol encoding retained until independent parity evidence; bundle errors preserved |
| R5 / M5 | ##gambuild-params LF/env transport on managed route | Direct structured request emission preserves presence/encoding/cwd; E02-E05/E14-E16/E20-E25 pass | Gambit semantic operation selection and portable legacy dispatch stay; no all-callers deletion claim |
| R6 / M6 | Shell native metadata/package resolver | Producer side records and one resolver cover canonical subset, order, diagnostics and query effects; E18-E23/E27/E29 pass | Semantic linker metadata composition remains; new rejection is a scope restriction, not warn/ignore parity |
| R7 / M7 | Portable/Darwin literal substitutions and final eval | One typed recipe source generates both outputs; managed program/argv/env/cwd runs directly; E01-E17/E24-E29 pass; call graph has no gambuild/eval fallback | Legacy renderer/script may stay for explicit unsupported/portable callers; literal substitution alone does not satisfy gate |
| R8 / M8 | Separate hand-written mode/flag policy in legacy and typed outputs | ConfiguredNativeModel authoritative; configure probes feed it; E01-E08/E12-E13/E26-E28/E30; coherent model/header/script/profile publication and actual artifact identities | Configure/header generation and legacy output stay; no copied Zig flag table; remove old policy literals once both renderers derive from model |

Dependencies are not a simple sequence of file deletion. R8's shared model and
R6's metadata coverage support R7; R2/R5 establish correct ingress for R3/R4.
Migration can qualify an object profile first, but that does not close the bundle
or either direct-exe gate. A gate record must enumerate callers/modes/input
subset/platform/identities, covered E rows, rejection policy and native receipts.
Any unqualified caller remains explicitly legacy, not silently counted migrated.

*** 4. No-Wrapper Completion Record
:PROPERTIES:
:ID: ad1a387c-3b50-5093-87a1-26640112d9b1
:CUSTOM_ID: 4-no-wrapper-completion-record
:END:

A future retirement receipt must contain:

- Pinned old and new source/toolchain/model/profile/decoder/extension identities;
  accepted modes and input subset, plus explicit rejection cases.
- E-row observations from independently captured old/new process boundaries;
  query/diagnostic/failure evidence, source/path/alias invariants and native gates.
- A source call-path inventory proving no migrated request uses GAMBUILD/BUILD_*
  env transport, native gsc -obj, gambuild-C, template eval or hidden legacy retry.
- A rule-ownership audit: the old literal rule has moved into the shared model,
  rather than being copied and still independently edited in two places.
- Required outer platform/build/test gates, retained failure history and exact
  scope. Performance admission is separate; no speedup follows from E-row passes.

This is a definition of required evidence. No source call graph, test suite,
profile generator or native gate was changed or executed in this document work.

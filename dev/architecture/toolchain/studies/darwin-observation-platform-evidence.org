*** Official Web References Read
:PROPERTIES:
:ID: 4c7cd9d0-5f46-570a-a10f-18a0ca1c5741
:CUSTOM_ID: official-web-references-read
:END:

- [[https://developer.apple.com/documentation/endpointsecurity/es_event_exec_t][Apple es_event_exec_t]]
  identifies argument/environment accessors and exec properties. SDK headers
  provide detailed version/lifetime comments used in this design.
- [[https://developer.apple.com/documentation/endpointsecurity/es_event_exit_t][Apple es_event_exit_t]]
  documents process exit status; local SDK additionally identifies wait encoding.
- [[https://developer.apple.com/documentation/endpointsecurity/es_message_t/seq_num][Apple seq_num]]
  documents event-loss detection. This page describes availability as version
  greater than 2, whereas the read SDK field comment says >= 2. This study does
  not resolve that wording mismatch; selecting >= 4 for the initial candidate
  also requires the SDK global counter and avoids depending on that difference.
- [[https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.developer.endpoint-security.client][Apple ES client entitlement]]
  and [[https://developer.apple.com/documentation/endpointsecurity/client][client initialization]]
  establish entitlement request and privilege/TCC failure categories. These are
  prerequisites, not evidence this task has permission or a working client.
- [[https://developer.apple.com/library/archive/documentation/Security/Conceptual/System_Integrity_Protection_Guide/RuntimeProtections/RuntimeProtections.html][Apple archived SIP runtime protections]]
  describes protected-process restrictions and DYLD purging. Its 2015 date limits
  exact-host conclusions; no live protection-state probe was made.

API-specific argument/environment/global-counter pages sometimes returned only
JavaScript stubs and their linked Markdown fetches failed. They are not cited
as independently read full documentation. Local SDK declarations/comments and
the successfully indexed official type/sequence/client pages supply the claims.
A rolling Apple XNU page was opened during research but is not used to identify
this host's kernel implementation or prove observer completeness. No third-party
ES wrapper or blog is used as normative API evidence.

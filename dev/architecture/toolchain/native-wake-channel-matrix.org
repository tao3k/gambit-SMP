** Gain

| key | avoided | added | condition |
|---+---+---+---|

| latency | Avoid indefinite old-roster stall from a lost notification under admitted fallback | Native wait timeout/recheck and scheduling overhead | Conditional detection bound T plus scheduling delay; not measured latency or arbitrary OS progress guarantee |

| language | One modern C wake authority can serve cleanup, FFI waits and scheduler | Typed outcomes, control gate, lock-free signal ingress where qualified | Zig cannot remove synchronization, signal ABI, root or retirement obligations; extra language value not established |

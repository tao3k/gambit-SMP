** Native-only execution and failure custody

1. Validate and lease the explicit completed producer once, with exact historical
   input bindings where needed; validate the actual runtime identity.
2. Compare the complete current core Scheme inventory and bind its actual
   bytes. Import the declared native leaf delta from its source lock.
3. Open the fixed task-owned consumer through the existing incremental source
   custody protocol. Import once; apply only byte changes thereafter. Reuse the
   shared configuration proof or run bounded configure; preserve the ABI.
4. Independently qualify selected typed argv modes. During native-only Make
   execution, replace the templates' =gsc-boot= generation entry with a directory
   denial gate; Make cannot recreate an executable at that path.
5. Run phase3 then phase4. Any unexpected generation prerequisite fails;
   silently regenerating is not an accepted reuse outcome.
6. Compare all generated C, including linker C, and the pinned generation
   inputs; preserve the original producer. Publish only a completed native
   output, then run map multi-shot continuation and GC consumers on it.

Ordinary failure restores the disabled entry with =finally= and checkpoints the
same work tree without publishing a successful runtime. Termination before
cleanup can leave it incomplete; reconciliation must address that same state.
Creating a new tree to hide the failure is forbidden. The incomplete state
never mutates or supersedes the immutable old producer.
No unknown result is reclassified as PASS, and no heap/wait increase is permitted.

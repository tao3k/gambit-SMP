** Gain

| key | avoided | added | condition |
|---+---+---+---|
| root-lifetime | After canonical external release, no mandatory managed owner root merely to await an acknowledgement | One stable rootless outcome/tombstone record until acknowledgement settles | No Scheme object or resource-capable pointer hidden in the supposedly rootless record; outstanding grants remain rooted |
| admission-work | No new accepted borrow after close; stale open observations cannot enlarge the drain set | One reserve and one commit revalidation per proposed borrow plus root publication and rollback/outcome records | O(B) bookkeeping for B requests and O(outstanding requests + pending notices) storage; no fixed latency or speedup inferred |

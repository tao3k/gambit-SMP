** Elimination and added work
Retire implicit processor-zero/ambient VM assumptions only after a complete registry/scanner adapter and entry-state protocol. Added work is root leases, borrowed-slot protection, owner/reentry checks and reloads. Current required GC roots are baseline, not a Zig-specific cost.

Modern C owns this baseline redesign. The protocol and formal reuse are language
independent; none proves an additional net gain from maintaining Zig.

proofs; the five new source simulations and RC-MEMORY remain open. A retained
root domain is neither a barrier participant nor a collector work context.

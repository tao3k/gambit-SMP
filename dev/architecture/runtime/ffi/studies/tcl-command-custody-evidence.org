| TX02 | [[https://www.tcl-lang.org/man/tcl8.6/TclLib/CrtObjCmd.htm][CreateObjCommand/DeleteCommand manual]], deletion and command info | Delete hooks and token-based removal; renamed commands require identity-aware removal. | TX04 | [[https://raw.githubusercontent.com/tcltk/tcl/core-8-6-branch/generic/tclBasic.c][tclBasic.c branch reading]], browser source-line ordinals 1974–2132, 2387–2409, 2978–3139, 3348–3355, 4225–4306, 5124–5222 | Create has pre-install NULL returns; replacement may directly discard a recreated command; deleteProc precedes final command-structure cleanup; string argv is freed after callback return; normal/NRE evaluation performs post-call cleanup. | TX05 | [[https://www.tcl-lang.org/man/tcl8.6/TclLib/Thread.htm][Tcl threads manual]], introduction | One interpreter may only be used by its creating thread. A mutex does not grant permission to migrate its operations to another OS thread. |
| TX06 | [[https://www.tcl-lang.org/man/tcl8.6/TclLib/SetResult.htm][SetResult manual]], freeProc section | Tcl owns/retains results under the specified policy; custom callback handles non-Tcl allocation; VOLATILE copies. | TX07 | [[https://raw.githubusercontent.com/tcltk/tcl/core-8-6-branch/generic/tclResult.c][tclResult.c branch reading]], rendered lines 3–8, 47–50 | Saved interpreter state has restore/discard obligations; FreeResult invokes its custom free callback. Preserve does not keep further eval logically enabled after deletion. |
| TX09 | [[https://www.tcl-lang.org/man/tcl8.6/TclLib/DoOneEvent.htm][DoOneEvent manual]], description | Event processing may recurse; DONT_WAIT avoids sleeping for absent events, not arbitrary time inside a handler. Its event-work result differs from a Tcl command completion code. |
| TX10 | [[https://www.tcl-lang.org/man/tcl8.6/TclCmd/catch.htm][catch manual]], description | Tcl can catch exceptional command return codes and continue. Hence a return-code sentinel is not proof of an immediate, uncatchable Scheme transfer. |
| TX11 | [[https://www.tcl-lang.org/man/tcl8.6/TclLib/DoOneEvent.htm][DoOneEvent]] and [[https://www.tcl-lang.org/man/tcl8.6/TclLib/SetResult.htm][SetResult]] | Event and command-result boundaries need separate adapters; a scope must record which interface actually delivered the callback. No new independent claim of their internals is made. |

The live manuals identify themselves as Tcl/Tk 8.6.18; branch readings use
~core-8-6-branch~. Neither establishes which Tcl/Tk the Gambit example would
load here. No local Tcl source checkout was found in vendor. A tagged raw
tclBasic read failed, the GitHub commit endpoint was unavailable, and shell
retrieval failed DNS resolution. Thus no immutable remote commit or full-source
hash is asserted. Separate DeleteCommand/DeleteInterp/SaveResult/SaveInterpState
and cancellation-page fetches failed; claims use the successful pages/source
above. Failed retrievals are retained as gaps, not converted into evidence.

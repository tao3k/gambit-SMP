IV01. Count equal semantic obligations once.

The prior 13 necessary shared support families remain the architectural basis,
not an empirically minimal count. This study refines seven proposed record
kinds within that support (ID02), adds no claim of seven separately eliminated
systems, and establishes zero Zig-exclusive support eliminations. Current
common-schema C is the baseline, not unmodernized manual C.

IV04. Quantify work without assuming speedups.

For a fixed admitted history define C credited command retirements, D temporary
depth leases, A activations, Y yield attempts, X prepared yieldto transfers,
F failed-transfer rollbacks, W rewinds, P popped callback invocations, and S
producer-settlement work. Distinguish interpreter events from generated checks;
do not double-count a yieldto as a second source dispatch unless it occurs.

#+BEGIN_SRC text :eval never
W_support = C*k_credit + D*k_lease + A*k_activate + Y*k_yield
            + X*k_transfer + F*k_rollback + W*k_rewind + P*k_callback + S
M_support = live_activation_records + live_transfer_records
            + live_callback/debt/root/producer/resource metadata
#+END_SRC

Each term requires a concrete provider bound before any total estimate. The
source splice/rollback routines linearly search the destination callback chain:
with B traversed callbacks, a prepared/failed transfer can have O(B) scan work.
A redesigned owned direct slot handle could remove that scan only if slot
lifetime and generation/invalidation are proved for all mutations. Its extra
handle/mapping cost must be counted and both C and Zig can use it. Infinite
yieldto cycles or arbitrary native cleanup defeat a finite drain bound.
[IX04–IX10, IP05–IP09]

IV05. Define common positive net benefit by eliminated work and fan-out.

Runtime benefit requires W_removed > W_support_added for the same observable
history and resource metric. A safety improvement can be valuable without
being a speedup. Maintenance benefit requires fewer independently maintained
depth producers, environment pairings, slot mutation rules and failure policies
after actual retirement, with complete coverage. Generated line count and
nominally shared support count are not eliminated work. Whole-word trace
restore, manual root compensation and unowned splice scans remain until their
replacement is semantically admitted. No retirement has happened here.

IV06. Isolate the Zig-specific break-even condition.

Let S_Z be necessary C-specific binding/cleanup/support work actually eliminated
after C generation and existing library reuse. Let K_Z be residual Zig compiler,
ABI/header, release/tooling, mixed-language support and any independently justified duplicate realization.
Zig increment requires S_Z>K_Z without weaker semantics/resource/progress
requirements. This study proves no positive S_Z term: the seven record kinds,
two emitter audits, root debt, native boundary and reuse cut are required by
both providers. Optional future direct-slot optimization is common to both.
An experimentally admitted unique compiler service could change the result;
its promise cannot be booked as current savings. [IV01, IV03–IV05, IP10]

IV07. Refutations and falsification criteria.

| Optimistic claim | Refuting source/design observation |
|-
| Depth is always nonnegative, so usize is safe | Direct idle root-yield rewind can pass through -1 under stated source premises |
| aux saves the original absolute depth | Resume adds relative offset to the current caller's depth |
| Null root means runner is home | TOP_CB is environment-relative; different empty environments share null |
| yieldPtr null means transfer complete | Successful yield clears it while caller slot still owns the list |
| Deletion behaves like ordinary coroutine command resume | Direct rewind stages activation without the command increment |
| Rewind guarantees arbitrary cleanup will finish | Reentry, native loops and unknown producers defeat that liveness premise |
| A returned host call makes the interpreter clean | Suspended application coroutines and producer/native effects can persist |
| Zig removes the coroutine/FFI protocol | Equal-scope C and Zig retain the same seven obligation rows |

IV08. Decision and next gate.

Continue Scheme-owned common contract and modern generated C. The advance is
phase-indexed debt/ownership reasoning and explicit refusal of unjustified
reuse, not a language-based acceleration claim. The unresolved work is the
complete writer/deferred-slot/environment pairing invariant, every raw/private
and injection producer, full cleanup progress, persistent-session isolation and
total cost. All full requirements and AG05–AG07 remain unresolved/unpromoted;
no reusable native profile or Zig incremental benefit is issued. [ID01–ID18,
IP01–IP10, IV01–IV07]

| ID | Primary evidence | Bounded use |
|-
| NP01 | [[https://ocaml.org/manual/5.3/intfc.html][OCaml C interface]], §§5.1, 7.3, 12.1–12.2 | Rooted locations and cooperative updates differ from heap access permission. Native threads require registration. Named root values can change during GC. Blocking transitions may run pending callbacks/raise and forbid managed access while released. Gambit's analogous participation protocol must be derived, not copied. |
| NP02 | [[https://anil.recoil.org/papers/2020-icfp-retropar.pdf][Retrofitting Parallelism onto OCaml]], §§1.2–1.4, 5.4 | Existing C access assumptions constrain collector design; activation/scanning of fibers needs explicit synchronization. Infer a Gambit access protocol; do not import benchmark percentages or assume current library internals match the paper. |
| NP03 | [[https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf][WG14 N1570]], §5.1.2.4 ¶25; §7.13.2.1 ¶2–3; §7.17.3 | Conflicting unsynchronized non-atomic actions are undefined; longjmp needs a live same-thread environment; certain modified nonvolatile automatic locals become indeterminate. Proposed gate, cut and off-stack ledger are deductions from these constraints, not supplied algorithms. |
| NP04 | [[https://kcsrk.info/papers/retro-concurrency_pldi_21.pdf][Retrofitting Effect Handlers onto OCaml]], §§2.3, 3.1–3.2, 5 | Deliberate one-shot and no-C-frame capture choices, mixed-stack exception handling and cleanup tradeoffs. Gambit retains different Scheme and native-marker semantics. The paper does not validate jumping across Zig frames. |
| NP05 | [[https://raw.githubusercontent.com/ocaml/ocaml/5.3/runtime/caml/callback.h][OCaml callback header]], lines 26–52 | Explicit propagating versus typed result callbacks offer distinct boundaries. This is inspiration for an intentionally specified service result, not equivalence of a returned error and a Scheme continuation transfer. |
| NP06 | [[https://www.iro.umontreal.ca/~feeley/papers/FeeleyMillerLFP90.pdf][A Parallel Virtual Machine for Efficient Scheme Compilation]], §§1–2 | Historical Gambit motivation for a target-parameterized semantic machine and frontend/backend information exchange. Supports the architectural direction; does not describe today's FFI, prove a modern GC or require Zig. |
| NP07 | [[https://ziglang.org/documentation/0.15.1/][Zig language reference]], tagged unions, error unions, defer and atomics | Private state/ordinary cleanup can be expressed with typed mechanisms. No lifetime, moving-root, complete GC or foreign-longjmp guarantee follows from those facilities. Compare against generated/opaque modern C, not today's raw C macros alone. |

NP references are primary reading identities, not downloaded byte-pinned
inputs. No quotation or numerical performance result is reused. The
architectural conclusions and formulas are our conditional deductions.

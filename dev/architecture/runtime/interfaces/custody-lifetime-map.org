** Lifecycle transitions

#+NAME: custody-lifetime-steps
| Step | From | To | Guard | Custodian | Frame | Obligation |
|---+---+---+---+---+---+---|
| Enter | Public cursor | Private activation | Snapshot alloc/limit; select cell; retain region and activation identity | Counted phase participant owns unfinished copy/Tail and private suffix | No task settles; C automatic locals are the inspected representation | WC-PRIVATE-LIFETIME |
| TailLoop | Private activation | Private activation | goto again follows Tail synchronously; each new copy may derive further tasks | Current cell plus remaining start/n and alloc/limit must survive; completed Tail edge can derive copy debt | Tail progress is not whole-object or descendant completion | WC-TAIL-LIFETIME |
| Flush | Private activation | Public local cursor | Write alloc_heap_ptr at threshold/space cut or normal mark_array return | Cursor becomes visible to local scan; Tail may remain on stack at threshold | Same Body identities; no settlement from cursor assignment | WC-PRIVATE-LIFETIME |
| Publish | Public local cursor | Queue or local scanner | Exact end marker/prefix and profile lock/barriers; current-scan branch stays local | Body queue/local custodian accepts; source retains Tail; queue container stays pinned | Move Body custody without changing task set | WC-TAIL-LIFETIME |
| PrepareTransfer | Private activation | Frozen transfer | Proposed migration only: freeze old execution right; preserve full continuation/cursor/role frame | Source stays counted until destination or counted transfer service accepts; no idle gap | No task reissue; old and new may be counted simultaneously | WC-OWNER-TRANSFER |
| AcceptTransfer | Frozen transfer | Successor custodian | Accept exact collection/phase/region/activation generation and unfinished task set | One execution right; durable acceptance before source release; unknown outcome retains transfer | Task ownership changes; issued/settled sets unchanged | WC-OWNER-TRANSFER |
| DrainIdle | Local scanner or successor | Phase idle | No private activation/Tail/initializer/transfer debt; complete local scan/steal path before count decrement | Queued tasks can reside in pinned queue while owner idle; phase closure needs complete producer inventory | Idle differs from PSTATE destruction and does not settle queued tasks | WC-OWNER-RETIRE |
| Retire | Phase idle | Retired storage | No remaining raw-pointer/container/scanner users; all unfinished rights accepted elsewhere or settled | Keep queues/locks/msections alive until users drain or container migration is accepted | Thread exit alone is not a reclamation permit | WC-OWNER-RETIRE |
#+END:

** Receipt currency
#+BEGIN: sysml-view :kind lifetime-receipts :source architecture/runtime/interfaces/models/sysml/copy-handoff.sysml
#+NAME: custody-lifetime-receipts
| Rule | Cut | Validity | Boundary | Obligation |
|---+---+---+---+---|
| IssuePrivate | At candidate finishCopy cut | Exact initialized copy, generation, local alloc range/role frame, counted activation and future scan path; required Tail retained | No native receipt API exists; ghost cut requires source simulation | WC-RECEIPT-CURRENCY |
| ConsumeOnce | Actual finishCopy settlement | Revalidate current custody or accepted successor/settled receipts and one settlement right; no unknown effects | An old Boolean accepted flag or worker ID alone is insufficient | WC-RECEIPT-CURRENCY |
| Advance | After publication or migration | Replace authority by exact same-task successor chain; historical settlement remains true | Do not revive Copy debt or use stale private lease as current execution authority | WC-OWNER-TRANSFER |
| PublishBody | At threshold closure before goto again | Only Body custody advances to queue/scanner; Tail remains source-owned until explicit transfer or discharge | Signal is not receipt; queue ownership is not whole-object ownership | WC-TAIL-LIFETIME |
| IdleAndExit | Before counted retirement or storage destruction | Idle forbids owner-private/Tail/transfer work; destruction additionally forbids queue/lock/storage users | Native root scanning starts counted before mark_reachable; arbitrary forced OS exit unqualified | WC-OWNER-RETIRE |
| Reuse | After phase/region/worker slot reuse | Historical receipts remain records; new authority requires matching fresh generation; old settled receipt authorizes no storage access | Same address or processor index does not authenticate new custody | WC-RECEIPT-CURRENCY |
#+END:

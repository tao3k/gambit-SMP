** Proposed lifecycle

|---+---+---+---|
| RootsEnrolled | StrongOpen | Count root scanners before drain probe | source-order plus producer coverage owed |

| CleanupCustody | CollectionComplete | Participant/result and cleanup custody accounted | deferred resource lifetime remains target-specific |
| CleanupCustody | TargetPermit | Target policy permits still-header release after native callback return | earlier than full cycle return; not native-resource success |

| TargetPermit | Reclaimed | Match resource and admission generations; consume once | no stale permit or new borrower |
| StrongOpen | RetainedFailure | Transfer fails while source still owns work | registered custody required |
| CollectionComplete | ProtocolViolation | Attempt to enqueue into a completed phase | reject; no retrospective lifetime repair |

** Proposed QNT atomic steps
#+BEGIN: sysml-view :kind migration-steps :source architecture/runtime/interfaces/models/sysml/copy-handoff.sysml
#+NAME: migration-cut-steps
| Step | Guard | Updates | Frame | Source mapping / gap | Obligation |
|---+---+---+---+---+---|
| beginPublish | Running matching context owner/revision; initialized prefix; no freeze or other publish | PublicationInFlight(opId,immutable manifest); pin context; execution owner retained | No fragment settles; abstract stutter until accepted visibility | Old mark_array/end_heap_chunk has no operation registry; proposed serialization | WC-MIGRATION-SERIAL |
| commitPublish | Actual marker/link/tail visibility and destination acceptance established; same opId | Move included Body IDs to queue/local scanner; record actual Committed; retain publisher observation/lease separately | Tail/parent and task identities unchanged; source may still observe Unknown and retain publication lease | FIFO effects refine atomic Body transfer only with profile proof | WC-MIGRATION-SERIAL |
| freezeContext | Running owner revision matches; admitted full cut; no publish-in-flight or external lock | Freeze source execution; advance freeze revision; pin immutable restore state | Source remains counted; committed queue remains live, not snapshotted for rollback | Logical stop after source cut; no native asynchronous stack extraction | WC-MIGRATION-STATE |
| prepareDestination | Frozen exact TransferId; compatible free context lease and enough capacity; current phase | Destination Prepared with counted coverage; no execution grant | Source still counted; acceptance preparation does not move canonical task ownership | Proposed service action; destination resources cannot alias another live context | WC-MIGRATION-RESTORE |
| rejectTransfer | Decision Pending; target cannot commit after durable Rejected decision | Record terminal Rejected and fence late accept/commit for same TransferId | No task movement; source frozen until known rejection observed | Timeout or local prepare error alone is not fenced rejection | WC-MIGRATION-DECISION |
| commitMigration | Pending decision; matching immutable snapshot/context revision; prepared counted destination; no publish | Atomically decide Committed and give destination sole execution grant for exact unfinished domain | No task issue/settle; source remains frozen/pinned until reconciliation | Proposed linearization specification, not a demonstrated multi-field atomic C implementation | WC-MIGRATION-DECISION |
| reconcileOutcome | Query same durable TransferId/generation; source cannot infer outcome from timeout | Observe Committed or Rejected, or keep Unknown and retained counted custody | Lost/replayed reply does not duplicate execution, commit or Copy settlement | Unknown is knowledge state; actual decision may already be committed | WC-MIGRATION-DECISION |
| resumeSource | Known terminal Rejected; late commit fenced; no unknown publication; exact frozen context retained | Restore source sole execution grant and fresh running revision | Same tasks/frontier; prepared destination resources drained separately | Never resume source merely because a commit reply was lost | WC-MIGRATION-RESTORE |
| releaseSource | Known Committed; current accepted successor or settled task receipts; no other private source work | Release source support/count only when own obligations permit; retain container users/pins independently | Historical finishCopy remains settled; no copy reissue; task sets unchanged | Destination can finish before reply; settled evidence substitutes for forcing it active again | WC-MIGRATION-RESTORE |
| observePublish | Valid same-opId exact committed publication receipt or qualified settled successor evidence | Source observes Committed; advance context revision; clear publisher lease and allow later freeze | No repeated Body transfer or scan; observation does not change actual publication decision | Actual remote readability may precede publisher acknowledgement; never delay abstract commit past acquisition | WC-MIGRATION-SERIAL |
#+END:

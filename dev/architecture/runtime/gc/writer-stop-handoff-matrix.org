* C memory duties
| Edge | Required order | Counterexample |
|---+---+---|
| ENTRY-CLOSE | Acquire writer gate/borrow atomically with close exclusion; close prevents future acquisitions and waits for existing permits | Separate open check then increment permits a writer after zero was observed |
| STORE-LOG | Finish physical write before release-publishing its progress; interruption between them permits only exclusive idempotent private repair | A missing progress bit is not proof that a write did not occur |
| SEAL | Publish generation-bound data/control seal only after no future authority and no in-flight stores/CAS/borrowers/debt | Catcher restoration, exit flag, counter increment or release fence alone is not a seal |
| HELPER | Acquire prior exact-generation seals and no old metadata readers before checked generation transition | Old helper cannot write after successor publication; wrap/exhaustion refuses new authority |
| ROOT | Separate GC root publication/update protocol from control repair; preserve source and scan pins through unresolved handoff | No reinitialization of GC-updated root from immutable but stale SCMOBJ intent |

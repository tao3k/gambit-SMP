* Benefit and peak-memory matrix
#+NAME: root-costs-native
| Capability | Removed work | Quantified bound | Added cost | Condition or falsifier |
|---+---+---+---+---|
| Pending responsibility | Released native context need not execute its own root scan | For K admitted released contexts: K root tasks remain; active ack targets N-K | O(K) descriptors/phase credits; enqueue/claim/ack state transitions | No removed root scan; existing roots are direct calls, so task layer is new work |
| Lost delivery | Query a stable claim/Ready record instead of repeating effects | Zero additional scan writes for a query or duplicate acknowledgement | Task/epoch/attempt directory and terminal result retention | Only ready/quiescent result loss; unknown write progress cannot be replayed |
| Cooperative worker exit | Continue from a qualified checkpoint without rescanning known prefix | Restore cost O(Scheckpoint); no hard time bound for drain | Checkpoint copy-frame/cursor/child credits plus source and target pins | Stop alone or unknown join lacks complete state; arbitrary owner death remains blocked |
| Strong termination | Prevent empty-queue or idle-count false completion | Frontier covers pending+claimed+ready+quarantine+private+derived work; scan remains O(R+H) | Full-frontier accounting and separate strong/weak phase generations | Zero unsafe early completions is a correctness target, not a speedup |
| Reentry arbitration | Preserve owed late claims and avoid worker waiting on requester | RootAck is earlier than whole-round ResumeSeal; no shortening below actual phase dependencies | Ticket/cut arbitration, phase wait and protected O(U) reload | No bound without finite producers, available worker and fair scheduling |
| Foreign cleanup boundary | Break cleanup-to-owner-return cycle only through qualified deferred custody | Retain Hforeign physical backing until actual destructor/release completion | Owner-affine dispatch, root/native payload transfer and release receipts | Cannot omit destructor or free still shell on enqueue alone; unqualified path refuses release profile |
| Peak memory | Reuse task records and existing root/frame backing only after last use | Peak=max_t(existing backing+task/checkpoint/receipt pools+pins+deferred native backing) | Retained views, root banks, suspended frames and quarantine may extend peak | Count backing once; O(K) records is not O(K) total retained heap; no peak decrease proved |
| Modern C and Zig | Scheme owns coverage/FrameSpec; modern C owns typed roles, ledgers and collector adapters | Zero additional Zig runtime-work reduction established | Both need source closure, attempt fencing, resume seals and memory-order evidence | Language replacement cannot supply missing recovery state or remove GC phases |

* C memory ordering
| Edge | Required order | Rejected shortcut |
|---+---+---|
| PORT-ENROLL | Safe empty port installed with VM/root participant before payload or thread visibility; complete source view freezes before origin admission. | No origin bootstrap via marker allocation that can itself GC an unprotected parameter. |
| INTENT-BEFORE-CAS | Immutable candidate/token/expected owner header and source custody published before ownership CAS can execute. | Observing free header before in-flight control/future publication closes is not no-effect evidence. |
| FIELD-PROGRESS | Write private metadata, then release progress evidence; stopped helper may see actual store without progress bit and repair idempotently. | Progress bit is not permission to read a partial payload; plain concurrent same-value writes are still excluded. |
| LOCATOR-COMMIT | Publish exact locator after complete metadata; root acceptance precedes final release commit; consumers acquire commit before reading private fields. | Locator, normal C return and root admission are distinct facts; none alone implies whole binding committed. |
| ROOT-CLOSE | Canonical root-admission/GC-close cut owns scan-visible root word; during close pending source remains old registered view; relocation updates accepted root. | Control helper never writes cached payload over GC-updated root; acquire fence does not legalize an arbitrary data race. |
| STOP-HELP | Close future control/data authority and drain both in-flight sets before exclusive helper; no release from owner-exit observation or failed join. | Revocation counter alone cannot cancel already executing CAS/plain store; lock owner death cannot be repaired by unlocking blindly. |
| RECYCLE | Close original outcome, source/physical scan and reader debt, then checked epoch/owner-tag reuse; root/GC adapters outlive PSTATE cleanup. | Async recovery needs qualified atomic/header/platform stop; general portable C fallback does not promise fault-tolerant progress. |

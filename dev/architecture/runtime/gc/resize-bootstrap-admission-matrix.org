* C memory order
| Edge | Required order | Rejected shortcut |
|---+---+---|
| VIEW | Arguments and RA spill plus materialized FP/R0 precede full-view acceptance; logical frame identity survives stack relocation. | Pointer to current stack slot cannot by itself be a persistent RootHandle. |
| CLOSE | Register-vs-close arbitration and snapshot membership share a linearization domain; slots initialized before publishing. | No live value accepted after snapshot closes merely because an atomic pointer store succeeds. |
| DEFER | Close winner retains pinned frozen caller view; GC updates that view; context-ready acquire and reload precede later descriptor fill. | No caller raw borrow while waiting, no pending SCMOBJ copy outside scanned storage, no lock across rendezvous. |
| CREATE | Descriptor and per-child create reservation precede OS invocation; success/result and child binding are independent observations. | Do not derive no-child from missing ACK, create error synchronization, or creator death. |
| COMMIT | Exact ready generation acquires root/OS/binding receipts and excludes closed GC; only then do barrier and GC consumers switch membership together. | A scalar processor_count store is not the entire generation commit protocol. |
| RETIRE | Close entry admission, prove no child or exact stop, detach membership, drain scanner/descriptor readers, then cleanup/reuse exact PSTATE. | No timeout, ignored join or duplicate cleanup decrements ownership debt. |

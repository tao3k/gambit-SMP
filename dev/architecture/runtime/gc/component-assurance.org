** Elimination and added work
Retire fixed PSTATE-equals-worker assumptions only after participant and worker roles have independent roots, task and phase contracts. Added work includes epoch grants, descendant accounting and memory-order qualification. Shared producer containment can eliminate support transactions conditionally; current performance is not established.

Modern C owns this baseline redesign. The protocol and formal reuse are language
independent; none proves an additional net gain from maintaining Zig.

* Benefit and peak-memory matrix
#+NAME: root-costs-native
| Capability | Removed work | Quantified bound | Added cost | Condition or falsifier |
|---+---+---+---+---|
| Business versus GC debt | Remove dependency GC -> constructor return when the return itself needs GC | For F frozen pending invocations, GC does not wait for F business completions; GC-critical uncovered debt must be zero | F stable escrow records, no-GC publication and root scanning | No claim all native producers can freeze; absent profile/stop/root evidence still refuses |
| Non-cyclic root scanning | Scan roots independently of owner port mutex/callback permit | Declared wait rank owner=2 > GC=1 > bounded scan service=0 | Pre-backed scan metadata, pinned handles and transitive lock audit | No deadlock proof beyond declared wait graph; all hidden callbacks/locks need source refinement |
| Native-call count | Query canonical result instead of re-accept/re-fork/re-read | At most 1 native producer invocation and 1 wrapper/result delivery per modeled attempt | Attempt identity, result/root slot and outcome-retention metadata | This saves duplicate work only relative to an incorrect replay strategy, not a claimed speedup over current C |
| Conditional GC critical path | Keep admitted constructor completion/rollback wait off root closure | Delta critical work = eliminated reverse-wait dependency minus freeze/scan/ledger costs; no finite wait-time bound on external calls | Capture/freeze/scan/reentry actions and result root publication | Positive only when service never waits on owner and added work is cheaper; not a wall-time measurement |
| Ticket reuse | Transfer existing persistent credit from source -> escrow -> wrapper or terminal | Live duties <= pre-reserved slots; one duty remains charged while business result or disposal unknown | Canonical record/receipt generation and reader/child drain | No additional ticket for ordinary continuation of same duty; fanout needs separate reservation |
| Control-memory bound | Share immutable profile; keep per-attempt escrow and frozen view | Control capacity = M*(escrowBytes+resultSlotBytes+receiptBytes)+rootCells*cellBytes+scan/wait pools+allocator overhead | Physical resident backing exists before native effect | Logical quota alone cannot guarantee no allocation failure; layouts/sizes remain unmeasured |
| Whole-round peak | Avoid requiring both old and copied payloads when exact ownership transfers | Peak=max_t(heap+actual pools+unique native backing+root backing+quarantine) | Captured client/process/MSG may outlive the GC; unknown outcome retains it | Count shared native backing once; no whole-round peak reduction proved |
| Native budget boundaries | Bound process-local memory/handles without claiming external process/network memory | Native bytes/handles charged by exact staged recipe; child process heap and OS/global resources have separate bounds | Per-provider bound, temporary strings/pipes/TLS/RC overhead and side-effect state | Unknown bounds refuse bounded admission; kernel/external resources are not covered by Scheme heap quota |
| Failure-path modernization | Unify custody support while preserving three different source semantics | 3 failure cuts: accepted client vs server; process result/error+dev duty; consumed MSG/RC duty | Source correction, per-stage disposal and exception/error mapping | No existing path retired; fixnum/device/#f behavior needs independent semantic acceptance |
| Unknown outcome isolation | Allow GC closure when only bounded native outcome is unknown | 0 extra invocation and 0 physical refund from timeout/notification loss; query then known-result reentry | Potentially indefinite quarantine and retained roots/code/resource budget | Unknown managed writer, dependency shape, callback frame or owner transfer is not isolatable |
| Modern C and Zig | Scheme-generated contracts and shared modern C service support | No incremental Zig runtime-work saving established | Both need escrow/root/lock/ABI/effect and memory-order proofs | Modern C mandatory; a language switch supplies neither GC coverage nor deadlock freedom |

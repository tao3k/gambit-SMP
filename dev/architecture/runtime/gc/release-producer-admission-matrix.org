* Benefit and peak-memory matrix
#+NAME: root-costs-native
| Capability | Removed work | Quantified bound | Added cost | Condition or falsifier |
|---+---+---+---+---|
| GC critical release work | Move only admitted legal-delay bodies Fi out of collective cleanup | Delta critical work = sum eligible(Fi-Hi)-profile/root/ledger cost; serial comparison only | One handoff per right plus roots/rescan; scheduler contention | Positive only if saved body work exceeds these costs; zero measured speedup |
| Budget unit | Share one persistent ticket across producer/wrapper/queue/terminal states | M=sum disjoint Constructing+Wrapped+Queued+Running+Retained; not distinct function count | O(M) ticket/receipt slots and generation metadata | Two equal release functions or RC payload addresses can still require two release rights |
| Preflight capacity | Avoid collector allocation/waiting for owner to free queue capacity | For each resource dimension k: sum live q_i[k]+inflight descendant reserve <= pool[k] | Atomic quota ledger; root/code/wait/handle/native-byte bounds | Reserve before first native effect; unknown size/fanout refuses bounded profile |
| Peak control memory | Reuse same slot when transferring one duty; no second queue payload copy required | Pool = M*slotBytes + rootCells*rootCellBytes + waitBytes + receipts + allocator overhead | Resident pre-reserved storage can increase low-load peak | Logical credit cap requires actual physical backing proof; no numeric byte estimate without layouts |
| Retained native memory | Account resources ignored by Scheme wrapper size | Peak=max_t(baseHeap(t)+physicalPools(t)+retainedNative(t)+rootBacking(t)+quarantine(t)) | Delay can retain payload longer; unknown outcomes can retain indefinitely | Do not sum independent maxima, double-count already physical reserved bytes or refund on queue ACK |
| Root closure | Reuse registered dependency handles; avoid re-discovery during destructor | R dependency cells scanned/relocated; late managed edges require counted pre-seal rescan | Instance registration before possible GC; weak/strong ordering | Descriptor alone not root instance or current trace receipt; opaque FOREIGN not a managed root |
| Code/library profile | Share immutable effect/affinity descriptor per code/config generation | O(P) descriptors plus O(M) generation references | Configuration-change revocation, external alias audit, library pins | Code descriptor dedup permitted; per-instance release rights cannot be deduplicated |
| Explicit and rollback paths | Reuse typed disposition/custody support while preserving caller boundary | No work reduction claimed for synchronous origins; three value rollback protocols | Preflight adaptation in CFUN/SFUN plus each direct constructor | No legal timing/error equivalence means no delayed job admission |
| Source coverage | One generator protocol can cover arbitrarily many generated value releases | 12 os_io registrations + 1 permanent-null setup expression; 3 value templates; 4 example custom types | Open custom converters/C API require registration; platform predicates remain | Counts are source inventory, never active Darwin leaf coverage or speedup |
| Source correction cuts | Replace ambiguous failure ownership with exact return-slot custody | Three lexical blockers: Win32 event return, process conversion failure, accepted-client/server mismatch | Source corrections and independent failure-path evidence | No implementation done; do not assign resource leak frequency or observable impact without native evidence |
| Teardown | Use shared drain/transfer barrier instead of implicit PSTATE lifetime | No live ticket/code/root reader when withdrawing scanning/RC/native service | Ordered shutdown DAG; owner dispatch must not wait round seal cyclically | Unknown task disposition/root transfer refuses teardown, not automatic refund |
| Modern C versus Zig | Scheme emits one typed ReleaseSpec and modern C adapters | Zero extra runtime-work saving established for Zig | Both need same profile, credit, root, ABI and memory-order proofs | Modern C mandatory; Zig optional only with independently demonstrated incremental benefit |

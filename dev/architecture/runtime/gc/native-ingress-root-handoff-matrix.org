* C memory order
| Edge | Required order | Rejected shortcut |
|---+---+---|
| PIN-RETIRE | VM lookup and handle pin/retire share a coherent gate; only read opaque token until accepted. | A pointer to already-freed handle/code/clientData cannot be made safe by addref after entry. External unregister/queued-call drain evidence is required. |
| BORROW-PUBLISH | Parent source lease covers every read before child root registration. Child acceptance and raw-borrow relinquish are one custody transition; acknowledgement can be later. | Do not decrement parent coverage then link child roots. Lost ACK retains overlapping custody and uses canonical query. |
| CLOSE-PARK | Close stops new raw-entry claims before waiting. Already pinned handle storage may persist while its payload cell is scanned; parent raw borrow must park/transfer or abort from a full view. | Do not wait for gate reopening while the same active borrow prevents collector entry. Opaque pins and raw execution authority are distinct. |
| MARKER-CONVERT | Child root acceptance precedes marker allocation; each conversion publishes a safe initialized prefix before the next collecting allocation. | Existing still-owned results are already retained in their qualified profile; stable-address ownership does not prove arbitrary field writes or nonzero RC coverage. |
| NESTED-IDENTITY | Activation-local selector is captured before allocating/reentering and restored from the parent activation, not reread from mutable global state. | TLS removes cross-thread sharing only; nested overwrite/cleanup still needs stack discipline and executable-entry lifetime. No arm64 support is inferred from inactive thunk code. |
| EXIT-RESULT | Canonical root/marker/resource cleanup receipt precedes terminal propagation; accepted result/error backing remains pinned until receiver acknowledgement. | A kill call textually after ___call is not guaranteed to run when ___call rethrows. C setjmp cleanup state needs defined lifetime and value rules. |
| RELOAD-RECLAIM | Collector-exclusive slot updates happen-before acquired resume/reload; reclamation additionally drains all descriptor/code/clientData readers and native dispatch. | Release/acquire visibility is not storage lifetime. Unknown results cannot count as cancelled, reclaimed, or harmless solely by timeout. |

* Benefits and added overhead
| Capability | Removed work | Bound | Added cost | Positive condition or falsifier |
|---+---+---+---+---|
| Handle ingress | Avoid stale raw payload copies across closed epochs | Opaque identity only while waiting; payload load after admission | Registry lookup/pin/retire and root-cell metadata | Benefit is correct decoupled admission; CPU improvement is not established. |
| Parent root reuse | Avoid copying every live parent value into a new handle | Reuse mapped locations when compiler certificate covers them | Borrow/accept/ack bookkeeping; possible duplicate root coverage until ACK | Positive work reduction requires fewer copies than registration/coordination work. |
| Existing still ownership | Reuse retained still/permanent converter results | Known still refcount1; no forced duplicate per-result handle | Typed ownership classification and once-only cleanup receipt | A smaller measured profile may need no extra root payload for these results; source/scan closure remains required. |
| Root slot payload | Explicit root words for input and converted prefix | Illustrative 4 inputs + 2 converted at 8 bytes: 48B; depth2: 96B | Descriptor/map/registry/marker/native backing not included | These are native-evaluated model payload examples, not measured allocation or mandatory net added memory. |
| Conversion cleanup | Retire implicit nested generated release assumptions for admitted path | O(initialized-prefix) cleanup, exactly one accepted custodian | Progress tracking, result/error receipt, longjmp-safe state | No global GC blocker may be hidden in unknown cleanup effects. |
| Nested callbacks | Retain precise continuation/native activation ownership | O(depth * live root slots) plus native activation backing | Activation stack, marker/result retention and root reload | Depth/borrow duration bounds are needed for bounded peak; no such general bound is proved. |
| Tcl userdata adapter | Avoid needing a machine-code closure when API supplies context | Use ClientData as a managed acceptor identity | Adapter changes and delete/in-flight/queued-call drain contract | Does not establish generic C ABI callback closure support or raw ClientData safety after deletion. |
| Dynamic thunk | Retire global selector dependency only after certified replacement | 0 dynamic-thunk support newly established on Darwin arm64 | Target ABI/backend or mature closure library, executable lifetime, nested selector protocol | Modern C alone cannot synthesize arbitrary context-free callback closures portably. |
| Peak and unknown exit | Avoid premature reclamation and lost roots | Peak=max_t(unique backing + separate roots/maps + native/dispatch escrow) | Overlapping parent/child roots and unknown native resources may remain retained | No bounded peak reduction or GC latency claim without stop/drain and origin evidence. |
| Modern C branch | Isolate forthcoming C-layer refactor decisions from language expansion | vendor branch modern-c at recorded unchanged source commit | Future implementation and native qualification are separate tasks | This turn creates the branch only; existing vector edit preserved; no production path retired. |

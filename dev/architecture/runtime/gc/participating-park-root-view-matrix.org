* Benefit and peak-memory matrix
#+NAME: root-costs-native
| Capability | Removed work | Quantified bound | Added cost | Condition or falsifier |
|---+---+---+---+---|
| Same-call GC progress | Avoid adding callback-completion wait when separating collector workers | One admitted current invocation -> one park accept + one resume; extra native invocations=0 | SafePointSpec, root view, canonical park/scan/resume state | Current Gambit already collects inside callbacks; this preserves that ability during worker separation, not a new measured speedup |
| Safe-point precision | Replace blanket W_ALL assumption with generated completion cut | One complete spill/root/constructor map per park; no park at known incomplete rest frame | Scheme completion plans, verifier and descriptor/code lifetime | Actual generated spill and constructor coverage must close before old macro logic can retire |
| Root storage | Use described canonical cells instead of duplicating every root value | Metadata O(A+R+D); root visit O(R); no mandatory O(reachable heap) snapshot | A activations, R distinct root slots, D active native/effect obligations | Alias census must be complete; caller-held copies require handles/reload, not an invented immutable value snapshot |
| Native-call exclusion | Drain only relevant issued effects, not require original native call return | Native invocation stays live; GC-relevant effects/borrowers/nested writers must be0 | Effect/origin registry, completion evidence and lock dependency profile | Native-only outstanding work requires separate isolation proof; unknown relevant work cannot become zero on timeout |
| Canonical receipt | Avoid retrying native operation after lost park acceptance ACK | One canonical accept per park identity; query adds0 invocations | Protected attempt/result lookup and retained source pins until resolution | Failed preaccept retains source; accepted unknown response remains VM duty; no receipt reuse across attempts |
| Collector authority | Permit root rewriting while mutator is parked | At most one modeled scan claim; no simultaneous mutator permit | Release/acquire view, exclusive scan/resume state and reader drainage | Full C order proof and independent-worker integration still open; no relaxed load shortcut |
| Fresh reentry | Avoid stale registers/handles after relocation | One context prepare/bind/reload sequence per resumed park; starts stays1 | Whole-round result, root generation and exact owner incarnation | Same native stack must remain alive; moving raw C catcher to different worker is refused |
| Nested callbacks / exceptions | Retain full activation chain instead of treating inner return as outer quiescence | O(A) live activation/exit records; all relevant nested debts settle before park | LIFO marker/catcher roots and exit-vs-scan arbitration | Continuation escape uses generated exit guard; arbitrary native longjmp/unregistered roots reject profile |
| Wait-cycle removal | GC waits for park handoff rather than synchronous result completion | Removes edge GC -> callback-finish when qualified park exists | No GC-critical lock held by parked owner; cleanup/root dependencies explicit | No universal latency or liveness bound; cleanup requiring owner entry must be delayed or rejected |
| Peak memory | No task payload duplication merely to park same call | Peak=max_t(H+P+N+Q); delta inherited marker 24*M(t) plus park/view/log pools and longer retention | Native stack, roots, code, borrowed inputs and unresolved resources stay charged | No measured/proved peak decrease; unknown debt can retain backing indefinitely |
| Retirement | Replace direct managed entry / blanket park flag / unqualified PSTATE lifetime | 0 production paths retired; admitted cohort only after source/order/ABI obligations | Scheme-generated safe-point/exit plans and typed modern C RootRegistry/AdmissionDomain | Keep C portable backend; low-level W/R instructions may be generated internally, not falsely claimed eliminated |
| Modern C versus Zig | Share semantic plans and typed lifetime protocol without second runtime language | 0 Zig-only runtime work elimination shown for park/root/native safety | Both need same safepoint, borrow/scan, native stack, atomic and exception proofs | Choose modern C mainline; CPU benefit needs actual removed baseline work > added protocol work; wait-cycle removal is a separate graph property, current cooperative GC already resumes in-call |

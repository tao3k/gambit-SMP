* Packed word contract
| Field | Encoding | Contract |
|---+---+---|
| gate | signed WORD accessed by backend atomic RMW/CAS | One word, all tags nonnegative; volatile alone is not synchronization |
| closed | bit0 | No future registered permit acquisition after successful close CAS |
| live | bits1..8 | Outstanding permit roles; only exact producer last-use may clear |
| used | bits9..16 | Monotone per generation; prevents same-role reuse after release |
| actor | bits17..24 | Exclusive pre-registered activation identity1..255; no processor-id inference |
| generation | bits25..WORD_WIDTH-2 | Checked increment, never wrap; high sign bit stays zero |
| VM-array | 64 records by default | Exclusive init before publication; pointers do not extend VM lifetime |

* Atomic protocol
| Edge | Required order | Rejected shortcut / cost |
|---+---+---|
| ACQUIRE | Read full packed header; CAS exact word sets used and live together | No open-check/increment gap; failed CAS must retry full checks |
| CLOSE | CAS closed in same word; earlier permits survive until real release | Close does not kill a native writer |
| RELEASE | After last real store/borrow, CAS clears only role live bit and keeps used | Duplicate release cannot affect another role or a reused generation |
| HANDOFF | CAS only on closed header with all live bits empty; increments checked generation and installs both owner permits | Tag includes actor, so competing candidates differ; missing reply never leaves an uncounted owner |
| LOAD | Existing backend uses full-barrier RMW for snapshot and CAS for mutation | Snapshot/query causes cache-line traffic; no free acquire-load claim |

| CW-P01 | [[https://simonmar.github.io/bib/papers/parallel-gc.pdf][Marlow, Harris, James and Peyton Jones, Parallel Generational-Copying Garbage Collection with a Block-Structured Heap]], §§3.1--3.5. | Discusses copying races, local allocation/work and global termination when workers might still export work despite an empty shared pending set. | CW-P02 | [[https://www.cs.utexas.edu/~EWD/transcriptions/EWD06xx/EWD684.html][Dijkstra and Scholten, Termination detection for diffusing computations]]. | Tracks outstanding signalling obligations in a finite computation with bounded production. | CW-P03 | [[https://kcsrk.info/papers/retro-parallel_icfp_20.pdf][Retrofitting Parallelism onto OCaml]], §§4.4.1--4.4.3 and 5.1. | Separates coordinated stop-the-world entry, parallel promotion and root distribution; equal root counts need not balance reachable work. | CW-P04 | [[https://www.llvm.org/docs/Statepoints.html#overview-core-concepts][LLVM statepoints]] and [[https://www.llvm.org/docs/GarbageCollection.html#goals-and-non-goals][GC goals/non-goals]]. | Admitted compiler relocation/root metadata is useful behind a common runtime contract. | CW-P05 | [[https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf][WG14 N1570]], §5.1.2.4. | Qualified synchronization can order queue payload, claims and resumed reads. Volatile field names and unrelated atomic counters do not alone supply the required cross-thread visibility or global predicate. This is a language-model reference, not qualification of the configured C/Zig ABI. |
| CW-P06 | [[https://ziglang.org/documentation/0.15.1/#Lifetime-and-Ownership][Zig ownership]] and [[https://ziglang.org/documentation/0.15.1/#errdefer][errdefer]]. | Local explicit ownership/error cleanup can aid builders; the programmer still owns pointer lifetime. Cross-thread producer permits, moving roots, phase closure and accepted-work recovery remain runtime support in either language. |

study's start, ~evidence/scenarios/zig-native/research.view.json~ already had a
different working-file digest. This concurrent change is preserved and recorded
as preexisting input drift; it is neither evaluated nor adopted as evidence for
this study. Engine declarations, views and independent native outputs are not
modified here. Historical design records remain immutable. Selected source
hashes, current checkout identity and this study's baseline are recorded
separately from those unrelated results.

All five full-runtime/provider/retirement/total-cost/Zig-increment questions
remain unresolved. Literature analogies and the explicit representation invariant
are conditional argument premises, not new registered witnesses or theory-gate
acceptance.

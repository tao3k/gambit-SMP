** Elimination and added work
Retire unsafe implicit cleanup ordering only after producer closure, last-user/derived-task accounting and owner-scoped physical release acknowledgements. Added work is permits, deferred delivery, unknown-outcome retention and shutdown coordination. Avoid retention cycles before claiming positive net benefit.

Modern C owns this baseline redesign. The protocol and formal reuse are language
independent; none proves an additional net gain from maintaining Zig.

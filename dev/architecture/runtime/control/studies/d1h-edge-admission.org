*** Independent Evidence Layers
:PROPERTIES:
:ID: d0e4e113-85e1-507e-9c2a-109c176e5433
:CUSTOM_ID: independent-evidence-layers
:END:

Each edge needs several witnesses; shared product agreement is not enough:

| Witness | Producer / observation boundary | Independence requirement |
|-
| W1 semantic expectation | Scheme fixture/control semantics, observable value/effect order, arity/errors, dynamic state and continuation result | Expected outcome must not be generated by the same host lowering being assessed; use independently derived cases and source-qualified BC controls in a separate process |
| W2 emitted producer facts | Typed HostGraph/FrameSpec and C1 source or native IR, each bound to exact source/config/provider inputs | Inspect actual emitted state/point/slot order, not just a capability Boolean or common planner hash |
| W3 final artifact | Caller and callee ABI, linked host entries/relocations, final tail edges and actual label/descriptor contents after supported setup | GCC evidence and LLVM evidence separate; inspect after all selected optimization/link steps. An intermediate verifier does not describe final code |
| W4 runtime/control | Real mixed execution, Scheme frame/point progression and native stack resource behavior per foreign-entry episode | Preserve unmodified-context outcome controls separately from instrumented diagnostics; instrumentation validity is another qualification duty |
| W5 GC/lifetime/failure | Actual live roots/maps and relocated reload, retained continuation/code/map consumers, setup/init failure delivery | Rooted storage, map completeness and lifetime are separate facts; no active-call count substitutes for captured continuation reachability |

W4/W5 are future observations, not capabilities supplied by this document.
Source analysis and finite models can support invariants but cannot issue final
native or performance acceptance. The exact observer and its perturbation
controls must be qualified; this design does not authorize running one now.

*** Twelve Edge Receipts
:PROPERTIES:
:ID: 02a2ce7c-8805-5588-afb1-d426183e9fd5
:CUSTOM_ID: twelve-edge-receipts
:END:

Rows correspond to X01-X12 in the [[file:d0-d1-cross-backend-protocol.org][D0/D1 matrix]].
Every receipt records caller and callee independently, including same-backend
controls. All rows have status *unresolved / unrun*.

| ID / edge | Independent positive evidence required | Negative/control case and failure rule | Required refactor / source |
|-
| E01 / X01 C1 local | W1 outcome/order; W2 point membership and frame moves; W3 local branch and correct point decoding | Wrong host/metadata ordinal must reject before branch; same function address must not grant membership | New C ordinal emitter/local identity; T01/T04, R01/R03 |
| E02 / X02 C1 -> C1 external | Each GCC host's exact declaration/required-tail form, final external edge and matching incoming state; alternating-host tail cycle bound | Capability unavailable must reject product; plain-return fallback or returning thunk fails D1-H even if a short run completes | Enforced C exit instead of trust fallback; T03, R02/R04 |
| E03 / X03 C1 -> N1 | GCC outgoing edge W2/W3 separately from LLVM N1 entry W2/W3; W1 closure/arity/result/error cases; mixed tail-cycle W4 | Wrong convention, wrong resolved point or dependence on GCC register assignment fails; an LLVM-only tail test cannot close this row | C tail exit + native pc decode/entry; T02-T05/T08, R01-R04/R06 |
| E04 / X04 N1 -> C1 | LLVM outgoing required C-ABI edge separately from GCC incoming ordinal dispatch; W1 behavior and independent reverse-direction result | Native-private convention sent to C host, skipped writeback or pending return helper fails; E03 pass does not imply E04 | Native tail exit + new C entry; T02-T05, R02-R04/R06 |
| E05 / X05 N1 local | W1 primitive/effect semantics; W2 liveness and CFG; W3 admitted local native branch/required checks | Removing a required poll or treating unknown effect as leaf fails even if arithmetic result matches | Runtime-aware native local lowering; T02/T09, R06-R08 |
| E06 / X06 N1 -> N1 external | Each LLVM host's ABI/attributes and point mapping; W3 required external tail edge; W4 long multi-host cycles | Ordinary call plus return, mismatched address space/prototype or a callee dependency on caller alloca fails | Native required-tail emitter and membership; T02-T04, R02-R04 |
| E07 / X07 non-tail Scheme call | W1 independent successor/effect oracle; W2 explicit Scheme return frame; W3 return descriptor and outgoing host tail edge; W5 mixed live frame roots | Keeping successor only on OS stack or reusing tail-frame policy loses state and fails; cover C1/N1 caller-callee combinations | Common FrameSpec and separate return point reload; T01/T02, R06-R08 |
| E08 / X08 return across backend | W1 multiple results/error behavior; each return RA's actual kind/owner/descriptor and destination entry; W4 C1->N1 and N1->C1 returns | Treating descriptor payload as a procedure entry or native result return fails; cover ordinary/task points and large maps | Point-kind-aware return lowering; T02/T04/T05, R06/R07 |
| E09 / X09 internal handler/resume | Typed runtime-role binding, caller size/alignment, saved GVM registers/RA, RETI map and resumed reload; W5 GC through selected slow paths | Wrong RETN/RETI interpretation, missing root or masked path delivering interrupts fails; private polling-point insertion must not change role identity | Symbolic handler bindings plus native checks/resume matched to repaired handler; T02/T04/T09, R03/R06-R08/R12 |
| E10 / X10 ordinary leaf foreign call | Site-specific effect evidence, C ABI return/conversion and allocator ownership; W1 delivered result | Unknown/allocating/callback site labelled leaf rejects; no inherited leaf classification from function signature | Explicit F0 adapter boundary; T09, R08/R09 |
| E11 / X11 collecting/reentrant/blocking foreign path | W2 scanner-ready state and adapter effects; W4 nested callback/catcher origin; W5 relocation/reload and resource lifetime on success/throw | Omit a mapped root or reuse a pre-GC derived address as a negative control; unsupported thread/entry context rejects before execution | Rooted adapters and explicit nonlocal cleanup owner; T08/T09, R07-R09/R12 |
| E12 / X12 foreign entry/final return | Independent C1 and N1 initial entry from call/run/SFUN; W1 original error semantics; marker/catcher/processor/lifetime observations | Expired/multiple foreign return must retain error behavior; a Scheme host normal-returning into H1 call fails | Explicit new host integration with retained foreign-return machinery; T08, R04/R08/R09 |

Negative controls are proposed qualification fixtures, not edits made to the
runtime by this study. Unsafe/malformed products should be rejected by a
qualified static/setup boundary; testing the rejection does not require jumping
through a known-invalid pointer. Runtime perturbations, where legitimately
needed, belong to separately controlled future diagnostic builds.

**** Composition Across the Whole Mixed Cycle
:PROPERTIES:
:ID: d4ab8fc3-3c4e-5467-97fe-d929bb66bb17
:CUSTOM_ID: composition-across-the-whole-mixed-cycle
:END:

E03 and E04 must be composed with E02/E06 and any real bridge/helper hops.
Enumerate all reachable host-transfer paths, including arity/rest/error handlers,
internal returns and dynamic targets. For each pure Scheme tail cycle within
one foreign-entry episode, either prove no pending host activations accumulate
or reject the D1-H product. Nested ordinary foreign callback recursion is a
different resource bound and must not be hidden in a tail-recursion result.

E07/E08 and E09/E11 compose with that cycle: bounded OS stack does not establish
that retained Scheme frames have complete roots or that continuation invocation
restores dynamic state. A common FrameSpec passing both renderers is a useful
consistency witness, not independent proof of its upstream liveness.

*** Module and Product Admission Cases
:PROPERTIES:
:ID: 98c44e81-32f8-583a-8685-6ccbba6b9fad
:CUSTOM_ID: module-and-product-admission-cases
:END:

| ID | Required future evidence | Failure boundary |
|-
| A01 | Preflight and post-relocation manifest agree with actual object/ABI/provider/cohort inputs | C0 module or unknown required capability rejects; matching structure sizes alone cannot pass |
| A02 | Every dispatchable point has one HostId/ordinal/kind/runtime label; required runtime roles resolve by semantic identity; intro slots excluded | Duplicate/missing/misowned points, wrong-kind runtime role or pointer-equality ownership fails |
| A03 | Mixed C1/N1 HostSpec materializes without entering any host for metadata; no pc=0 query or public goto table | Observed setup host entry fails the new contract, even if labels later work |
| A04 | Normal/task/internal and inline/out-of-line descriptors match actual scanners, including table movement during setup | Pre-setup guessed address, wrong chunk order or missing saved-register coverage fails |
| A05 | Allocation/validation/fixup failure leaves no false-ready state and retains all exposed resources safely; image storage and VM-generation instance state stay distinct | Old FIXUP_DONE short-circuit, cross-VM ready-state reuse or freeing reachable code/map/constant objects fails |
| A06 | Primitive setup, C initialization, globals and Scheme thunks preserve actual module/dependency/two-stage ordering and errors | Calling initializers during structural setup, replaying effectful failed init, or inventing cycle behavior fails |
| A07 | Actual capture/resume and scanner consumers retain interpretation storage through failure/teardown | Zero current native calls does not permit releasing code/maps referenced by continuations |
| A08 | Native-selected unit emits no generated C packaging; C1 unit uses new renderer; each retired caller/path has an ownership receipt | A wrapper forwarding into old full targ-dump or cpu.scm does not count as retirement |

The same record identity cannot be reused after source/configuration, final
linked code, module materialization, descriptor generation or observer context
changes. A provider-only change invalidates affected native products/edge
receipts; a host/frame protocol revision invalidates the whole dependent cohort.
The [[file:../../../toolchain/studies/compilation-unit-artifact-contract.org][artifact invalidation owner]] still
defines construction keys; this record does not create a second cache authority.

*** Unresolved Work Has Named Owners
:PROPERTIES:
:ID: cf735934-c846-57ea-8e9d-195d3971315e
:CUSTOM_ID: unresolved-work-has-named-owners
:END:

| ID | Owner and concrete missing work | Selected decision that does not wait on it |
|-
| U01 | Gambit compiler: complete HostGraph/FrameSpec/primitive and c-intf extraction | One semantic producer; no new service-side language semantics |
| U02 | C-provider owner: actual local GCC 16.2 attribute/target support, all emitted required exits and final C artifacts | Reject plain-return fallback in D1-H; refactor C exit generation |
| U03 | LLVM-provider owner: exact target ABI/attributes and final native tail edges in both directions | Uniform target C ABI, no private D1-R register convention in this cohort |
| U04 | Common product owner: configured C layout correspondence, HostId/point mapping and declarative object emission | New module/host product; no whole-old-emitter or C-packaging forwarding |
| U05 | Compiler/runtime join: every frame kind, liveness, descriptor and relocation-safe optimized resume | Reuse Gambit collector/continuation semantics, qualify a new producer |
| U06 | FFI/runtime entry owner: complete site effects, marker/catcher and nonlocal resource paths | Preserve supported nested foreign calls; no arbitrary new thread entry |
| U07 | Module/init owner: exact primitive/C/Scheme two-stage ordering, recursive init, errors and failed-attempt policy | Replace early done marker with explicit progress and failed-owned state |
| U08 | Runtime owner: roots during materialization, payload-specific publication, storage retention/drain and cleanup join | One existing metadata/registry/lifetime owner, no second module lock/collector |
| U09 | Platform/provider owners: final Darwin object/link behavior, generated constructor effects and any arm64e ABI/authentication | Native AOT product with declared platform scope; old THUMB2 is not an implementation |
| U10 | Integration owner: E01-E12/A01-A08 closure, BC semantic controls and N-series work/time/memory/maintenance observations | Structural refactor and retirements remain the design objective, with no claimed runtime success or speedup |

These are implementation and qualification tasks for a later authorized phase.
They are not reasons to preserve every old C path beneath a new wrapper. None
has been implemented, probed, tested or timed by this document work.

Rows below are evaluated from SysML. Formal routes locate proposed replacements; they do not assert existing native implementation.

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| overlap-authority | duplicate physical slot identities and duplicate scan writes | one owner transaction per reserve and unlink; O(n) reference overlap search | all allocation and view authorities participate; current native retirements zero |
| lost-reply | duplicate allocation registration and premature source release on retry | one stable operation record per request; exact query; replay tombstone storage | same request identity; no process-crash recovery promised |
| source-writer | holding source after a proved independent copy is covered | alias path blocks writes for full lifetime; copy adds roots and storage | copy branch inherited only from parent; not proved in new product |
| parallelism | serial preparation of disjoint rooted candidates | serialized metadata mutation and contention; no fairness guarantee | only preparation outside lock; physical non-overlap and isolated root slots proved |
| cleanup | processor-local cleanup guessing whether shared header is live | VM owner drain and retained unknown-result work | cleanup_rc bypass must retire only after all exported callers migrate |
| language-choice | duplicating registry ownership across C and Zig | Zig would still need allocator index GC bridge transaction ledger and FFI admission | no demonstrated incremental Zig benefit over shared modern C contract |

** Memory

| key | publication | observation | obligation | overhead |
|---+---+---+---+---|
| mutex | initialize candidate outside owner lock under scan-visible source root | lock owner then revalidate revision generation extent and request identity | no Scheme callback allocator or GC safepoint while holding index lock; unlock synchronizes later successful lock | short serialized reserve commit unlink operations |
| publication | single owner transaction publishes immutable descriptor plus root-cell registration and result | scanner and lookup use same lock or proved acquire-load pinned snapshot | release/acquire only publishes initialization; does not pin storage or synchronize moving GC cell writes | bundle root plus descriptor pin and GC round participation |
| CAS-alternative | CAS whole pinned snapshot with exact expected revision | failed CAS updates expected; inspect only after acquire and lifetime protection | cannot CAS separate list root and receipt independently; retry overlap check; no weak CAS failure interpreted as rejection | snapshot allocation retries reclamation and possible contention |
| settlement | same owner transaction validates exact lease then removes occupancy and records completed result | old or duplicate token returns already-settled or stale without decrement | never decrement then independently record; cancellation no nonlocal exit inside commit; stable owner retains unknown outcome | one exact ledger mutation no blind counter decrement |
| generation | close drain unpublish grace then advance checked generation | all old keys and operation receipts compare complete identity | generation is not index revision or semantic payload version; exhaust refuses new issuance | checked counters tombstones delayed reuse |
| GC | candidate source pin precedes first movable allocation; descriptor registered before visible publication | one canonical physical slot per round; GC updates through registered cell | alias metadata immutability does not make root cell immutable; no duplicate scanner writes | root enumeration pin scan ownership; integration unresolved |

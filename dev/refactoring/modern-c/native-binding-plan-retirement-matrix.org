** Claim

| key | mechanism | condition | result | gap |
|---+---+---+---+---|
| elide | Unobserved metadata projection | Complete observer and writer closure; no fault-prefix change | Readonly both loops may remove two demand writes | Whole-source and all exceptional observations OPEN |
| preserve | First logical normalization outside emitter | Same cut and alias-visible state; no intervening writer | Second normalization can be removed by exact value algebra | Moving first effect is not eliminating it; no rollback by assumption |
| reentry | Pinned plan and generation-scoped operation | Retry distinct from genuine repeated execution | Stale resume rejected; new operation gets new output context | Rejecting legacy unrestricted continuation is admission change, not equivalence |
| errors | Typed deferred fault at equivalent cut | Original order and visible byte prefix established | No success receipt for partial or unknown output | OOM timing and actual host argument order OPEN |

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| elision | 2P late table lookups and metadata setters; P=455 suggests 910 helper uses in matching artifact generation | P owned plans; two readonly consumers; certification and lifetime costs | No alias observer or intervening writer; lookup/encoding work may move to planning |
| preserve | At most P second metadata normalizations after first retained | P logical first effects plus plan ownership | No intervening mutation and exact list-value equality; physical identity not automatically covered |
| allocation | Repeated transient tuple/name work may be shared | Owned name/label/index plus O(P) plan and O(C) byte verification | No measured allocation or speed saving; OOM order needs separate semantic choice |
| incremental | Stable immutable binding result can be reused across consumers | Keys include header role cut, generator, ABI, target and session-affecting inputs | No mutable cell/address identity in persistent key; invalidation and complete writer closure external |
| net | Duplicate lookup/encoding work D plus certified redundant setters W | Plan K + ownership S + verifier V + qualification A | Positive only if D+W>K+S+V+A; modern C23 baseline; not person-days |
| darwin | No direct compile-time saving established for same C bytes | Toolchain capability admission and native artifact reuse design | Do not infer reduction of macro expansion or GCC cold latency from helper counts |

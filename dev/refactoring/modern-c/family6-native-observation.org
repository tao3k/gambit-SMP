** Gate 2 translation validation by emitted unit
:PROPERTIES:
:CUSTOM_ID: gate2-translation-validation
:END:

Feeley and Miller describe PVM as a bidirectional contract between the
front end and target, including calling conventions, primitive operations
and coordinates in logical frames. The modern Gambit implementation has
a concrete evidence cut at =c#compile-program= in =gsc/_front.scm=.
It dumps GVM from =module-procs= and then passes those procedures to
=target.dump=. The output path is scoped to the attempt. A single
invocation captures both artifacts before either can be replaced by a
subsequent emission.
[[https://www.iro.umontreal.ca/~feeley/papers/FeeleyMillerLFP90.pdf][Feeley and Miller, PVM, section 2]].

Translation validation checks a particular source-to-target result.
For Gate 2, the proposal is a local refinement check over seven legacy
obligations. Write the review key as
=(Make generation, emitter, input closure, unit, invocation)=.
GVM and generated C share this key, and the new C must match the
retained Make C byte for byte. The Scheme operands and GVM control
edge identify the operation. A local simulation then relates GVM
frame slots to the C stores, retry descriptor and return successor.
The comparison must preserve both the committed effect count and the
frame interpretation at every intermediate label.
[[https://weizmann.esploro.exlibrisgroup.com/esploro/outputs/conferenceProceeding/Translation-validation/993262143603596][Pnueli, Siegel and Singerman, Translation Validation]].

| Boundary | Witness | Separating control |
|----------+---------+--------------------|
| Front end to GVM | Bound Scheme expression, procedure, branch origin, operands, callee and successor with the live slots | Two repeated =new-ref= calls with the same arity but different source operands |
| GVM to C | Label trace, ordered lowered stores and adjustments, enter pressure and retry/return continuations | Identical callee and return shape with a different store footprint or a retry label alias |
| Emitter to handler | Pre-enter stores backed by the old frame map; demand consumed in the old view; grant and first write use the independently unwound view | A stale saved handler cursor that still falls inside the same numerical interval |
| C to image | Final Make C/object proof, selected archive member, handler compile closure and image identity | Same C replay with a substituted object, or an image from a different source lock |

The five =_prims= obligations share one unit replay and require five
distinct operand/control reviews. =_ptree2= contributes F6-20-6 and
=_eval= contributes F6-20-7. Review the GVM procedure, source location
where available, block and return provenance before tracing the C
spans. C direct-call ordinals supply search leads only. With
=gsc/_t-c-2.scm=, trace =targ-gen-jump= and
=targ-gen-label-return*= back to demand and spill emission. Apply
=FrameContract.preEnterSpillNeedsOldExtent= to the old-frame slots.
The existing Native Witness obligation still requires independent
saved, unwound and first-store cursors and one settlement.

* ASCENT and repair

=rest-native-observation.rules.ss= is a typed native ASCENT fragment. It derives
=rest_violation=, =rest_missing=, =rest_observed_cut= and =rest_repair_target=.
Keys include exact image, spelling, case and a digest of the native stream and
command. Different commands/attempts cannot fill each other's gaps; conflicting
counterevidence dominates support for the same obligation. There is no Python
inference fallback or fixed repair/retry sequence.

Reports retain the first observed failed contract, bounded witness addresses
and values, complete measurement counts, raw event-span references, terminal
state, source/runtime identity and archived rule digest. Large snapshots remain
in =rest-observation.bin=; ASCENT receives checked obligations rather than huge
snapshot tokens. Normal aggregate reads verify artifact hashes, recompute the
measurements, and reject a retained ASCENT verdict or repair target that
disagrees with those measurements. Evidence reads never start a producer.

For an existing successful checkpoint, the reader follows the exact recorded
origin run, step and committed step digest, then validates its original raw
artifacts and contract. It reports =executionReused: true= and
=executionLaunched: false=. Historical evidence is not relabeled as a new
execution, and missing or substituted origins cannot trigger an implicit rerun.

Only complete matching inference yields =OBSERVED= for the selected cut.
Violation yields =VIOLATED=; missing premises or inference yield =INCONCLUSIVE=.
Both fail the executable observation, regardless of matching stdout. The raw
diagnostic report is written before inference, preserving a crash or timeout
even if ASCENT's remaining deadline expires. Failures remain historical data.

separating observation, changed model premise, owner repair or affected Make

=executionAuthorized: false= does not prohibit the user's separately authorized
work. The hosted compiler repair adapter does not grant unrelated runtime

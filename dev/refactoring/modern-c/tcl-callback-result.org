** Responsibility retired and benefit mechanism

Command existence no longer stands in for callback lifetime. The real callback
pins its existing RC owner before payload access, carries stable native identity
through generated pointer/string conversion and marker allocation, then reloads
the Scheme vector from the GC-updated RC cell. Normal return releases that owner.
Nested deletion drops the command owner while outer and inner callbacks keep
their own roots. This replaces the unsafe ownership premise; it does not merely
insert a check or increase heap/wait limits.

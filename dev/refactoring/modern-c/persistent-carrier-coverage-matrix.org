** Identity

| key | structure | rule | caveat |
|---+---+---+---|
| owner | VM SourceSlotId + owner generation | Register complete immutable descriptor and root before exposing source lookup | Current context RC list is not such a descriptor |
| writer | SourceId + WriteOperationId + candidate root | Accepted writer survives close; keyed completion cannot target next operation | Unbounded abstract IDs do not prove finite native overflow |
| payload | Semantic payload generation | Frozen for source pins; old target carries independent prior generation | GC relocation does not increment this semantic generation |
| round | CollectorRoundId + root descriptor generation + scan owner | Refresh round receipt after GC; do not equate with payload generation | Task completion is not by itself source admission |
| target | CarrierId + bound payload generation | Old carrier remains rooted if new source payload is installed | Backing storage and module/context grace still require owners |

** Memory

| key | publication | observation | obligation | overhead |
|---+---+---+---+---|
| register | Initialize private slot and descriptor then release publish | Acquire frozen census before dereference | No GC gap: source pin until target membership known | Descriptor, root slot and generation |
| scan | Freeze membership and root mutation under collector protocol | Claim exact descriptor generation and round | mark_array writes moving slot; release completion only after last use | Per-round update plus task claim |
| close | Atomic admission transition active to closing | Acquire validation prevents accepted late borrow | Accepted before close drains; closing remains in census | Lifecycle state and counters |
| retire | Registry unlink only after scans, users and observers drain | Acquire all last-use decrements and completed round cut | No count-to-zero check separate from close; prevent ABA reuse | Grace period and identity tombstone |
| payload | Setter serialized with source pins and GC freeze | Consumer reloads registered slot after GC | Atomic metadata does not make arbitrary SCMOBJ mutation safe | Rooted candidate and source write authority |
| unknown | Keep descriptor and backing owner in durable live registry | Exact keyed resolver observes commit or safe abort | Timeout is not evidence of nonpublication | Retained memory may be unbounded without resolution |

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| processor-retirement | No need to keep an entire processor alive solely for carrier roots | Independent VM carrier descriptors and census | Only after backing storage and all nonroot dependencies transferred |
| repeated-handoff | One persistent registration rather than per-GC deregister/reregister | One scan per live slot per round remains | Lifetime spans multiple rounds; native fidelity required |
| classified-scan | N_RC minus N_payload slot visits per round | Classification and descriptor indexing | All unknown/native ABI users retain conservative fallback; duplicates deduplicated |
| revocation | No global shutdown guess or repeated rediscovery of alias ownership | Close/drain/observer bookkeeping and retained unknowns | Authoritative writer and borrower closure |
| modern-c | Common generated root/scan/lifetime contract usable in C23 | GC protocol, metadata and proof maintenance remain | No Zig dependency required for these semantic benefits |
| zig | Potential safer local storage and typed ABI generation | Second compiler/runtime ownership model and FFI integration | No demonstrated elimination of necessary root protocol; net advantage unresolved |

** Cost

| key | avoided | added | positiveCondition | boundary |
|---+---+---+---+---|
| persistent-handoff | C*(K-1)*H | C*P + K*C*E + R | avoided > added | H is not shown to be paid each round in current source; required slot updates remain |
| classified-roots | K*(N_RC-N_payload)*visit_cost | classification + index + grace + unknown_retention | avoided > added | Unknown native clients retain conservative roots; duplicate new and old scans can make savings zero |
| processor-release | Retained processor-only bytes and lifecycle coupling | Descriptors + target backing + grace retention | All other context/arena users independently settled | No measured byte estimate; source can_retire rejects RC without a freeze receipt |
| zig-increment | Concrete support actually retired relative to mandatory modern C | Additional compiler + interop + duplicate ownership support | Retired support exceeds new support while preserving contracts | No positive language-specific net benefit established |

** What was solved, and why this is a responsibility replacement

Before the change, native lookup and later creation could both succeed for
two concurrent calls of the same name. Insertion-only locking cannot fix two
earlier misses. One service transaction now owns lookup/recheck, permanent
construction, bucket/NEXT/count, rehash and anchor publication. Native reverse
walks and the actual TTY callback use the same topology authority. GC captures
owned cells, marks outside the gate and conditionally returns moved values;
it cannot overwrite a newer permanent publication with a stale captured anchor.

The falsifiers are concrete: duplicate native identity/count, an intermediate
NEXT topology observed by an admitted walker, or stale mark writeback. The old
factory counterexample and stale-writeback mutation are rejected while current
C passes. This replaces split authority and a borrowed mutable root address;
it does not assert that adding a mutex alone solves all SMP architecture.

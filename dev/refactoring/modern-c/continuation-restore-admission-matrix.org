** Claim

| key | mechanism | condition | result | gap |
|---+---+---+---+---|
| R-span | Prove B<=R<=H from same-block ordered frozen endpoints | All generated stack writes and break restoration preserve provenance | Conditional symbolic theorem | Legal Scheme full trace and external FFI aliases remain open |
| quarter | R<=quarter reserve is an additional property | No universal trimming across explicit and heap GC entries was found | Cannot certify quarter fit for all legal Scheme from current evidence | No source-qualified legal-input counterexample; numerical implication refuted only |
| policy | Check R plus execution headroom at freeze | Shared when it fits, otherwise preserve initial stack as dedicated | Avoid late fatal fallback by planning before setup | Dedicated plan must also reserve global copy-space and pool capacity |
| enforcement | Authorize every later heap fallback from immutable plan | No R or section identity change until restore completes | A preflight observation alone is insufficient | Native hook and writer closure plus C11 refinement open |
| failure | Reject or retain before parity flip | All old members consume same immutable outcome and acknowledge | No coordinator-only return or new Scheme execution while frozen | Stable exception handoff and emergency headroom remain open |

** Memory

| key | publication | consumer | gap |
|---+---+---+---|
| freeze | Last source pointer write happens-before owner acknowledgement | Coordinator acquire observes fp/break/source section as one frozen view | Ordinary reads only after writer exclusion; per-field atomics insufficient |
| plan | Initialize manifest and per-member reserve policy then release publish | Every member acquire same generation and digest | Generation reuse prohibited while readers or late receipts exist |
| fallback | Acquire plan or hold owning epoch before changing heap/stack limits | Allowed sharing cannot shrink below committed K | No extra global atomic per copied word required |
| failure | Publish rejected result release; acquire consumption and last-reader ack | Old roots retained until all acknowledgements and result delivery | Unknown is retained, never timeout-forged completion |
| restore | R/source identity pinned through weak completion and move_continuation | Restore completion precedes authorization to resume context | C11 native adapter and callbacks not refined by sequential QNT |

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| shared | Use original heap borrowing for short active segments | O(P) length/provenance checks and plan records | R+headroom fits shared reserve and total heap capacity independently sufficient |
| dedicated | Reuse initial stack instead of allocating another section just for restore | Forbid fallback; surrender up to current shared heap quota per protected section | Net benefit only if avoiding extra storage/failure outweighs lost heap capacity |
| pool | At most eligible stack sections contribute fallback visits | Recompute actual N and actual eligible count | L<=N remains conditional; no credit for removing existing allocation lock |
| reject | Prevent partial parity flip for unsupported plan | Collective latency and retained resources on unknown results | No speedup claim; do not map rejection directly to an allocating Scheme exception |
| modern-c | Explicit runtime contract replaces implicit quarter assumption | Plan issuer, guard coverage and generation reclamation support | Zig is not needed to express these contracts |

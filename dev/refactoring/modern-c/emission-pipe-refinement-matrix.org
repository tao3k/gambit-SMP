|---+---+---+---+---|
| direct-exclusion | Selected typed scalar output and stable built-in hook | No payload/type/predicate mutation | No direct VAR/PTREE special branch in emitter interval | No global absence-of-callback theorem |
| cursor | Concrete read/expose/rebase/publish actions with ghost character counts | Peer primed after escape; exhausted no-carry branch, retained peers, successful allocation and bounded counters | emitted-delivered equals wlo+whi-rlo across any modeled replay | General carry-over, faults, compiled roots and actual identities still external |
| resume | Saved local index restored; current buffer generation retained | Capture at selected timeout continuation | No stale write to the old cached full buffer after drain | Captured old buffer may remain a GC root even when not used |

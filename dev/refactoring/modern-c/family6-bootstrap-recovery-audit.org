* Findings

1. The generic =source-regenerated core was not established= message loses
   the actionable compiler diagnostic. Inspect the first native error,
   not only Make's final =Error 2=. The read-only =research --read= summary
   now exposes the original log line and hash after validating its receipt
   binding; a changed log is explicitly unverified. This needs no rebuild.
2. Transport preflight and real Scheme emission are different cuts. The
   small C-copier fixture passes in these later attempts but cannot prove
   return-address geometry, label class/numbering or syntactically valid
   emission by the actual GSC. The initial string/Path preflight defect
   was a framework mistake; current code normalizes that digest argument,
   and its managed regression now supplies the real string-valued API.
3. Checkpoint reuse is empty in completed attempts 19 through 25. Five switch
   executor identities. Source-lock and patch bytes also change between
   21/22, 22/23 and 24/25. This is not seven retries of one identical native
   input. Existing checked import must distinguish executor compatibility
   from a real producer change; removing the same-executor guard would
   manufacture reuse, not solve it.
4. The audited pre-repair =source_core_resume= was a second, weaker reuse path. Its cohort
   pointer does not bind a source lock, profile, compiler identity or
   authenticated successful phase. It returns a directory without using
   the existing artifact/lease import checks, replaces =gsc-boot=, and
   invalidates C/objects only when their C text contains =___LBL()=.
   It also skips the ordinary retained-generation Scheme-inventory check.
   An isolated unit control accepted a path outside its fixture control
   root and retained an old unmarked C/object after installing a different
   emitter. This proves a helper-level gap, not a tested production custody
   exploit. It does not prove that this gap caused every observed failure.
5. The frame and label errors remain unlocalized. An unknown label class
   may reflect emission logic, mixed generations or runtime corruption;
   the current message alone cannot distinguish them. Do not weaken the
   return-frame rejection or replace an unresolved label with a dummy.

Recipes and arbitrary Evidence selectors, rather than a prescribed retry list:

- Distinguish loading the interpreted compiler, preprocessing the selected
  module, frame/demand transformation and C emission. Select or reduce the
  smallest source input that preserves the observed failure.
- Locate the first heap exception before the REPL exception hook; preserve its

  Determine whether the pinned interpreter, current compiler sources or their
  interaction owns it. Do not infer the responsible source from exit 0.

  Keep its original failed receipt; another output name is no causal change.

  synthesize generated C or treat a REPL exit as successful emission.

observations can be composed without a new Python whitelist; actual producer
descendants retain custody and prior-attempt guards. Raw receipt-bound log

the model. Empty output allocation is a generic lease-owned state transition,
not a per-module rename script. The three cuts are defaults; a model may choose
another explicit locked =lib/_NAME.scm= through the same capability.

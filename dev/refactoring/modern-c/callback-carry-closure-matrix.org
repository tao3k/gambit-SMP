** Claim

| key | mechanism | condition | result | gap |
|---+---+---+---+---|
| counter | c=rhi-rlo; b=wlo; h=whi; shared next | b becomes b-rlo; whi becomes h+c; rlo becomes 0 | Post-minus-pre pending expression equals c; payload concatenation preserves bytes | Not a public bug claim; other caller/FFI reachability and counter semantics open |
| no-carry | four direct reader guards | Valid rlo<=rhi and unmodified locked state | c=0 at fill, recovers preceding no-carry conservation | Aliases, injected methods and reentrant/FFI mutations not closed |
| roots | capture may retain input string, port, writer, old buffer and dynamic environment | Lexical locals identify candidates, not live GC slots | Return/field zapping is insufficient for release; multi-shot capture retains custody | Generated program points, saved registers and map coverage unresolved |
| failure | FIFO advance and wlo update precede append allocation | Allocation failure or escaping callback at intermediate point | No full rollback/equivalence claimed; old and next storage need continued custody | Actual OOM/GC exception timing and compiler roots require refinement |
| retirement | one immutable native binding plan | Same entry, canonical writers, admitted transitive closures and fault prefixes | At most one second helper per qualified binding can disappear | Current qualified bindings=0; first demand still required |

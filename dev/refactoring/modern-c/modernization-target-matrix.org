* Six architectural replacements
| Decision | Canonical owner | Target | Lesson | Replacement | Retirement | Benefit condition | Added cost |
|---+---+---+---+---+---+---+---|
| semantic | dev/architecture/compiler | GVM-to-native semantic contract compiler | PVM paper: front/back cooperation exposes representation, calls and target knowledge | Scheme owns FrameSpec/PointId/ModuleSpec/EffectSpec/AllocationSpec; generate typed C functions/tables and explicit ABI | Retire duplicated semantic macro emission and layout decisions after all generators/runtime consumers use the schema | Count repeated preprocessing/compile bytes and semantic decisions eliminated; no new language runtime required | Schema/compiler bootstrap cost and an ABI rebuild; simple C portability macros may remain |
| domain | dev/architecture/runtime/execution | Execution, participation and collection carriers separated | OCaml parallelism paper and domain/backup-thread source: GC participation is an explicit protocol | VM owns membership/heap epochs; ExecutionContext owns Scheme state; GCParticipant freezes roots; CollectorWorkContext owns scan work independent of OS/PSTATE lifetime | Retire implicit PSTATE ownership of collector queues, allocation state and cleanup after exact producer/consumer/lifetime replacement | Reduce owner-dependent GC callbacks and repeated membership reconstruction; measure contention and pause population | Root snapshots, epoch bookkeeping and scheduler/worker coordination; no universal dead-thread recovery |
| heap | dev/architecture/runtime/gc | Generational heap with precise publication and mutation | OCaml paper compares concurrent minor/read-barrier design with parallel STW minor; learn the tradeoff | Context-local nurseries, shared mature heap, parallel STW minor, generated remembered writes and explicit promotion budget; isolate major algorithm behind heap/phase contract | Retire full mature-graph minor scanning only after all roots, continuation/denv/FFI writers and sparse/promotion layouts close | Minor work = young live + remembered edges + roots; savings require avoiding mature scan beyond barrier/promotion overhead | Remembered sets, barriers, survival/promotion copies and reserve peaks; mature moving/nonmoving and concurrent major remain open choices |
| control | dev/architecture/runtime/control | Continuation-centric control and scheduler boundary | Effects paper makes suspension/resumption a runtime concern; Gambit already has stronger multi-shot semantics | One precise frame/root format for running, captured and resumed computation; persistent or copy-on-write captured frames; one-shot optimization only with proven use | Retire carrier-local C control assumptions after repeated resumption, dynamic-wind, exceptions and supported FFI escapes are preserved | Reuse captured immutable graph across minor GC only with complete mutation evidence; direct-style scheduling without rewriting Scheme | Frame ownership/COW bookkeeping, remembered mutations and handler/FFI boundary cost; do not impose one-shot restriction |
| foreign | dev/architecture/runtime/ffi | Root-safe native activation and effect/resource ownership | OCaml source separates blocking leave/reenter and GC service; Gambit needs its own continuation-aware contract | RootRegistry before allocation; generated native entry plans; park/freeze/reload; VM-owned outcomes and effect-classified release tasks outside collector critical phase | Retire raw marker-only lifetime, ad hoc root choreography and inline arbitrary release only after whole real caller coverage | Remove duplicated per-entry ownership logic and avoid waiting for blocked owner in collector phase | Stable roots, task custody, resource affinity and root-aware resumption; unknown unregistered writers still require refusal/retention |
| build | dev/architecture/toolchain | Semantic artifact graph and native compilation boundary | PVM separation plus existing build research: interface programs and dependency-aware products, not command wrappers | Scheme frontend/session -> semantic module artifacts -> generated C/runtime ABI artifacts; phase-ready dependency DAG, stable snapshots, incremental/parallel scheduling and reusable AOT interface programs | Retire repeated expansion and regenerated/recompiled unaffected units after clean-versus-incremental observational equivalence | Unchanged/leaf/macro-change work counts; whole build latency and C parser work under existing caps | Dependency/snapshot storage, artifact validation and unavoidable state instantiation; LLVM/MLIR adapters consume contracts, Zig optional |

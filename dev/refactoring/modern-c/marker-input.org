** Conditional correctness and counterexamples

Assuming a valid active owner and no nonlocal escape from allocation, native RC
allocation/registration and installation are noncollecting. A successful borrow
fixes logical identity while allowing the collector to update its address. No
domain mutex spans GC. Reload after allocation initializes the marker from the
current address. Returning the loan and then releasing the native reference
balances every returned outcome, including controlled vector refusal.

A predecessor control must use the original scalar procedure and real moving
GC; observing a stale marker field is sufficient and must not dereference stale
memory. Root and borrow counts are real observers, never modified to create a
failure. Controlled allocation refusal proves only that returned branch, not
general OOM capacity. Unknown/nonlocal outcomes remain unqualified.

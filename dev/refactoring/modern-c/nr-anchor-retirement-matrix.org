Safety-model closure does not certify native caller coverage, C23 execution or performance.

** Gain

| key | saved | added | condition | status |
|---+---+---+---+---|
| parse-closure | no invented token on successful parse; real conditional producer now known | caller slot and parse-buffer cleanup are separate; post-publication failure still needs escrow | normal error-token path and initialized caller slot | source-bound |
| nr-transfer | reuse existing callback data[0] normal ownership rather than duplicate snapshot | O(I) independent records only for I admitted in-flight/unknown callback scopes | normal return plus native-abandonment policy | conditional |
| stable-query | retire settled heavy records without retaining every complete payload forever | process-lifetime typed-ID resolver/slot generation; outcome history only when promised | retired-or-unknown API allowed; no permanent successful-result lookup promise | design-only |
| unknown-pop | 0 queue-empty based owner retirement; 0 blind snapshot/node retry | unknown token/node/provider custody may be indefinite | proof of native consumption and final node release | conditional-model |
| runtime-retirement | 0 runtime paths retired; no native speedup measured | resolver, exact-operation adapter and full coroutine product remain | all native refinement obligations | design-only |

** Issuer

| key | source | signature | gap |
|---+---+---+---|
| parser-caller | parse-caller | initialized stable out slot; receive produced error token after normal producer return | callee may publish then abandon during reparsing |
| nr-dispatcher | nr-pop | queue node custody transfers to in-flight callback before proc invocation | raw C local alone is not abnormal-exit escrow |
| snapshot-owner | expr-endpoint | known Restore/Discard endpoint plus node completion | token consumption and node free are separate irreversible effects |
| query-resolver | previous-record | live typed-ID anchor; validate generation and pin record before returning address | no code implements proposed InvocationId resolver yet |
| retirement-owner | delete-env | combine closed senders/deliveries, lookup gate, old pins and source/result detachment | normal queue/panic guards are not complete native receipts |

** Obligation

| key | status | condition |
|---+---+---|
| anchor-safety | conditional-model | typed ID resolved through live process anchor; old record pinned under same lookup authority |
| parse-chain | source-bound | same immutable Tcl commit/blob now supplies missing producer and initialized caller endpoint |
| nr-custody | conditional-model | pop transfers to in-flight duty; known token consumption and node disposal before done |
| native-abnormal-exit | unresolved | foreign escape after pop or token consumption needs independent node/token custody and exact receipt |
| anchor-implementation | unresolved | live resolver before raw access, generation no-wrap, raw route exclusion and C23 orders |
| coroutine-product | unresolved | caller Env versus coroutine Env identity and all nested rewind/delete paths refined |
| record-detachment | unresolved | sender closure includes delivery drain; results and external observers detached before retirement |

** Complete replacement, not additional patch configuration

The private =___for_each_symkey= name remains. One checked permanent-identity copier
serves the Scheme owned view and the native snapshot. The count, noncollecting native
allocation and copy occur in one existing global-gate interval. Every callback runs
after unlock, borrowing only permanent identities; the snapshot is freed on normal
return. No bucket/NEXT address escapes the interval. The sole production consumer,
TTY =complete_word=, now checks BOOL refusal before editing input or using completion
storage. Its actual pure name fold preserves order. The previous callback-spanning
lock/raw-chain borrow and separate unchecked native walker retire together.

This removes a callback-to-registry lock dependency and permits declared callbacks
to intern, reenter snapshots and collect. This does not claim that the old restricted
pure TTY caller already caused a demonstrated corruption. Live global owner and
normal callback return are explicit premises; nonlocal C escape, global teardown,
foreign cancellation and dynamic C-closure lifetime require separate replacements.

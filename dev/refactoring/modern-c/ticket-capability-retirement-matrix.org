** Identity

| key | structure | rule | caveat |
|---+---+---+---|
| ticket | SessionNonce + DomainId + Generation + AttemptId | One terminal outcome per complete key; immutable payload binding | A slot, object address or payload hash is not the key |
| capture | CaptureDomainId + CaptureId + Generation | All derived raw copies or managed exports belong to a tracked lineage | Object inequality does not imply independent frame/denv authority |
| transport | OperationId + TicketId + immutable argument digest | Lost reply queries the same record; pending is not absent | Same payload does not identify semantic re-execution |
| resume | CaptureId + fresh AttemptId minted by external restore gateway | Each true multi-shot invocation gets a distinct ticket | Do not mint from a counter/token stored inside restored Scheme frames |
| handle | CaptureId + HandleId + Generation | Drop same handle is idempotent and does not release another handle | Managed handles do not count arbitrary Scheme/raw aliases |
| borrow | CaptureId + BorrowId + participant generation | Return one borrower; duplicate return cannot decrement another | Native participant roster and out-of-band aliases still require closure |
| scanner | RootDomain + ScanBorrowId + generation | Maintenance admission closes; admitted scans release by exact ID | Authority closure alone does not authorize root unlinking |
| terminal | Immutable outcome or non-reused tombstone | Late query returns prior outcome or a defined non-replay status | Physical tombstone reclamation and crash persistence are not proved |

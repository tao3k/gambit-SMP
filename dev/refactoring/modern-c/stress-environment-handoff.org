** Conditional net benefit and peak bound

Let U count valid environment-construction occurrences, not procedure entries,
hook calls, capture calls or continuation shots. In req1, entry-hook runs before
execute checks arity. A hook may return without execute, retain execute after the
entry returns, or invoke it repeatedly. Each valid execution creates a fresh
parameter location; invalid arity creates no ordinary req1 environment. Count
entry admission, execute attempts and successful environment creation separately.

Partition U closed environment lifetimes into E (never materialized), L
(deferred but later materialized once) and I (immediate generic representation).
Thus U=E+L+I. Let D count extra physical environment allocations beyond one
canonical result for each L/I lifetime; H is metadata allocation traffic. Use
alpha_elim=E/U and alpha_defer=(E+L)/U as different observations. Open or UNKNOWN
lifetimes are not E. A materialization whose return was lost counts physically
once when confirmed, not zero because its caller missed the return.

| Quantity | Conditional avoided work | Added work/capacity | Positive condition |
|----------+--------------------------+---------------------+--------------------|
| Physical allocation traffic | Baseline32*U versus candidate32*(I+L+D)+H | Actual metadata/padding H and duplicate physical attempts D | Net32*(E-D)-H >0; alpha_defer alone proves no elimination |
| Collector scanning | Actual eliminated RTE slot visits, measured per collection | Transient-root visits, remembered stores and materialization roots | Saved visits exceed added visits; root scan itself cannot disappear |
| CPU time | Measured eager work removed for E and deferred work amortized for L | Entry/hook admission, valid executions U, materialization for L, slot repair and exit | Matched net CPU after all terms is positive; do not subtract materialization twice |
| Physical peak | Live eager objects no longer retained, independently measured | Transient frames + materialized aliases + live UNKNOWN records + copy/restore reserve | Compare simultaneous live intervals and full-round maximum, not cumulative traffic |
| UNKNOWN custody | No valid allocation saving by abandoning uncertain state | Retained roots and reachable graph until definitive settlement | Bound retained lifetimes or report peak unbounded; no timeout-to-death inference |

The earlier32*(alpha*N-M) notation is superseded by this explicit lifetime
partition: counting deferred-but-eventually-materialized calls as eliminated
and charging their first materialization again gives an ambiguous benefit.
This corrects the cost model only; no raw allocation/native observation changes.
Alpha_elim=0 is a valid counterexample. Mandatory reflection can require generic
materialization on every call while admission still adds work. Heavy capture can
increase materialization and frame costs. Performance remains UNMEASURED until a
runtime-owned full implementation and matched native comparison exist.

retain their affected domain; they are not global authority to stop healthy VMs.

environment after an earlier result may already have escaped.

** Optimization admission and current decision :decision:

An active environment is not automatically a Scheme vector. Replacing only
macro-make-rte with a C stack pointer is invalid: macro-rte-ref/set!, parent
traversal, generic code-run, closed-field reflection and serialization consume
an ordinary Scheme object today. A nonallocating representation therefore needs
one complete interface lowering, not a constructor substitution or a new name.

| Admission question | Required guard / fallback | Present decision |
|--------------------+---------------------------+------------------|
| Can this entry use projected active slots? | Exact code/operator identity and complete FrameSpec/liveness mapping, including parent/self/argument; a symbol name or local interrupt mask is insufficient | No qualified lowering; ordinary entry stays |
| Can a caller invoke unknown Scheme/native code? | Publish one canonical rooted vector before crossing an unqualified consumer; preserve existing calls instead of rejecting programs | Dynamic consumer closure remains OPEN |
| Can a safepoint suspend or capture implicitly? | Cover scheduler/interruption capture and GC frame materialization, not only explicit call/cc; never disable interrupts to improve alpha | No complete observer/deoptimization adapter |
| Can a saved shot outlive its owner? | Shared lexical identity and canonical result stay in a rooted domain independent of carrier and wrapper; last-reader custody remains | Existing multi-shot semantics are the required control |
| Can failure return to ordinary execution? | Before publication, a complete source view permits generic retry; after possible exposure, resolve same identity or retain UNKNOWN | Production operation record/query implementation absent |

Scan accounting must count actual work, not just allocated vectors. For the
configured three-field RTE, a conditional interior saving is three pointer-slot
visits per eliminated live RTE per traversal, minus extra active-root, remembered
and metadata visits. Parent/self/argument reachability still has to be traced.
Transient projections may increase active-root slots from one vector reference
to several direct references. Copy traffic, root visits and peak live objects
must therefore be measured separately from procedure-entry and environment-construction counts.

The current decision is NO-GO for claiming or starting a cheap local
allocation-elimination REV on this evidence. GO for the complete source/root/
exposure contract and its ordinary native controls. A runtime implementation
proposal must first supply the whole lowering and credible eligible-lifetime
cost premise; otherwise retain the ordinary representation and continue the
independent SMP families on their own responsibility chain. This is not a veto
on modern C or an instruction to put interpreter optimization inside the shared
GC/scheduler REV. Historical+2.93-percent attribution remains a separate open item.

different label or a no-hit run cannot advance the saved-return obligation.

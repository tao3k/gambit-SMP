** Contract

| fromNode | toNode | custody | c11 | premise |
|---+---+---+---+---|
| initialize | READY | payload publication | release READY / acquire successful claim | Payload stores before readiness; forwarding alone insufficient |
| READY | OWNED | one object scan owner | atomic whole-word masked CAS | Queue task ownership is not object scan authority |
| OWNED | duplicate-return | retain first call frame | no ownership clear on mismatch | An OWNED loser may return while winner and descendants remain active |
| OWNED | DONE | own subtype field footprint | release completion only after field accesses | DONE excludes copier Tail and unscanned descendants |
| DONE | local-drain | retain derived work | active carrier remains until local queues/frontiers settle | DONE is not an idle or reclamation receipt |
| local-drain | idle | local no-debt condition | all last uses before mutex-protected decrement | All real producers must be roster-covered |
| idle | phase-terminal | zero active with closed input | one termination synchronization domain | Weak round and cleanup are distinct |
| copier-Tail | local-drain | separate first-field ownership | scanner and Tail footprints disjoint or synchronized | Frame link fixups remain an unresolved non-Tail writer |
| reset-cut | initialize | new round identity | quiescence before plain memset; no late stale task | Single-epoch model does not prove reset/ABA exclusion |
| READY | chunk-queued | initialized chunk publication | release visibility before queue read | READY alone does not transfer queue custody |

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| duplicate fields | At most D redundant field scans for D duplicate occurrences | D additional state lookups and one observation CAS call each absent interference | Savings only after actual duplicate source/footprint qualification; no throughput claim |
| unique object cost | One authorized field scan per object | Three state transitions; six CAS API calls plus three section lookups absent retries | Compare equally correct structural task uniqueness; object bitmap is not automatically necessary |
| scan metadata | No object header or frame coordinate expansion | ceil(ceil(n/2)/(B/2)) words per section plus round clearing; two-bit trailer | For aligned even sections and B=64: 1/64 full payload bytes; relative active half 1/32 |
| counter fusion | Avoid a second independent publisher counter | Retain copier owner call frame child work and final idle coverage | Every source producer synchronous and covered; no new physical-worker failure tolerance |
| modern C choice | Explicit ownership shared across pair/generic consumers | C11 atomics generation reset footprint and native proof remain | No Zig-specific saving established; code-generation language does not prove GC closure |
| typed atomic observation | Replace six CAS API calls per unique object with three loads plus three transition CAS on no-retry path | Explicit atomic storage and observation success/failure ordering; retries remain | Proposed modern C service only; global legacy CAS macro replacement is inadmissible |
| validated scan coordinates | Potentially remove repeated 3U+D section lookups | Section epoch header bounds trailer mapping and queue-transfer validation | Allocator and chunk producer issue coordinates; stale coordinate refusal required |

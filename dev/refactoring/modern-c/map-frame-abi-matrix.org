** Impact

| key | trigger | semantic | native | runtime | retirement |
|---+---+---+---+---+---|
| liveness-content | Changed map body or successor roots, unchanged wire schema | Recompute affected procedure plan and semantic dependency consumers | Re-emit/recompile changed module and true inline/dependency consumers | Reuse unchanged decoder; retain old module descriptors/code for live saved frames | Do not rebuild whole runtime just because a mask value changes |
| frame-wire-schema | Changed tag, bit width, slot interpretation, internal saved-register or OFD rules | Reuse only a proven target-independent semantic projection | Invalidate matching emitter/decoder/runtime/loader/native ABI cohort | All readers must agree; old frames require old decoder service or proven migration, otherwise reject activation | Old descriptor decoder retires only after old GC/capture/restore/label users close |
| target-physical | Changed word size, alignment, register allocation/call/root representation | Target feedback can invalidate normalization, primitives and GVM; never assume frontend reuse | Rebuild affected layout and code plus runtime ABI consumers | No mixing old saved frames with incompatible collector/restore representation | Portability remains parameterized; no universal cross-architecture saved continuation |
| native-tool | Compiler or service upgrade with demonstrated unchanged semantic/layout contract | Keep admitted semantic and emission products | Invalidate affected object/link recipes; ABI-changing flags reclassify as target-physical | Keep installed live cohort; tool identity is not runtime compatibility proof | Retire repeated frontend work only with dependency and output equivalence |
| no-change | Exact demanded projections, trace and output manifests stable | Zero admitted semantic producer executions; fresh stateful instances still cost | Reuse matching emitted/object/link products | No runtime layout replacement required | No timestamps or same file names as reuse authority |

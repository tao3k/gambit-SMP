#+OPTIONS: toc:2

* Delivery boundary
:PROPERTIES:
:CUSTOM_ID: tfib-a-spec
:FAMILY: 6
:STATE: OPEN
:END:

Deliver one production responsibility: carry a rest construction attempt
from its authorized caller and committed heap frontier through GC, if
required, to a complete reservation and one delivery or an explicit
refusal. Ordinary rest, keyword-rest and rest-keyword share this authority
chain. Changes may be staged for review. A is accepted as a unit only.
The existing [[file:tfib-construction.org][TFIB construction order]] owns
the B and C responsibilities and the original family gate.

The retained diagnostic GSI demonstrated one GC, one reload, one READY
claim and one body entry for each rest spelling, and simple join results.
Use that image as historical diagnostic evidence. Its reported hash and
positive observations do not bind the present worktree or prove no writes
on a short grant, sustained TFIB completion, or any throughput gain.

[[file:../../../evidence/research/retained/modern-c/stress-gsi/dev-tfib-a-production-audit.json][Independent production audit]]

Source review during this handoff found that the walker now drops the
previous gate before reacquiring the allocation lock, the heap-limit path
preserves hp on the new near-limit GC branch, and the allocator lock covers
capacity check plus section claim. Those changes narrow the open cuts to
the lifetime gap, authorization of that GC branch, settlement of a claim
that fails final extent validation, and independent probe ownership.
The entry probe still writes a sentinel from shared diagnostic state.

* Attempt authority and transitions
:PROPERTIES:
:CUSTOM_ID: tfib-a-states
:END:

Use the existing VM/context and rest activation identities. Bind VM
incarnation, context and attempt generation, source half and logical span,
configured return descriptor, registered roots, repaired epoch and
destination interval. A read lease preserves storage and records the
logical bound. A destination grant authorizes a full write footprint.
Preserve the currently committed heap frontier across either operation.

| Transition | Owner and publication point | Failure custody |

Publish the precise caller and whole argument/key window in the existing GC root domain. The source retains custody until target installation is confirmed. | Refuse stale or unknown authority before access. Keep a valid mapped caller and any unacknowledged roots. | Reserved → initialized → delivered | The admitted context alone writes the whole batch and publishes the committed frontier. READY, tail entry and actual body entry have separate evidence. * Implementation sequence
:PROPERTIES:
:CUSTOM_ID: tfib-a-implementation-sequence
:END:

** 1. Put first reads under a source lifetime protocol

Inspect =___rest_caller_chain= and =lock_source_stack_frame= together.
The allocation lock protects section-map membership; the section gate
protects the short descriptor/link access. All acquisition paths use
=ALLOC_MEM_LOCK → section gate= and never reacquire the allocation lock
with a section gate held. Avoid nested section gates. Hold logical source
custody across a break without holding a gate across the handoff. Reuse a
validated frozen root or source pin if it already prevents retirement;
otherwise add bounded custody to the existing section claim and retirement
predicate. The pin must make this lifetime guarantee independently of the
gate. A raw address carried in a local variable supplies no such guarantee.

For a same-section walk, decode under the existing gate without reentering
the map lock. Across a break, keep source custody, release the gate, resolve
and acquire successor custody in the normal order, then validate the link
revision/identity before dropping source custody. Read under the successor
gate. Failed acquisition retains source custody until a safe refusal.
Use the older suffix's recorded logical end and the configured label
contract. An unknown endpoint must take the safe mapped path. Retire the
physical-half fallback for authorization. Preserve the generation
recheck/rollback and last-reader retirement already exercised by the
directory diagnostic. Its injected transition still needs native evidence
of actual close and reuse arbitration.

** 2. Keep the committed cursor through the heap-limit path

Trace =___CHECK_HEAP= from generated hosts to =___heap_limit=. Existing
emitted paths can allocate a pair and retain it in a Scheme register
before the check. Treat their hp as a committed frontier when the
configured extent and owner authorize it. Preserve the full committed
prefix for census, scan and accounting, including legal use of the
existing guard allowance. Remove the generic clamp based on byte
distance. If a generator actually has an uncommitted reservation, it may
release it only with an explicit reservation identity, unchanged commit
frontier, and a proven reentry label that repeats no committed store or
effect. Missing provenance takes the existing error/slow protocol.
Likewise a stack overflow path cannot manufacture a frame by clipping fp.
Review changed callers that normalize stack/cursor values under the same
rule before the candidate is sealed.

** 3. Put capacity check and physical grant in one allocator transaction

Move the rest-specific decision into the existing allocation owner.
With the allocator lock, or the equivalent sealed GC epoch authority,
read the synchronized live/assigned ledger, validate current owner and
epoch, check the actual contiguous destination and stack margin, and
commit exactly one assignment/grant. Reuse the existing locked
allocator entry and its count/ownership updates. Document synchronization
with still-word updates as well as section assignments. If the budget or
interval is insufficient, return before changing either. Revalidate
under the same authority after collection. Capacity may be recovered by
GC before a new section is needed. Never hold the allocator lock while
entering that GC. Two contenders with one eligible section must produce
one grant and one recoverable refusal; neither may publish a partial
batch. Keep exact pair, vector, alignment and stack footprints for all
three emitted call forms.

** 4. Move the refusal oracle outside the production decision

Keep fault injection and observation in Gambit's existing test fixtures.
Scope forced refusal to one context, epoch and attempt. The test owns the
sentinels and initializes them only in an explicitly test-owned valid
interval before invoking the handler. Observation at the handler cut is
read-only. Verify heap bytes, written-address trace and actual argument
cursor before mapped cleanup. Cover the complete target extent and its
last word, and record the affected key/argument slots. Remove shared
production counters and flags from grant decisions and unconditional
handler instrumentation. A process-wide mutable cap or a sentinel
written by =___rest_grant_fits= cannot serve as the oracle. Verify an
uninjected concurrent attempt has the ordinary outcome.

** GSC census blocker and the existing-image boundary

Follow [[file:tfib-producer-retry.org][producer admission and bounded retry]]
for the integrated generator/handler contract. It specifies requested
space, old-view return descriptors and handler backing before the first
write, and distinguishes an empty retry from a real capacity result.

The construction report observed the current GSC failing at census with
fp 160 bytes below the selected half. The previous GSC had no output.
Keep these separate, and keep the first producer unresolved. At eight
bytes per word this is twenty words. The template's first-break space
is four words, so a one-break-sized allowance cannot explain that
displacement. Verify the configured descriptors and actual half before
assigning a cause.

The earlier =capture_continuation_source= revision checked a temporary
=scan= but stored raw =fp=. The implementation-owner follow-up reports
that the three coordinates now agree in =gsi.cut-frame=. Bind that
correction to its image and source. A producer view is valid only if it proves one
coordinate for geometry, first frame access and later copying. Normalizing
a coordinate in one consumer leaves the other consumers with a different
frame. A partial frame may contain live roots and cannot be skipped.

Carry that exact view and its source lease through census, copy and undo; never derive it by clipping fp. |

Quint =rest_caller_frame_grant= distinguishes a staged, published and
consumed view. =stagedViewCollectControlTest= rejects collecting after
staging even if root/frame flags appear true.
=splitCursorViewControlTest= rejects census consuming a different
identity than the published view. Source refinement must map that
identity to =VM/context/epoch/half/fp/break/descriptor/root-registration=.
Existing Lean frame/interval obligations own byte and word geometry,
alignment and containment. The model does not identify which emitted
store or section publication caused the reported 160-byte failure.

** Required receipt

Submit one manifest with the exact source tree, source-core prior,
effective GCC/C23 profile, generator and generated C hashes, link
inputs, and GSI hash. Include emitted return labels, raw event order,
root/interval observations, controls and natural exits. Retain tool,
input and artifact fingerprints. A copied receipt or mutable cache path
cannot establish the subject identity. Use existing Gambit tests for
native SCM and existing Python Evidence for the receipt.

| Audit row | Required adversarial control | Review stop |
|-
| Source and locks | Same-section second frame, cross-break old suffix, concurrent reflective reader, and lost successor. Observe locks, retained custody, and the first load. | Reverse acquisition, missing logical end, stale first load, or early retirement. |
| Commit frontier | Live pair or closure written before CHECK_HEAP, followed by GC and later consumption. Also force an actual uncommitted reservation and validate its declared retry. | Truncated committed prefix, second effect, or cursor rollback without a producer receipt. |
| Capacity | Two processors contend for one eligible section. Then run recoverable-headroom, genuine exhaustion, exact batch and one-short for all three rest spellings. | Two grants, lost section/accounting state, early false overflow, or old-epoch write. |
| Refusal and delivery | Independent full-extent sentinels, first and final field, actual stack cursor before cleanup, unrelated concurrent attempt, lost result reply and unique body entry. | Any refused batch store/pop, probe leaking to another attempt, or duplicate successful delivery. |
| TFIB progress | Same GSI records distinct completed child joins and ordered top-level join returns, with wait dependencies, wake/terminal pairs, GC phase and interpreter work over time. | Mere wake counts, short synthetic join semantics, or RTE entries without verified completions cannot classify the full workload. |

After A is reviewed, classify a wait obstruction only with a committed
result and a stranded eligible waiter, or a closed dependency with no
outside producer. Classify throughput only when real joins advance and
matched elapsed/CPU, GC and interpreter work explain the critical path.
Retain unknown otherwise. Quint supplies existing abstract histories;
source binding and the native receipt decide the implementation rows.
The original =p2 → p1= campaign still requires all four original cases,
natural exits and the original 295 s inner / 300 s outer budget. DEV
remains 5/12 until it completes.

* Producer and consumer lifecycle :custody:

The first qualification attempt exposed a real producer precondition. Stock
core had installed the intentional dummy seed; from-scratch deletes generated
C before compiling Scheme. A dummy returning success cannot replace that work.
The failed phase therefore reported a missing library C product. The new phase
failure rule stopped immediately rather than continuing later phases.

Retain this failure. Recover the previously completed compiler by exact hash
from the same task's preserved outputs, and use the existing GSC Make bootstrap
target to install the real seed before destructive source regeneration. This
is a source-qualification lifecycle, not a change to normal CI core commands.
Known script aliases remain registered while an interrupted workspace lacks
its executables; do not allocate a replacement SDK copy or ignore unknown links.

** Gain

| key | saved | added | condition | status |
|---+---+---+---+---|
| closed-internal-readers | 0 added per-lookup RMW if all internal readers remain in closed collective | existing barriers and join retained | complete internal synchronous scope; no exported lookup | conditional |
| shrink-domain | reuse existing RC-empty rejection; no RC migration needed for admitted shrink | nonempty RC domains remain ineligible until real handoff exists | existing can_retire_pstate plus known join | source-bound |
| exported-readers | no universal hazard scheme forced on synchronous internal users | O(A) enrolled observer leases for A exported readers or explicit refusal | stable admission anchor before first VM/task load | unresolved-native |
| failed-join | 0 speculative cleanups or gate destruction after unknown join | retained worker/VM/native resources; unbounded retention possible | unknown is not worker termination | conditional-model |
| retirement | 0 runtime paths retired by formal checks | unify typed cleanup preconditions across live shrink and private setup rollback | native all-callers and abnormal-exit refinements | design-only |

** Consumer

| key | source | access | lifetime | limit |
|---+---+---+---+---|
| live-shrink | shrink-join | old-set commit -> exit -> join -> still transfer -> cleanup | departing worker known dead; remaining roster lives | other native readers need separate closure |
| abort-growth | retained-join | abort entry then join created threads; cleanup initialized slots only if joins known | unpublished contexts and retained native entry records | unknown create/published contexts are not private rollback |
| setup-rollback | setup-failure | cleanup after failed sync initialization before successful setup return | exclusive unpublished setup lifetime | must prove no custom callback published it |
| global-shutdown | whole-vm-cleanup | shrink to one; reject retained requests; cleanup current pstate and VM | setup/VM lifecycle owner | public foreign users and reentry still unresolved |
| public-cleanup | cleanup-api | function pointers exported in global table | caller must provide enclosing lifetime and exclusivity | internal grep is not external caller closure |

** Issuer

| key | source | signature | gap |
|---+---+---+---|
| roster-coordinator | old-roster | old roster commit before departing thread exit | external entrants not inherently closed |
| native-join-owner | shrink-join | successful join witnesses departing OS-thread termination | does not witness external thread or callback retirement |
| storage-owner | still-transfer | transfer surviving still list and accounting before context cleanup | RC and effectful domains rejected by current shrink admission |
| vm-api-owner | cleanup-api | stable VM entry permit before public cleanup and first pointer load | current public ABI does not supply composed receipt |
| retained-custodian | retained-join | keep old native/storage identity on unknown join or escaped scan | recovery and liveness not established |

** Obligation

| key | status | condition |
|---+---+---|
| cohort-safety | conditional-model | closed admission; normal drain; known worker termination; zero exported observers |
| internal-shrink | source-bound | actual old-set commit, native thread exit, successful join then transfer and cleanup |
| external-api | unresolved | public cleanup and foreign pointer readers require stable enclosing VM authority |
| native-drain | unresolved | all claims, descendants and abnormal exits covered by effective collective |
| native-join | unresolved | successful join adapter and cancellation/exception landing qualified on selected target |
| c23-refinement | unresolved | memory orders, generation and native width correspondence |

Safety-model closure does not certify native caller coverage, C23 execution or performance.

** Gain

| key | saved | added | condition | status |
|---+---+---+---+---|
| eval-producer | no pre-enumeration of all callbacks from arbitrary Scheme/Tcl scripts | one retained producer plus O(C) active child records | fresh root ingress closed; authorized existing eval/pump continues until it returns | conditional |
| landing-once | 0 admitted stale-ticket or duplicate cleanup replays | stable identity ledger and explicit cleanup-inflight/unknown custody | known cleanup receipt; marker false is not completion receipt | conditional-model |
| result-lifetime | 0 premature provider/storage releases solely on callback return | O(R) outstanding results and unknown operation records | Tcl disposal route and original free provider remain live | unresolved-native |
| existing-hook | reuse ordinary release_string -> release_rc | no assumed Scheme reentry for this selected hook; other free hooks classified separately | effective target and origin binding qualified | source-bound |
| closure | 0 current runtime paths retired; no measured speedup | admission wrapper, identity mapping and cleanup/result receipt adapters | native caller and exception closure required | design-only |

** Consumer

| key | source | access | lifetime | limit |
|---+---+---+---+---|
| admitted-eval | eval-entry | arbitrary command sequence may enter multiple callbacks | retained eval producer across root close | no proof all scripts terminate; forced bounded fuel changes semantics |
| event-pump | event-entry | DoOneEvent can dispatch independent or nested event callbacks | separate owner-affine pump permit | cannot inherit authority from unrelated eval automatically |
| command-dispatch | dispatch | proc/clientData called then argv freed | Tcl active invocation plus managed source and VM permit | Command refcount is not RC payload root ownership |
| common-landing | sfun-end | return RC borrow, owner release, kill marker | exact active native invocation until cleanup acknowledged | repeated native cleanup can double release; no idempotence inferred |
| replace-result | set-result | new result installed, old callback then object reset | both old disposal and new result ownership across callout | old hook can reenter/escape; publication is not old cleanup completion |
| free-reset | free-result | custom callback before freeProc zero | owner-affine interpreter plus result disposal record | escaping callback may leave stale raw freeProc |
| interpreter-delete | delete-result | eventual delete then namespace/variable cleanup then result free | native preservation and owner thread until actual deletion | DeleteInterp request return is not blanket all-resource receipt |
| saved-result-owner | saved-result | SaveResult moves freeProc/result; Restore resets current then transfers back; Discard calls saved hook | external Tcl_SavedResult holds provider/storage even if interpreter field cleared | all producers and aliases of save tokens not yet enumerated |
| object-result-conversion | object-result | SetObjResult and nonempty GetObjResult invoke native free hook; SaveInterpState invokes GetObjResult | result owner and release target through conversion | one model result does not prove whole object/legacy snapshot product |

** Issuer

| key | source | signature | gap |
|---+---+---+---|
| eval-owner | eval-entry | VM entry plus interpreter generation and owner-thread scope before Tcl_Eval | existing adapter provides no stable receipt |
| pump-owner | event-entry | separate admitted event-pump producer and dispatch scope | Scheme event mutex alone does not prove Tcl OS-thread ownership |
| command-owner | command-registration | command/source identity lease before ClientData snapshot | registration itself is not dynamic invocation authority |
| landing-owner | sfun-landing | exact InvocationId and cleanup completion, independent of multishot Scheme frame | end_sfun and marker kill have no idempotence token |
| result-owner | result-publish | ResultId and original provider/storage hold until authoritative release | delete/reset return and raw freeProc fields are not durable receipts |

** Obligation

| key | status | condition |
|---+---+---|
| producer-safety | conditional-model | pre-admitted eval/event-pump remains producer until no child or unknown cleanup |
| tcl-ordering | source-bound | pinned local Tcl source; not loaded Darwin library identity |
| producer-issuer | unresolved | stable owner/interpreter generation plus eval/pump entry and source command permit |
| exact-landing | unresolved | per-invocation receipt outside captured Scheme frames; cleanup result known before done |
| native-result | unresolved | old free hook reentry/escape, provider/source lifetime and same-operation disposal receipt |
| c23-refinement | unresolved | native close/producer/dispatch synchronization and actual loaded ABI |

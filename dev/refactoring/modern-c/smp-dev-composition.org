** Ownership and replacement contracts

1. *VM round and root/work cut.* A VM epoch closes admission and freezes the
   actual root slots and participant identities. Root tasks and worker arenas
   carry private, published, claimed, weak and tail responsibilities until
   each is discharged. Queue emptiness is not termination while a publisher,
   borrower or hidden child remains. The old physical parity remains owned
   until every real reader has passed its last access. Unknown outcomes retain
   custody. This replaces reconstructing ownership from a carrier or a queue.
2. *Physical allocation and resume.* The round hands each execution context an
   exclusive interval with generation, cursor and physical limit. A drained
   worker tail or disjoint loan is transferred once. Continuation restoration
   precedes publication; the context's cursor and poll bound are published and
   the generated host reloads them. The compiler's complete allocation region,
   including the first closure header and fields, fits in that same interval.
   Polling threshold and physical end are different: a post-write poll cannot
   validate an earlier write. Logical stack links do not authorize section reuse.
   Reuse the existing resume-plan, capacity and range models, and the actual
   delayed-reader fixtures; close the concrete producer/reader census and C
   memory-order refinement before retiring old authority.
3. *Request and control.* One owner retains an accepted request through queue,
   claim, invocation and one result or abandonment; notification is not the
   result. Nested requests, target migration, arbitrary exception values,
   dynamic-wind and multi-shot continuation reentry retain their Scheme
   semantics. Retire duplicate membership or capture only after equivalence and
   last-borrower closure. No accepted callback may be dropped for speed.
4. *Interpreter application and tails.* TFIB spends work in interpreted
   application and control materialization as well as creating threads. Bind
   allocations and useful progress to actual application, argument environment,
   tail transition and continuation epochs before selecting an optimization.
   Candidate direction: keep a context-owned transient argument/control region
   for a proven non-escaping tail transition, materializing the same observable
   frame and environment before capture, debugging, interrupt, exception or any
   escape. This is a proposal, not a demonstrated safe optimization: aliases,
   recursive/reentrant calls, GC maps and all capture points require a census.
   Preserve interpreted execution and original work; do not compile the test,
   erase delays, reduce iterations or assume all measured allocation removable.
   Removing the vector alone does not remove the separate code-procedure
   dispatches visible in =##cprc-app1-red= and =##cprc-app2-sub=. A second,
   conditional direction is an interpreter-owned compact instruction loop for
   code nodes whose exact operations and lexical state are known. It must retain
   evaluation order, numeric tower/overflow and exception behavior, binding
   identity, stepping hooks, interrupt safe points and root maps. An unknown
   operator, changed binding, observer or unsupported state returns to the
   existing interpreter before any unrepresented effect. Materialization must
   preserve the current program point and lexical locations. This is a proposed
   generic interpreter path, not compilation or a TFIB-specific substitution.
   Neither a working implementation nor a speedup is established.
   =macro-step!= supplies the handler an execution callback and its operator and
   arguments; the handler can invoke that callback with different arguments or
   more than once. A specialized effect must therefore guard the actual callback
   invocation and use its arguments, without moving the effect ahead of the
   handler or assuming a single invocation. The [[file:../../../evidence/research/retained/modern-c/stress-gsi/dev-interpreter-step-callback-baseline.json][native baseline]] observes
   changed arguments and two callback invocations at p1 and p2; it does not
   establish candidate equivalence. A [[file:../../../evidence/research/retained/modern-c/stress-gsi/dev-interpreter-dynamic-stepper-baseline.json][second baseline]] enables reference stepping
   during operator evaluation and observes its effect on the following argument
   at p1 and p2. A fused reader must inspect the current handler at the original
   evaluation point, not assume it remains disabled. The existing =macro-make-cprc=
   also establishes an environment map before entering an interrupts-enabled
   body, so the replacement must preserve that boundary and its live roots.
   The [[file:../../../evidence/research/retained/modern-c/stress-gsi/dev-interpreter-generated-dispatch.json][regenerated source observation]] records three operand-dispatch sites
   and a direct =subproblem-apply2= jump; that helper reads and branches on the
   stepper. The [[file:models/quint/smp_interpreter_stepper_race.qnt][finite stepper-guard model]] shows an early cached false guard
   can diverge if the handler becomes enabled before the original helper read;
   a later read preserves the modeled double-callback outcome. The [[file:../../../evidence/fixtures/dev-interpreter-stepper-race/race.recipe.json][exact-test
   Recipe]] and [[file:../../../evidence/fixtures/dev-model-framework-v5/dev-model-evidence.recipe.json][SysML/ASCENT model chain]] passed. This modeled interleaving is
   a hazard to investigate, not evidence that production can actually be
   interrupted at that point, nor proof that a later check is atomic or safe.
   An [[file:../../../evidence/research/retained/modern-c/stress-gsi/dev-interpreter-constant-candidate.json][isolated constant-node experiment]] generated and linked a candidate image;
   four continuation, interrupt and stepping controls passed at p1 and p2.
   Its mutable code-procedure identity, additional poll and source-level
   linearization require further tests; no performance gain or broad semantic
   equivalence is established and the production interpreter is unchanged.
   In an [[file:../../../evidence/research/retained/modern-c/stress-gsi/dev-interpreter-constant-perf.json][alternating matched diagnostic]] with two samples per image and topology,
   this candidate's means were slower than baseline at both p1 and p2. The small,

   A [[file:../../../evidence/research/retained/modern-c/stress-gsi/dev-interpreter-poll-ablation.json][no-poll ablation]] was measured separately against the candidate; its two

   A [[file:../../../evidence/research/retained/modern-c/stress-gsi/dev-interpreter-constant-identity-control.json][synthetic code-node control]] changes the global constant-node procedure:

   Eight bounded controls passed and alternating reduced-delay samples were
   recorded; variability prevents a production performance claim. This hand edit
   is not a compiler implementation: continuation maps, interrupt semantics and
   compiler-source regeneration must be established before any adoption.
5. *Registry, native lifetime and recovery.* Registries publish stable identities
   with explicit reader lifetime. FFI frames, callbacks and external owners hold
   real roots/leases across relocation and nonlocal exit. Create, partial create,
   rollback, exit, failed join and unknown return retain exactly the obligations
   of their incarnation until last consumers drain or an authoritative result
   reconciles them. This replaces inferred cleanup on thread/VM disappearance;
   it does not invent a global lock or assert that unknown will eventually clear.
6. *Producer and evidence.* Existing build/qualification owners bind the source
   delta, compiler, ABI, generated C, libraries, executable, profile and original
   population to one cohort. A changed writer, map or generator triggers affected
   prerequisite requalification. Native success is not obtained by combining
   separate attempts, diagnostic fixtures or a different image. Five commit
   gates are source freeze, alias/slot repair, control/native boundary, full
   native/PBT, and matched cost/peak; all remain open for this composition.

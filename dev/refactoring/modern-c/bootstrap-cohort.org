two bootclean/build passes and the native bootstrap adapter checks two instances
of each of phase1 through phase4. Neither a host pass nor a single self-source
pass may be reported as that complete two-pass bootstrap.

* Conditional mathematics and the concrete-source gap

[[file:models/quint/bootstrap_cohort.qnt][QNT]] separates host qualification, argv, two generated coverage classes,
target build, target self generation, self build and semantic observation.
Its retained counterexamples reject missing linker metadata, process-only argv,
host-pass-as-self, semantic admission before bootstrap, and host-runtime import.
The successful sampled traces are finite safety evidence, not native results.

[[file:models/lean/BootstrapCohort.lean][Lean]] proves that universal per-class coverage reflects complete native
coverage when the required-name/class mapping is total. Merely finding one
representative in each class is explicitly insufficient. The native adapter
must establish universal coverage of the manifest's filenames; the QNT two-class
state cannot infer all 51 witnesses. Monotone emission preserves established
coverage. Semantic admission still requires a separate self-pass event.

Remaining refinement obligations are actual compiler source/effect closure,
producer-to-required-file mapping, successful compilation/link publication,
generated FrameSpec root coverage, C memory ordering and runtime lifetime.
Conditional laws do not prove these assumptions. ASCENT must keep them open.

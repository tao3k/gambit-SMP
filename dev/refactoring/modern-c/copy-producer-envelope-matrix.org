** Claim

| B | Canonical physical source charges + alignment + threshold count | Identity keyed by allocation/epoch/physical offset, not descriptor spelling; complete old source | B>=U+T; frame destination strictly smaller than full rounded stack source | Source writer/alias partition, newer VM resize-request roots and all-phase charge injection still open |

| reuse | Retain immutable producer summaries across builds and GC rounds | Bind generator source, ABI, module identity and constructor manifest | Reuse size maxima and root layouts; recompute frozen source occupancy each round | Summary invalidation and old-code retirement remain mandatory |

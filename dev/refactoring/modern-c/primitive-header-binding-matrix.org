** Claim

| key | mechanism | condition | result | gap |
|---+---+---+---+---|
| roles | Two temporal projections | Capture header values before native helper writes | Header s-nd and native binding coexist | Current-source generation provenance OPEN |
| idempotence | Demand setter maps payload to singleton | Same interned key and entry identity; no intervening mutation | Second value update redundant; first may change classification | Physical-write removal requires alias observer closure |
| spans | Independent byte parser for existing C | Exact SHA and half-open byte intervals | Two binding tuple spans agree with global and host labels | Full ModuleSpec encoder and native expansion OPEN |

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| two-helpers | 2P emission-time use-glo calls and existing-entry setters; artifact P=455 gives 910 calls | P immutable binding records plus 2P readonly consumers | Producer closure proves entries and indices; no missing-use error changes |
| header | Repeated role classification for C and Spec in proposed dual consumers | One owned header snapshot; copy cost H | Only savings against dual-consumer design; current compiler already writes header once |
| binding | Repeated name conversion and binding tuple derivation | P records; span metadata O(P); byte verification O(C) | Share encoding without alias retention; no measured speedup |
| macos | No directly established preprocessing or startup saving | Same C bytes retain downstream compile work | Darwin improvement requires separate artifact reuse or C emission redesign |
| net | 2P mutation-capable uses plus duplicate work D | Planning K + owned storage S + byte verification V + profile qualification A | Positive only if avoided work exceeds K+S+V+A; no numeric timing claim |

** Role

| key | identity | retirement | boundary |
|---+---+---+---|
| NativeThreadDomain | Native thread incarnation, checked TLS, owner dispatcher | Admission closed, all attached segments/readers drained, known native exit and TLS detach | Not equivalent to processor ID |
| NativeReturnDomain | Segment generation, native return target, live local catcher extent | Known return/unwind consumes return permission and invalidates affected extents | OS thread alive does not mean returned invocation alive |
| StableGuard | Activation TicketId, rooted arguments and completion custody | Exact activation settled, entry closed, scanner and code readers drained | Guard persistence does not extend local jmp_buf lifetime |
| CapturedContinuation | Scheme frames, denv and descriptor leases | All reachable holders and in-flight restorations relinquished | A restoration does not recreate expired native return authority |
| RootBundle | Actual GC-updatable slots and owner generation | Transfer acknowledged, borrowers drained and collector grace | Native pointer pin alone is not a registered Scheme root |

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| G1 | No current C-stack-copying work removed; zero-copying constraint retained | Pinned native carrier and explicit segment registry | No arbitrary C-stack copying; thread-affine libraries remain on owner |
| G2 | No current thread-count saving established; avoid an N-thread-per-resumption redesign | N fresh resumption guards/tickets plus initial entry; active segments K, receipt history Q and pinned time | Sharing is by live native segment, not by continuation shot; pool reuse only after full native exit |
| G3 | No existing conservative C-stack scanning saving established; account actual root slots | Registered mutable root slots; per-round S visits plus descriptor pins | All foreign Scheme references are declared; raw aliases reject managed qualification |
| G4 | Potential independent Scheme scheduling through isolated native ownership | Per-domain serialization; no global registry CAS required by design | Pure Scheme scheduler remains free; live native return paths stay thread-bound |
| G5 | Proposed per-ticket settlement rejects duplicate completion; no measured baseline saving | Stable receipt storage and replay retention | Delivery retry uses same ticket; a genuine continuation resumption receives a new ticket |
| G6 | Legacy marker-as-lifetime-proxy responsibility can retire | NativeEntrySpec lowering and ModuleSpec/FrameSpec leases | Only after every SFUN/run/generated entry and FFI alias is covered |
| G7 | Zig required language/runtime supports eliminated: none proven | Zig would still need the same root, stack and return contracts | C23 is baseline; no incremental semantic gain from language substitution established |
| G8 | Unknown outcomes never authorize eager free | Retained bytes and blocked retirement may be unbounded | Correctness gain only; requires observable reconciliation before a liveness or memory bound claim |

** Memory

| key | publication | observation | obligation |
|---+---+---+---|
| registry | Initialize stable domain then release-publish generation/state | Acquire+pin before dereferencing | Lookup load alone is not lifetime protection; close admission and drain readers |
| return-lease | Owner-serialized live-to-claimed transition; pin native owner | Acquire observes segment generation and catcher validity | CAS claim alone is not physical return receipt; unknown remains owned |
| root-transfer | Publish target slots release; GC acquire snapshot and updates | Collector round acknowledgement before source slot release | Atomic pointer publication is not GC root registration; moving collector rewrites actual slot |
| settlement | Ticket-scoped completion state acq_rel | Duplicate observation uses acquire and exact activation incarnation | Captured guard cannot settle newer activation; no winding-only release |
| retirement | Close gates acq_rel then drain pins/GC/code readers | Acquire observes last release and known native exit | A zero counter alone does not imply no late entrant; atomic lock-free support not assumed |

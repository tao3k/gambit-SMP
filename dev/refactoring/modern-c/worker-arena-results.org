This is a real C runtime responsibility replacement in =vendor/gambit= on
=modern-c=. Scheme semantics, the shared object graph, multi-shot continuation
and the C ABI remain Gambit's. Worker allocation no longer borrows a context
heap cursor. Physical carrier synchronization and owner-affine foreign cleanup
remain explicit limitations of this adapter. Changing a worker count alone is
not admitted.

The [[file:models/sysml/root-worker-exit.sysml][canonical SysML]] owns the two realizations and seven worker admission
conditions. [[file:root-worker-exit.org::#root-phase-realization][Native projections]] and [[file:diagrams/root-worker-exit.svg][D2]] show both the implemented cut and
remaining obligations. [[file:models/sysml/root-task-c-refinement.sysml][The C refinement contract]] adds refill and handoff to the
existing seven operations. No new QNT/Lean model or theorem duplicates an old
obligation. Existing formal results are not readmitted as a C memory-model proof.

** Physical partition and accounting

Let =H=MSECTION_SIZE/2=, =F=MSECTION_FUDGE=, and =L= the actual active-stack
restore length, including the first break frame. Every =L <= H-F= and destination
parity is checked before the first space flip. Initial disjoint sections require
=R+W= entries in the existing physical pool. This checks initial grants, not all
future copying demand or fragmentation.

The optional bottom loan has length

#+BEGIN_EXAMPLE
loan = min(3 * floor((H - 2F) / 4) + F, H - L - F)
copy span = [stack_base, stack_base + loan - 2)
restore stack remains above stack_base + loan
#+END_EXAMPLE

Two terminal chunk-link words stay outside the copy limit. No other worker gets
this loan; the assigned free-section suffix excludes all initial grants. The loan
is used once. It does not increase usable heap or add an extra physical section.
A request larger than the remaining contiguous span can still fail. This is not
a complete pre-flip packing algorithm.

For closed worker intervals =I= and final interval =J=:

#+BEGIN_EXAMPLE
arena.retired_words = sum(consumed_prefix(I))
context.words_prev_after = context.words_prev_before + arena.retired_words
context.heap_span_after = J
movable_occupancy = 2 * (retired_prefixes + used(J) + restored_stack_words)
#+END_EXAMPLE

Chunk links remain part of physical occupancy. A known forwarding-CAS loss
refunds only its private unpublished reservation; it does not refund retired
prefixes or section waste. At handoff the final interval and retired words change
custody, rather than becoming a second allocation. RC sentinels, still lists and
Scheme root-domain identity stay in their original context storage.

** Conditional safety argument and counterexamples

1. If all admitted root writers are stopped, the coordinator can reserve distinct
   stack/copy sections and publish round parity. No epoch check alone freezes a
   writer; a native borrower without that guarantee remains excluded.
2. If the arena has one physical writer, VM section acquisition is exclusive and
   the loan is private, refill cannot acquire another context's active heap tip.
   Reusing a loan after its first consumption would overlap live copies.
3. If forwarding wins, payload initialization and Tail remain with that worker.
   Neither queue publication nor a lost acknowledgement transfers that debt.
4. Only after weak descendants and old writers drain can final heap span and
   retired-prefix accounting transfer. Duplicate handoff is refused. A pending
   grant, active scanner or unknown worker write prevents recovery/resume.
5. Every context is restored and cleanup completes before root thaw. Currently
   this relies on a bijective synchronous adapter. With W < R, merely skipping
   carriers loses cleanup or strands barriers; with W > R, assigning the same
   resume recipient twice loses copied-prefix accounting.

A worker dying midway through plain handoff stores is not recoverable merely
because its epoch matches. Physical exclusion and the final collective remain
required; an unknown shared-heap writer can still block the affected VM. The
empty, unpublished aborted-thread isolation test proves a narrower progress case.

** Conditions for unequal workers and roots

The [[file:root-worker-exit.org::#root-phase-realization][SysML-generated table]] is the admission inventory. ASCENT joins its exact seven
condition identities with the source/profile/native guards. With all nine selected

=resume-coverage=, =affine-cleanup=, =collective-split=,

Removing any one slice guard must remove the slice result and restore the first
condition to missing. =rweUnequalReady= and =rweRetirementReady= stay empty in
all controls. One of seven conditions is not a percentage of modernization work.

The existing =copy_custody.qnt=, =round_capacity.qnt= and
=root_producer_closure.qnt= own bounded scheduling/authorization histories and
counterexamples. Existing =CopyCustody.lean=, =RoundCapacity.lean= and
=RootProducerClosure.lean= own coverage/accounting/refinement claims with explicit
premises. This turn changes their C adapter and evidence association; it neither
duplicates their transition systems nor claims new theorem or memory-model proof
results.

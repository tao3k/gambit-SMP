* Native SysML projection

[[file:bootstrap-cohort.org][Native attempts and interpretation]].

| Boundary | Actual route | Required invariant | Work / capability enabled | Added cost / premise |
|---+---+---+---+---|
| host | complete current compiler source graph -> independent AOT host ABI -> emitter for target ABI; interpreted igsc retained as a diagnostic | Compile all compiler modules together, not a partial backend overlay. Host native ABI and emitted target ABI are distinct; host runtime is never linked into target. Source/SDK/argv and dependency assumptions remain explicit. | Break old-C/new-header bootstrap cycle and remove interpreted compiler execution from each target emission without restoring carrier aliases or importing repair runtime | One whole host compiler AOT build and host SDK storage; no automatic cache-reuse claim without complete source/effect dependency closure |
| argv | process.scm command-line/script-command-line -> igsc canonical processed argv -> main.scm command-args | Strip Make runtime aliases from effective script argv, clear the obsolete script view, and preserve all compiler argument words | Eliminate two inconsistent option views; real Make prelude/warnings/source arguments produce C instead of zero-output returns | One normalization per invocation; no general shell string decoder or global FFI rewrite claim |
| inventory | leased source-state inputs -> all top-level lib/gsi/gsc _*.c -> bootclean -> complete generated hash inventory | Required module and linker C units are known before deletion; failed emission cannot shrink the required set to zero | Old module metadata cannot silently survive a changed FrameSpec/ModuleSpec/runtime ABI | All affected C products must be regenerated; correctness work is added, not an incremental-build speedup |
| target-native | same Bazel configure profile -> generated C -> target libgambit/gsi/gsc | Existing O1 modules/O3 runtime and SMP/multiple-VM/threaded-VM flags; exact effective argv/headers recorded; artifact success and quiescence required | One explicit target cohort replaces accidental reuse of old generated carrier accesses | No old C shortcut across incompatible layout; canonical compiler/root/lifetime consumers still need native acceptance |
| temporary-roots | GC_SAVE/RESTORE1..3 and os_setup six service families -> execution_context.saved -> mark_execution_roots -> reload/clear | All raw temporary-root consumers migrate with their scanner. 78 os_setup accesses retain existing conversion/result/error clearing behavior. No carrier alias is restored; fixed three-slot capacity is not arbitrary nested-FFI admission. | Source-complete execution-root ownership covers generated allocation helpers and OS service constructors instead of only six previously compiled C units | Existing context indirection at each access; no additional root slots or root-scan range; native GC/FFI progress remains to qualify |
| self | new target gsc -> fresh bootclean -> target self-source pass -> hash/identity receipt | hostedSource and regeneration checkpoints are distinct; a host pass cannot suppress the real self pass | Compiler/runtime agreement is checked through an actual target compiler invocation | Second source generation/compilation pass; no model or first-pass result substitutes for it |
| semantics | new target gsc -exe -> tests/frame-continuation-roots.scm -> real map capture, two restores, GC and native call | Original, 20 and 200 restored map results; 80 retained roots; expected wind/visit history; 11 completed forced GCs; native call count 3 | Exercise Gambit multi-shot semantics together with frame/GC/native consumers | Independent carrier retirement, all FFI callbacks and failed membership remain separate open gates |
| startup-capacity | current_vm_resize -> vm_resize_pstate -> GC resize_heap -> setup_pstate/setup_mem_pstate -> two physical startup sections per new context | GC membership is the closed existing set; requested contexts are future consumers. A grant must cover already assigned physical sections plus two per pending context and bounded resume reserve. Unknown allocation or capped capacity below the floor cannot publish a grant. Proposed planner is not implemented. | Replace nominal global minimum with a physical reservation contract before member/thread publication; source and native evidence explain the host-budget p11 startup failure | Explicit growth reservation can increase peak physical sections; interval/allocator/rollback and C refinement remain open. No larger heap or forced p1 setting qualifies the failed SMP lane. |

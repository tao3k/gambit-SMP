** First complete patch and rejection conditions

The first patch must unify generated and reflective ordinary stores with explicit
source authority and actual runtime/module binding. Preserve SET_GLO and Scheme
names. If the service changes an ABI, include real table/layout consumers and old
module rejection. The input value must stay rooted until commit or an explicit
refusal; no partially published store or permission may be inferred after an
unknown result. A gate must not be held across GC, Scheme allocation or callbacks.

Per-store locking has a cost on every assignment; an activation permit shifts
the proof to safe-point/exit lifetime. Neither is currently selected or proved.
Routing one macro through a mutex while leaving raw/reflection/setup paths open
does not close this responsibility and must not be called the modern SMP solution.

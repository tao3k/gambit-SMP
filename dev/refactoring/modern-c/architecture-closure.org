** Conditional composition proof obligations

1. Request conservation: accepted work has exactly one queued, executing, result-delivery or abandonment custodian. Routing and wake notifications convey no execution/completion authority. Preserve the original exception and nonlocal-control result.
2. Root coverage: every live Scheme cell belongs to the frozen union of actual root sources; every admitted writer is closed or participates in the protocol, and each consumer reloads relocated cells. Source revisions and moving addresses are distinct. A RootTask name is not a census proof.
3. Collector conservation: outstanding work includes queued, claimed, private copying, Tail, weak/cleanup and live producers. Unique forwarding does not imply complete payload. Finish requires all responsibility to be discharged or transferred, and every context restoration interval must exist.
4. Lifetime conservation: writer closure, GC participation, OS-thread return and resource reclamation have separate receipts. Unknown native results retain an owner; no unrelated VM depends on a global uncertainty gate. No safe takeover is inferred from a timeout.
5. Control equivalence: maps, shared captured frames, aliases, denv and dynamic-wind must preserve Gambit multi-shot behavior. Separate waiting roots from private service activation where semantics permit; do not remove user continuation capture or impose OCaml one-shot behavior.
6. Cost admission: fewer source operations is a structural benefit. Measure actual capture/materialization/retention, copied bytes, service backlog, tail latency and physical peak on the same producer. These are not consequences of a finite invariant. The original full populations and natural exits decide acceptance.

The conjunction is the architectural route to eliminate the observed defect classes, conditional on complete concrete refinement. It is not a proof that every unknown cause of Repair9 or the remaining9-12 families has already been solved. Each failed original workload either falsifies an adapter/premise or reveals an omitted factor; retain it and update the owning cut.

** Role

| key | identity | retirement | boundary |
|---+---+---+---|
| IngressRootDelivery | Outer and inner source/target slots have separate acknowledgement | Source storage ends after target root coverage is acknowledged | Both source carriers are admitted premises; raw ClientData needs an earlier pin |
| NestedNativeReturnDomain | Parent/child native extents and generation-bearing return authority | Outer unwind invalidates affected descendant return targets | Invalidation does not imply guard settlement or descriptor death |
| StableUnwindEscrow | Stable operation identity, exact affected subtree, root/code custody | Known landing plus per-activation settlement | Unknown landing retains ownership; no retry of an arbitrary longjmp |

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| G1 | Capture/restoration remains Scheme control independent of native stack return | One fresh execution guard and ticket for each managed resumption | Two modeled resumptions; no baseline OS-thread-count saving claimed |
| G2 | Outer unwind cannot silently abandon admitted inner root/code custody | O(d) descendant closure and lease transfer for d affected native domains | No claim that sequential END_SFUN cleanup already covers every unwind |
| G3 | Retirement checks can reuse one subtree/root/code ledger | Ledger publication, pinning and acknowledgement traffic | Only if it replaces duplicated adapter state; layering it over old ownership has no demonstrated work saving |
| G4 | Known native frame expiry need not force retention of whole execution context | Separate RootBundle, captured frames and image leases | Safe separation is conditional; object bytes and exact root/descriptor closure remain unresolved |
| G5 | Independent compilation contexts can share the same explicit entry schema | Native owner pin occupancy and per-context root registry support | Parallel gxi/gxc throughput is not proved by this lifetime model |
| G6 | Roots may retire while descriptor lease still protects a captured frame or scanner in a general design | This bounded conservative model waits for captures then root readers; descriptor release follows | No prompt-reclamation or reduced scan-count claim without a less conservative product proof |
| G7 | C23 can express the whole contract; no extra language is required for it | C23 ABI adapters, atomic publication and reader retirement remain necessary | Zig adds the same semantic work; incremental net benefit remains unproved |

** Memory

| key | publication | observation | obligation |
|---+---+---+---|
| root-publication | Initialize bundle slots and descriptor leases before release publication | Acquire registry snapshot or registration lock, then pin actual slots | Source release requires a qualifying root-round receipt; sampling reader count zero is not a receipt |
| subtree-escrow | Fill stable operation record and retain descendant roots/code before release publishing escrow | Owning thread acquires/validates exact closed subtree before longjmp | Atomic abstract escrow requires a native refinement; two separate guard stores are not an atomic transaction |
| landing-reply | Release commit landing record after exact target catcher is reached | Acquire same operation identity; missing reply remains unknown | No timeout can substitute for a landing or failure receipt |
| root-retirement | Close bundle admission acq_rel and release last admitted scanner pin | Acquire observes closed admission and scanner grace | GC must not wait on a guard that waits for that same GC; existing scanners finish while guards stay rooted |
| image-retirement | Retain image/code leases for captured frames and admitted scanners | Acquire aggregate root/code/native-owner closure across all VMs | Marker invalidation and frame_access gate release alone are not global unload permission |

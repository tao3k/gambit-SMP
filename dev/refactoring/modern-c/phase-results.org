** Responsibility selection and the historical hold

The earlier scope correction parked cleanup and phase-loop candidates to prevent
isolated Make edits from replacing the modern C runtime programme. That history
is preserved in GambitRevisionDelivery. The current explicit request advances the
classified Changes queue. This leaf revisits only phase-result composition after
observing three actual false-success classes in the configured producer. It does
not reopen configured-tool cleanup, rename official targets or alter bootstrap
commands. Native/root/writer/worker architecture remains the programme main line.

The actual old =phases= target invokes phase1--4 in one shell loop and discards
each non-final child status. It may return success after phase1/2/3 failed if
phase4 succeeds. The existing external qualifier may already detect some such
errors through logs/products; that is not proof that Make owns a correct result.

The single source replacement in =makefile.in= propagates each returned failure
at that composition point: =$(MAKE) $$phase || exit 1=. Names, dependencies,
arguments and successful phase order stay unchanged. No wrapper, executor,
profile, target rename, test population or cleanup edit is included.

** Conditional returned-status law

For returned statuses r1..r4, phase i runs only if every earlier status is zero.
Parent success is equivalent to all four returning zero. A returned nonzero,
including a signal represented by shell failure, stops the loop immediately.
GNU Make reports its own failure status; the exact numeric child code is not
promised. A child that hangs or whose result is unknown remains under the
unchanged supervisor limits, with no successful product receipt.

This establishes necessary failure propagation, not sufficient product validity.
All existing source/configuration/tool/output identities, complete phase counters
and original consumers still apply. It cannot repair a compiler that reports
success for invalid output, recover an unknown native owner or resolve a runtime
SMP scheduling defect.

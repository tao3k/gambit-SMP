** Gain

| key | saved | added | condition | status |
|---+---+---+---+---|
| nested-shutdown | 0 blocking self-drain waits in requestClose; no forced premature root release | stable requested-close record and later owner finalization | request and final retirement are separate operations | conditional-model |
| known-SFUN-unwind | reuse existing throw-as-result cleanup route and marker retirement | exact session identity and guard registration before collecting conversion | no raw foreign exit bypasses landing; generated code qualified | source-bound/conditional |
| shared-admission | 0 mandatory duplicate gates for run and its internal call | one outer authority plus scoped child grants; all raw bypasses refused or mediated | private delegated internal calls distinguished from fresh public calls | design-only |
| delayed-results | avoid treating callback return as all-storage drain | O(R) origin holds for R outstanding native result releases | Tcl release callback and module/provider lifetime remain callable | unresolved-native |
| retirement | 0 current runtime paths retired by formal checks | typed request/await/result and cleanup adapter; retained unknown ledger | all native callers, exception and storage closure | design-only |

| process-exit | exit-policy | cleanup then unconditional exit_process | process policy rather than reusable VM retirement | no recoverable retirement receipt inferred |

** Issuer

| key | source | signature | gap |
|---+---+---+---|
| embedding-owner | public-table | stable entry authority closes fresh host calls; remains live after close | setup_state alone is not concurrent gate |
| parent-scope | sfun-landing | preauthorized child/source grant and pending child debt | normal parent cannot settle while child or grant remains |
| landing-owner | generated-end | exact activation marker/catcher plus cleanup-completed guard identity | no receipt from arbitrary longjmp or multishot stale completion |
| result-owner | tcl-result | one-time native result release with origin/module hold | delayed Tcl disposal or unknown free may outlive callbacks |
| retirement-coordinator | parent-model | combine ingress drain, physical cohort, worker join and storage closure | current void APIs do not expose authoritative final status |

** Obligation

| key | status | condition |
|---+---+---|
| ingress-safety | conditional-model | close request preserves active scopes; settle after children and known landing |
| source-boundaries | source-bound | actual cleanup call sites, SFUN landing/end and Tcl delayed result release |
| public-callers | unresolved | all direct and indirect public APIs acquire stable outer authority before first raw pointer/TLS access |
| nested-grants | unresolved | preauthorized callback/source identity and bounded grant must be explicit; arbitrary late callbacks refused |
| exception-closure | unresolved | exact catcher/marker landing and one-time guard settlement; raw foreign longjmp/cancellation not covered |
| storage-completion | unresolved | all delayed result, RC, still, descriptor and allocator-origin debts settled |
| c23-refinement | unresolved | closed admission atomic linearization, release/acquire and effective native sync/join |

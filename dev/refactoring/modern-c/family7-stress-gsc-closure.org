* Literature Amplification and Architecture Synthesis

Family 7 closes the semantic gap between statically linked interpreted execution (=stress-gsi=) and dynamically loaded compiled C-host modules (=stress-gsc=):

1. *Independent Translation Validation (Pnueli et al. TACAS '98; Leroy CompCert POPL '06)* :: Rather than trusting =gsc/_t-c-2.scm= by inspection, [compiled_host_validator.py](file:../../../src/gambit_smp/compiled_host_validator.py) independently parses each =gsc=-emitted =.c= module and verifies:
   - Basic-block write-group dominance: every heap store (=___ALLOC=, =___BEGIN_ALLOC_*=, =___ALLOC_CLO=) and stack advance (=___PUSH=, =___ADJFP=) is dominated by =___group_demand_enter(___ps,&___hp,&___fp,S,H,___LBL(L),&___demand_attempt)= with matching =___DEF_SLBL(L,...)=, matching =___group_demand_commit(___ps,___LBL(L),...)=, and sufficient =(S, H)= word budgets.
   - Frame descriptor soundness: independent bit-field decoding of every =___IFD(___RETI/___RETN, fs, link, gcmap)= and =___OFD(...)= macro ensuring =0 <= link <= fs= and GC root masks stay within =[0, fs)=.
   - Post-safepoint reload discipline: every allocating procedure defines =#define ___PR_ALL ... ___R_HEAP= (or =___NEED_HEAP=) and performs no heap write after =___POLL= / =___CHECK_HEAP= without reloading =___hp=.
   - Back-edge safepoint liveness under =(not safe)=: Tarjan SCC detection over each procedure's GVM label CFG confirms every cyclic loop contains a safepoint (=___POLL= / =___CHECK_HEAP=) or non-local call, preventing SMP GC rendezvous starvation even in =(declare (standard-bindings) (fixnum) (not safe))= tight loops (=thread_interrupt_stress.scm=, =thread_terminate_stress.scm=).
   - RSS-guard bound: =___LBLCOUNT < 6000= on every compiled stress host so inline fast-path guards remain active while keeping GCC =cc1= memory orders of magnitude below the =8 GiB= ceiling.

2. *Dynamic Module Late-Binding ABI (=___GSTATE= / =___EXT=)* :: On Darwin =arm64=, Gambit compiles loadable =.o1= modules as Mach-O bundles (=-bundle -D___DYNAMIC= without =-undefined dynamic_lookup=), where =___BIND_LATE= is defined and =___CAN_IMPORT_DYNAMICALLY= is undefined. Gambit's canonical dynamic ABI (=include/_gambit/module_generation.h.in:450-455=) routes all runtime calls through =___EXT(f)= = =(___GSTATE->f)=.

** Releaser

| key | effect | identity | decision |
|---+---+---+---|
| release_scmobj | still count decrement; immediate/permanent no-op | the exact converted object | required on successful native-held conversion |

| generated END | three SFUN close-only + three CFUN empty | same converted object | missing effect in closed generated scope |
| SFUN_ARG / CFUN_RESULT / backend return | root assignment / GC map / register reload | converted value | does not decrement native hold |
| GC setup / sweep | nonzero held objects remain roots; unmarked freed | same still object | cannot fix leaked count1 |
| marker invalidation | marker decrement | distinct marker identity | cannot settle numeric argument |
| cleanup_rc / release_rc | RC payload/free linked native cell | different allocation/header | cannot settle numeric bignum |
| foreign release callback | foreign subtype destructor | bignum has no foreign payload | cannot settle numeric bignum |
| free_still_objs | whole storage teardown | all remaining still objects | ends VM lifetime, not per-call balance |
| custom C / Scheme decrement | arbitrary explicit effect | identity must be proven | exclude or transfer single ownership; open-world aliases unresolved |

** Gain

| key | benefit | cost | condition | refutation |
|---+---+---+---+---|
| retained-native-holds | B successful boxed conversions can discharge B extra holds | one release decision per N conversions; B physical decrements | same object; unique owner; no explicit manual double drop | no boxed conversions B=0; arbitrary user-owned decrements admitted |
| GC-root-pressure | remove B accidental native roots after true last use | language roots/captured continuations still scanned as required | otherwise unreachable objects; k later collections gives at most B*k avoided root visits | live captured objects cannot be skipped; not a time or RSS estimate |
| generated-contract | one direction-aware plan replaces six inconsistent size-family END responsibilities | success/failure/root/escape metadata and generator validation | producer and consumer same ABI; all generated users migrated | old modules or handwritten converters bypass plan |
| language-choice | C23 solves this ownership defect without a second runtime language | guard and root/GC integration remain explicit in C or Zig | required modern C mainline | Zig syntax or no-GC property does not discharge Scheme holds |

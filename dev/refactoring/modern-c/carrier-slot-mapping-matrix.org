** Identity

| key | structure | rule | caveat |
|---+---+---+---|
| physical-slot | VM + StorageId + storage generation + word offset | Canonicalize writable cell identity, never SCMOBJ contents | Storage issuer must prove native address/key adequacy over the admitted universe |
| logical-entry | DescriptorId + descriptor generation + SlotKey runs | Multiple entries can reference the same physical cell | Root-task deduplication does not merge borrowing or storage ownership |
| snapshot | CollectorRoundId + frozen registry cut + root policy | Exactly one scan authority per canonical cell | Incompatible strong/weak or layout policies must be rejected or separately proved |
| lookup | Stable VM index plus fixed lookup identity | Pin before descriptor dereference; validate active generation before borrow acceptance | Finite model has fixed identities and no slot reuse; native ABA proof remains open |
| code | ModuleHandle + scan ABI + layout fingerprint | All descriptor and task readers retain scan code until grace | Module pointer reachability is not native module unload permission |

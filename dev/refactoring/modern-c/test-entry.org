entry contracts. Gambit's existing =___MAIN_PROC= gives the corresponding
typed =WINAPI WinMain= signature and C linkage, but invokes Scheme setup;
that setup must not replace a standalone C assertion body.

* Shared adapter :source:ownership:

The private [[file:../../../vendor/gambit/tests/test-entry.h][test entry header]] supplies the configured Windows signature
and calls the original static body once, returning its actual status. Other
configurations retain =int main(void)=. The three existing bodies are byte
identical after accounting for the include and declaration replacement.
The [[file:../../../vendor/gambit/tests/test-entry.c][entry control]] verifies single dispatch and propagation of a nonzero result
on other hosts, and runs against the real configured entry on Windows. Its
non-Windows stub is explicitly not evidence of Windows SDK/calling-convention
compatibility; remote CI supplies that dimension.

The existing Make BUILD_EXE service builds every control. Add both files to
its source inventory and the entry control to the ordinary check prerequisites.
No workflow command, assertion, expected output or runtime service changes.
The pending scope-to-write-authority rename adopts the same entry in its
working control without reviving its deleted legacy file or publishing the
unqualified rename with this cut.

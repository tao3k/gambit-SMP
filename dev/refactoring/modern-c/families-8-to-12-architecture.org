* Engineering Cuts and Design Amplification :design:

** P0-2 Binding-Read Activation

1. *Single-page =primitive_value=* (=vendor/gambit/lib/_mem/global-bindings.inc=):
   Previously, =primitive_value(vm, g)= called =primitive_cell(vm, g)= and
   =primitive_flag(vm, g)=, issuing two separate =___global_page(vm, g->val)=
   hash-directory lookups per primitive read. Merging them into a single
   =___global_page(vm, g->val)= lookup followed by acquire-load of
   =page->primitive_set= and acquire-load of =page->primitive[slot]= halves
   directory probe work while keeping exact acquire ordering (proved equivalent
   in =BindingReadActivationRefinement.lean::singlePage_equiv_dualPage= and
   =activation-equivalence/harness.c=).
2. *Authenticated =___primitive_ref= fast path* (=vendor/gambit/lib/_mem/global-bindings.inc=):
   When =ps != 0 && ps->context != 0 && ps->context->binding_view.vm == ___VMSTATE_FROM_PSTATE(ps)=,
   =___primitive_ref= reads directly via =primitive_value(view_vm, g)= without
   re-entering =root_writer_open(ps)=. Whenever =binding_view.vm == 0= (during
   GC root freeze, parking, raw native entry, or context exit), execution falls
   back to =root_writer_open(ps)= unchanged.
3. *Generated-module =___GLOBALVARPRIMREF= fast dispatch* (=vendor/gambit/include/_gambit/declarations_end.h.in=):

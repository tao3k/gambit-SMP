** Identity

| key | structure | rule | caveat |
|---+---+---+---|
| allocation | VM + StorageId + generation + checked extent | Allocator owner publishes identity before any derived keys | Raw address and refcount cannot issue ownership |
| view | Parent StorageId/generation + offset/count + provenance | Known contained view shares parent identity | Containment without provenance is insufficient |
| slot | Allocation key + schema word offset | Physical aliases receive one canonical key | Native pointer/key adequacy, process/VM ownership and concurrent overlap completeness open |
| registry | EntryId + entry generation + immutable SlotUseSpec | Publish roots, owners and metadata together | Arbitrary idempotency ledger and entry reuse not modeled |
| payload | Semantic binding generation, separate from storage/GC | Alias freezes source; independent copy preserves old binding | GC relocation is not semantic setter execution |
| lease | SourceId/generation + LeaseId + binding policy | Exact old lease completion releases writer exclusion | Fixed model identities do not prove arbitrary concurrent lease accounting |

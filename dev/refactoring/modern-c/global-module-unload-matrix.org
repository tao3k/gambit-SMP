|---+---+---+---+---|

| aggregation | Owner-keyed receipts form an idempotent mask rather than message count | Complete closed manifest and exact receipt tag match | Duplicate same-owner receipt cannot replace another VM or module receipt | All-VM and raw native closure not established |

|---+---+---+---|

| parallel-VM | Independent VM local drains avoid process-wide stop as a default | O(O) owner manifest and receipt aggregation; per-borrow admission bookkeeping | No benefit if all callers remain raw or global shutdown is the only release point |
| GC-maintenance | Explicit child custody avoids forgotten descriptor readers | Task admission acceptance and exception reconciliation overhead | Does not eliminate captured frame/root scanning |
| incremental-code | Reusable immutable module/image summaries allow old/new generation coexistence | Invalidation on ABI label/OFD constructor and image membership changes | No old generation may be dropped merely because a new artifact exists |
| native-FFI | Separate proc payload root from converter/destructor image ownership | Native callback registry drain and raw escape fallback | All required support is expressible in modern C; no incremental Zig benefit proved |

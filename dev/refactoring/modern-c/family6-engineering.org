** Shared facts and independent invalidation

An authority observation needs owner, physical region identity/generation,
extent and access. Bind its use to source/image, activation, write group and
attempt. Track root-view and cursor revisions independently of region reuse.

** Immediate arithmetic direction for Grok

Under the declared nonnegative root/copy counts, establish =k <= INT_MAX-n=
before evaluating =n+k=. A positive-result test after the addition cannot
repair signed overflow that has already occurred. Refusal must preserve the
same ownership and measured-demand obligations as other planner refusals.

For the accounting policy assumed by the current capacity harness, let =B=
be a nonzero byte cap, =W= bytes per word, =S= usable words per section and
=T= occupied still words. First obtain =C=floor(B/W)= and require =T<=C=;
then compare section demand against =floor((C-T)/S)=. This form avoids
overflowing a section-count product or subtracting still usage from an
insufficient cap. A zero cap retains the existing unlimited-cap convention;
it does not remove the checked integer-sum obligation. Prove the equivalence
with the runtime's actual accounting policy before using it as a native
capacity guarantee. Physical allocation bytes and logical heap-budget words
are different quantities, so =SECTION_BYTES= is not a drop-in replacement.

This is a concrete candidate repair direction for the maintained planner,
not an implementation in the harness or a finding that the extreme overflow
input caused the historical header failure. The existing failure traces and
byte-budget/integer-overflow Recipes provide the local old/new controls.

** Select an experiment from the distinguishing evidence

| Observation | Next investigation | Distinguishing result |

| Failure before emission | Pair identified hosts on the same module and formal prelude; reduce syntax/dependency-preserving input when useful | Same first binding, invariant or fault signature preserved in a smaller case |

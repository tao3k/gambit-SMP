Safety-model closure does not certify native caller coverage, C23 execution or performance.

** Gain

| key | saved | added | condition | status |
|---+---+---+---+---|
| escrow | reuse existing node/token payload; no blanket deep snapshot copy | one independent in-flight record across pop and abnormal exit | stable record prepared before ownership gap; exact source identity | conditional |
| split-receipts | 0 effect-as-completion inference; 0 blind token/node retries | two operation identities/receipts or one qualified non-abandoning completion chain | native consumption and pool return can be irreversible separately | conditional-model |
| same-thread-release | reuse ordinary Tcl pool on its qualified native owner | unknown owners keep affinity; handoff metadata does not move allocator obligations | no cross-thread node pool return without explicit allocator migration proof | source-bound |
| resolver-fusion | one mapping critical section can fuse validation and record pin | existing pin lifetime beyond lock; stable resolver and closed admission still needed | all mapping readers/close/reuse obey same authority | conditional |
| record-reuse | drop heavy done record after pins/producers/raw routes drain | generation identity and resolver grace; long-lived resolver state and unknown records | no-wrap refusal and no permanent arbitrary history promise | design-only |

** Consumer

| key | source | access | lifetime | limit |
|---+---+---+---+---|
| expression-node | expr | TclNRRunCallbacks -> ExprObjCallback data[0]/data[1] -> Restore or Discard -> return -> node free | data points inside node; token and result objects have separate endpoints | foreign escape before generic free has no normal receipt |
| rewind-node | rewind | RewindCoroutineCallback restores snapshot then returns to dispatcher | caller Env snapshot scope and node survive until last use | full coroutine exit product remains unresolved |
| state-cleanup | discard | decrement error/result object refs before freeing snapshot state | exact original token operation | unknown may be partial or already freed; pointer is not recovery handle |
| small-pool-free | pool-put | TCLNR_FREE -> TclSmallFreeEx -> selected object storage service | owner thread/allocator until put and node last use | not every compile configuration uses this pool branch |
| typed-query | parent-model | borrow live resolver -> validate generation -> pin record before unlock | pin outlives map lock until reader last use | no record exposure while candidate only validated |
| mapping-reuse | parent-model | close under same authority; wait record pins; retire; wait anchor readers; publish new generation | record and map/identity graces are separate | process resolver still lives; lock-free alternatives not proved |

** Issuer

| key | source | signature | gap |
|---+---+---+---|
| dispatch-owner | pop | pre-pop registered stable escrow and original Env/thread/source identity | current callbackPtr local is not durable abandonment custody |
| token-endpoint | expr | exact callback Restore/Discard normal return or backend receipt | partial object decrements/state free may have happened on unknown return |
| node-owner | pool | known last callback data use and owner-affine pool return | pool mutation/ACK and node address reuse need independent control |
| resolver-owner | parent-model | live lock authority joins generation check with pin acquisition | not implemented by atomic pointer load then refcount increment |
| retirement-owner | parent-model | closed record entry, final pins, exact completion and sender/raw-route receipts | unknown lock/callback/delivery cannot be erased to produce zero |

** Obligation

| key | status | condition |
|---+---+---|
| handoff-safety | conditional-model | independent escrow before pop; token and node receipts distinct from effects |
| source-cuts | source-bound | pop/call/Restore/Discard/pool-free last-use boundaries in fixed local source |
| native-escrow | unresolved | record prepared without unsafe callout; owner-thread and exact callback/source identity retained |
| unknown-completion | unresolved | no retry after effect unknown; same-operation backend receipt or non-abandoning tail required |
| resolver-native | unresolved | live process resolver lock really covers mapping check and pin; abnormal lock holder custody |
| native-generation | unresolved | all raw readers/senders excluded or drained; no-wrap and identity tuple validated before pointer exposure |
| c23-refinement | unresolved | effective mutex/atomics, Tcl thread owner and loaded ABI; full product with Gambit roots |

** Native replay without another framework

their internal replay/shrink controls, then removes the executable. For a
standalone replay, use that same compile recipe in =tests/= of the exact
configured source tree and retain the executable:

#+BEGIN_EXAMPLE
../gsc/gsc -:~~bin=../bin,~~lib=../lib,~~include=../include -f -exe -cc-options "-DHAVE_CONFIG_H -I../include -I../lib" -o root-task root-task.scm
./root-task -:p1 --replay TRACE
#+END_EXAMPLE

=TRACE= is [[file:../../../tests/fixtures/vm-root-task/vm-minimal.scm][VM data]] or [[file:../../../tests/fixtures/vm-root-task/rc-minimal.scm][RC data]]. These are labeled negative invocation controls:
expect exit71, stale finish rejected, stateSCANNED/lease1 retained. They are
not positive tests expected to exit0. The data's first integer is warm-GC
count, not a version label. Fresh child destruction is test isolation,
never a production unknown-work recovery protocol.

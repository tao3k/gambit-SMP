* Blocking findings

** Startup-ready calls have no implementation in this tree

Both conditional Scheme implementations of startup invoke =##startup-ready!=
before enabling interrupts, and =##cvmr= invokes =##current-vm-resize-ready=.
The source search finds calls in =_thread.scm= and in two focused tests but
no definition or primitive registration. Checked-in =_thread.c= still calls
=##current-vm-resize=. A build using generated C therefore exercises a different
startup path. A build regenerating Scheme cannot discharge the new calls with
the reviewed tree alone. The lifecycle owner needs to supply the real
ready/resize protocol and matching generated artifacts as one coherent delta.
Verify partial create, ready rejection and unknown outcomes under the
existing budget, and match the Scheme and generated binding identities.

** Stack span checks do not bound all census reads

=capture_continuation_source= records a validated owner and span and checks
the first return-address cell. =census_continuation= then steps by frame
size until equality with =stack_break=. Its descriptor helper bounds the
frame by the semispace end. A descriptor can step over =stack_break= while
remaining inside that semispace. The helper also reads the saved RETI label
before validating that slot, and =census_capture= performs its first return
load before validating the captured stack coordinate. The copy endpoint's
later extent check cannot protect these earlier reads.

Carry an admitted source interval or an explicitly admitted break-link
transition through the census. Validate the saved-return location before
loading it. Check each next frame against the logical break before reading
the link or scanning slots. Acceptance should distinguish a valid frame that
ends exactly at the break, a malformed frame that skips it within the same
half, and a RETI or captured stack link outside its admitted span. Preserve
the owning task on refusal and ensure no forwarding or parity flip occurred.

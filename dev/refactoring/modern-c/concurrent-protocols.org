This is the retained two-protocol checkpoint. The subsequent layout ownership
replacement and successful incremental regression campaign are recorded in
[[file:hash-layout-results.org][the current layout/native result matrix]]. The
earlier failure packet below remains historical evidence, not a current failure
claim against the repaired source.

This work concerns distributed responsibility inside one shared-memory VM:
execution contexts, root domains and collector workers. It supplies no
cross-machine message, partition, crash-detector or network liveness contract.
The refactoring remains modern C with Gambit's shared Scheme semantics and
multi-shot continuations. No Zig dependency is introduced.

[[file:models/sysml/root-worker-exit.sysml][SysML]] owns the components, QNT
actions, C boundaries, bounds and distinct proof responsibilities. The native
projection drives [[file:root-worker-exit.org::root-phase-realization][Org views]]
and [[file:diagrams/root-worker-exit.d2][D2]]. This report records observations
and unresolved obligations; it is not another architecture specification.

* What was missing, and what now executes :assurance:
:PROPERTIES:
:CUSTOM_ID: protocol-execution-chain
:END:

Previously, edited QNT files and passing named traces were not connected to
an executed SysML-selected assurance chain. A file link did not establish
which C transition implements an atomic action or which premise is absent.

The existing projection tool now selects two =ProtocolBinding= instances and
nine =ProtocolStep= boundaries. It checks all 26 declared action names against
the actual QNT modules and covers each with an explicit C boundary disposition.
An existing C anchor can be located while its required adapter remains absent.
In particular, the census/planning boundary is explicitly =missing-adapter=.

The generated [[file:../../../evidence/research/capacity-admission/protocol-final.recipe.json][research recipe]]
uses existing =quint.parse=, =quint.typecheck=, =quint.test= and =quint.verify=
capabilities, followed by the existing evidence evaluator. There is no new
model executor. Environment-resolved model tools are observed in
[[file:../../../evidence/research/capacity-admission/protocol-tools.json][the tool identity record]];
the framework seal must actually contain them. A native-build-only seal does
not become a Quint toolchain by passing different arguments to a sealed run.

[[file:../../modeling/ascent/root-worker-exit.rules.scm][The actual ASCENT DSL]]
joins model source digests, observed test/safety/counterexample results and
action coverage. =rweProtocolScheduleChecked= cannot imply
=rweProtocolCRefined= or retirement. No C-refinement facts are supplied.
The surrounding LLM reviews premises and counterexamples; it is not a
separately invented proof service or a source of trusted checker verdicts.

QNT is not asked to prove integer packing for arbitrary heaps. Lean is not
given another copy of the worker scheduler. The bridge is an explicit
refinement premise, not an overlapping second proof of the same state machine.

* What the concurrent contract now rules out :counterexample:

- Publishing a plan before deduplicated census completion or reservation ACKs.
- Flipping after only one participant observed success, or returning refusal
  before every participant observed the common decision.
- Releasing source roots when a reservation result is unknown.
- Allocating the marker before the procedure/input root is registered.
- Treating a close request as cancellation of an already admitted writer.
- Scanning while a root writer holds the atomic store permit, or resuming a
  moved root without reload.

These are properties of the bounded target protocols. The current C collector
does not acquire the missing complete capacity plan merely because the model
forbids an early flip.

* Native failure remains a separate obligation :native:gc:
:PROPERTIES:
:CUSTOM_ID: protocol-native-boundary
:STATUS: HISTORICAL-NATIVE-CAMPAIGN-DENIED
:END:

The retained native SFUN candidate passed its root-bank callback test, including
collecting string conversion, nested callbacks, and object/int/void result
forms. The overall campaign nevertheless failed. The native
[[file:../../../vendor/gambit/tests/smp/gc/index-traversal.scm][single-writer table traversal]]
revisited an unchanged key after GC in its visitor. The
[[file:../../../evidence/research/capacity-admission/index-traversal-failure/receipt.json][retained failure packet]]
contains the actual source and failure artifacts. An earlier p11 compiler
failure with duplicate generated global entries is retained independently in
[[file:../../../evidence/research/capacity-admission/sfun-failure/receipt.json][its own packet]].

The table failure exposes a distinct physical-layout responsibility: reference
repair must not silently invalidate a live physical iteration cursor. Native
GC address-index rebuilding, read-only access and writer-owned layout changes
need a joint contract. It is not proved that this alone explains the earlier
p11 compiler failure. The two passing root/capacity models do not cover table
iteration; no success is inferred from a later unrelated compiler pass.

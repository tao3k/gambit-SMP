** Actual source gap and replacement

A source borrow retains canonical storage through moving GC. It does not grant
an arbitrary caller the activation's right to mutate argument slots. The old
common writer inferred span authority from a borrow count of one. The old
SFUN adapter checked record owner/root pointer but not ROOTED/ACTIVE kind.
Thus a retained REVOKED record could still change an argument cell. This is
an actual legal live-record sequence, not a freed-pointer or fabricated owner
counterexample. The baseline witness compiles the same new fixture against
exact4b9ac843 artifacts, kills a real marker twice, observes retained bank/entry
counts, refuses marker/call reentry, then exits75 on the unexpected successful
argument store. Its result and binary/source hashes are retained.

Registration had a second policy bypass: the same-domain early return occurred
before the source OPEN/owner/not-joined decision. Registration now locks the
existing source, checks the same owner predicate, and only then admits an
idempotent already-registered block. Refusal neither links nor mutates counts.
Wrong-owner/frozen controls are confined nonallocating states; they are not
claims of an independently reachable GC transition. GC and revoke are separately
exercised through real production consumers.

** Replace a timing assumption with lifetime ownership

The [[file:../../../evidence/research/retained/modern-c/pr-gsc/original-control-failure.json][unmodified campaign]] completed p1 7/8 and p2 8/8 in 20.239305 s.
The p1 control raised =inactive-thread-exception= before its second interrupt.
Its finite =waste-time= ratio does not keep the target alive across scheduling
and compiled/interpreted speed differences. A runtime is allowed to finish the
target; changing that rule would violate interruption semantics.

The [[file:../../../evidence/research/retained/modern-c/pr-gsc/control-refinement.json][source refinement]] therefore changes the official test's lifetime
protocol. The target retains its original computation, then waits for =finish=.
The driver retains both interrupt calls and all original computations and
assertions. Only after the existing handler-observation loop does it send
=finish= and join before the unchanged final value assertion. One additional
assertion checks the received message. Missing interrupt delivery or wakeup
still fails under the original guards. Nothing catches the old exception,
skips an assertion, accepts a terminated target or changes the scheduler.

The exact pure transformation reproduces the published fixture from its
original bytes and refuses missing/duplicate anchors or reapplication.
This qualifies an explicit test-source refinement; it does not claim that
the untouched original control passed or that the scheduler was reconstructed.
No additional Scheme test file is manufactured.

** Complete producer-to-consumer contract
- Immutable study claims retain their original commit/blob/bytes and their status.
- =copy_live_view= deliberately initializes isolated mutable fixture files from
  checked declared bytes; immutable locators are removed only from that fixture.
  Byte and range checks remain, as do mutation/restart/GC-layout assertions.
- =copy_output_observations= projects source origins together and borrows the
  genuine Git object DB. No checkout, transcript restoration or build receipt.
- =input_attestations= distinguishes verified =package:= assets from repository
  inputs. The existing API owner validates its inventory before and after use;
  per-input digests and unknown external-owner refusal remain mandatory.
- All three consumers use the same labels: ordinary Clue views, unavailable-view
  attestations and direct relation reads. No parallel identity registry is added.
- Commit author setup is local to the isolated fixture, never global.

* Causal result and its limit

The preceding guard candidate passes complete bootstrap but all three p11 compilations fail with exit 70. Read-only geometry puts both the repaired cell and its referenced object in current tospace. Observations include pair and closure fields, so it is unsafe to describe that failure as missing nominal heap capacity.

On the ownership successor, a binary-calibrated read-only breakpoint reaches =scan+684= with state =OWNED= (2), body =0xca50299e8= and header =0xb000=, before the duplicate counter increment or any field processing. The requesting caller is =mark_reachable_from_marked=. This confirms a second ordinary scan request against an already owned destination object. A 22-word vector's ordinary scan would consider 21 slots after its separately owned first-field Tail. The new request obtains no second writer.

This observation is not a universal reconstruction of the FIFO/frontier producer, arbitrary frame maps or every historical SIGBUS. The separate 20,000-closure graph integrity control passes but reports duplicate counts =(0 0 0)= in its last three GCs; retain that negative observation rather than inventing saved work. No throughput claim follows from the one observed GSC event.

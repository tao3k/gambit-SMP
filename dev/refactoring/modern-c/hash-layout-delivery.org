working checkout is not the tested or submitted source tree.

The collector repairs references and removes unreachable weak entries while
preserving physical slots. Native reads first probe the current key and, on a
miss with address debt, search current slots without mutating them. Set, delete
and path-compressing union/find own reconstruction. This replaces the old
collector-count-selected eager/lazy policy rather than adding a failure check.

Both real producers in =lib/_system.scm= use the same construction lifecycle:
=##implode-gc-hash-table= for text reconstruction and the binary decoder begin
with strong key/value scanning, install their payload, then publish final weak
and index flags in a nonallocating commit. The binary decoder's =alloc!= roots
the shell before recursive field decoding. Abandoned construction remains under
ordinary Scheme root/exception custody; this is not recovery from unknown raw
native writes.

* Gambit semantic questions :questions:

Generated C, proper tail calls and multi-shot continuation machinery retain
their existing contracts: this tree changes neither GVM lowering nor frame
descriptors, continuation-copy, restoration or dynamic-wind consumers. It
strengthens the GC transport contract beneath shared Scheme values and native
traversal, while keeping Scheme hashing outside GC. No OCaml one-shot control
restriction is introduced.

The mathematical premises remain explicit: valid table storage with an unused
slot for probing, fully repaired references before mutator resumption, stable
semantic hashes, rooted traversal state and exclusive mutation. Public
=table-for-each= restrictions are unchanged; the fixture's private pure read
does not grant reentrant same-table mutation. Generational GC, independent
worker admission, arbitrary old images and the twelve SMP requirements remain
outside this REV.

Reproduction inputs are the selected vendor Git tree, its recorded profile,
the vendor Scheme fixtures and the commands in the structured observations.
Bulky raw streams stay under task-cache retention; they are not an alternate
maintained implementation or durable source dependency of this document.

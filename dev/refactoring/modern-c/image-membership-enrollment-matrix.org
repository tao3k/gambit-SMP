** Gain

| key | avoided | added | condition |
|---+---+---+---|
| completeness | Avoid full-VM rescans on each repeated receipt; cache sealed membership | O(M+E) member/effect metadata and O(V+P) stable owner ledger | M members E initialization edges V owners P pending; closure must be complete |
| parallel | Separate VM topology lock from callbacks and image lifetime control | Short authority operations per accepted enrollment/borrow | Parallel benefit conditional on lock contention and absence of untracked native aliases |
| incremental | Keep old/new generated module generations concurrently without global restart | Generation-keyed handles and ABI dependency invalidation | Artifact replacement is not permission to free old captured frames |
| permanent | Qualified handles permit eventual per-image release instead of whole-process retention | One stable handle per identity plus observer drain metadata | Reclaimable bytes ZERO while any untracked permanent/raw alias remains |
| duplicate | Idempotent keyed receipt avoids duplicate completion accounting | O(V) receipt keys or equivalent compressed set | One owner receipt cannot stand for another without proven coverage |
| language | Same modern C ownership ABI shared by GC FFI and module service | Explicit generated adapters and source refinement | No runtime speedup or incremental Zig advantage established |

** Identity

| key | structure | rule | caveat |
|---+---+---+---|
| fresh | InvocationIntent plus external AttemptId | Mint once per direct admitted semantic restore | Raw primitive spelling alone gives no trusted navigation proof |
| navigation | Parent restore transaction plus qualified call-site role | Keep ticket through helper and arity packing | before/after user procedure invocation may itself start a new semantic restore |
| scheduler | ExecutionContextId plus existing TicketId | Resume same activation with carrier handoff | Direct ##thread-restore! outside known scheduler remains unqualified |
| foreign | HostEntryId plus child TicketId | Nested callback child differs from conversion OperationId | Static MLBL proc does not prove Scheme arguments rooted |
| bootstrap | SourceRootId plus generation plus pre-reserved carrier | Root transfer and GC reload before allocating guard or marker | Raw C local, volatile or slot address is not a registration witness |
| receipt | Full GuardId immutable across restored data | Dispatch exact identity regardless of ambient current | Real owner signer, finite generation and reclamation still open |

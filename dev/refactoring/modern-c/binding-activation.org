** Conditional refinement :source:memory_order:

1. =___lifecycle_enter= authenticates the carrier and actual entry. The context
   identity equals the admitted VM; tail/trampoline and nested return preserve
   that logical VM during the host activation.
2. Ordinary reads resolve the same canonical cell as the previous resolver.
   Directory growth retains existing page addresses. Reads never cache moving
   Scheme payloads or a stale directory generation.
3. The old primitive cell and flag helpers can perform two directory lookups;
   the new helper shares one page lookup. Presence/value acquisition and local
   overrides remain unchanged. =___PRMCELL= already performs the template acquire.
4. Root freeze/refresh is ordered by the existing cooperative collective.
   =prepare_mem_pstate= and RC reopening precede the first final barrier;
   coordinator refresh precedes the second barrier and resumed execution.
5. Last entry retains context through its final identity clear. Unknown join,
   release or cleanup cannot grant reclamation through this new field.
6. Version/structure-prefix checks reject old modules before the added fixup
   state is accessed. Appending a native identity changes ABI; old native
   consumers require recompilation, while Scheme names and generated-C inputs
   remain reusable. A full current Gerbil rebuild is not claimed here.

** Lessons and counterexamples

- Duplicate slot arrays/registries add memory and lifecycle work; they were
  removed from the prototype, not falsely counted as baseline retirement.
- Per-host checks and metadata bookkeeping alone did not give the expected
  request benefit. Same-runtime macro ablation produced mixed results; it is
  not proof that one check explains all whole-runtime regression.
- The final design consumes existing lifetime authority and retains only VM
  identity. No extra permit/epoch state is maintained solely for observation.
- An early capability guard silently selected legacy macros. Real compiler
  preprocessing, rather than header text, now verifies the actual path.
- The proposed second acquire was wrong: PRMCELL already acquires and needs
  an lvalue. The real compiler rejected it; the failed source/output custody is
  retained. Only the declared missing archive was rebuilt, never relabeled reused.
- Official lifecycle p1 and default-SMP invocation are different contexts;
  missing the original argument created a false attribution. Both histories stay.

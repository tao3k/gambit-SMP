** Responsibility replacement and semantic correction

The private constructor roots the captured Scheme procedure in the existing RC
allocation before vector allocation, reloads its relocated value afterwards,
then installs the initialized vector. Returned registration success transfers
ClientData to Tcl; returned rejection runs the existing delete routine locally.
Vector-allocation failure releases only the RC allocation. A null interpreter
is refused before allocation. No-return/unknown registration grants no rollback
receipt. Tcl's returned ownership boundary was reviewed against
[[https://github.com/tcltk/tcl/blob/core-9-0-3/generic/tclBasic.c][the Tcl9.0.3 release source]]; this is release-tag source evidence, not a claim
that the loaded binary was rebuilt from that checkout.

The original GSC-generated =___arg2= is a live =___CFUN_ARG(2)= cell, not a stale
C scalar. Extraction into a C helper requires explicit rooting to preserve that
property. The predecessor replay supplies the missing SMP processor argument
and a live caller cell; it is not an exact-byte predecessor executable. Its
counterexample concerns retained ownership on returned rejection.

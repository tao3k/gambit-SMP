** Gain

| key | saved | added | condition | status |
|---+---+---+---+---|
| prepop-reserve | 0 required allocator calls during admitted claim/register/pop itself | P preinitialized descriptors; memory P*S bytes before allocator overhead | capacity and root/native-owner setup occur before critical registration | conditional |
| exhaustion | 0 pop with missing/unknown escrow; no waiting on own nested slot | bounded profiles may refuse/pause before pop; unbounded nesting needs safe growth policy | P covers maximum active + retained debt or admission fails | conditional-model |
| narrow-tail | one qualified no-callout pool-put plus completion publication may fuse | variant/effects proof and cancellation/nonlocal-exit policy | ordinary token cleanup remains callout-capable; no generic transaction | unresolved-native |
| resolver-return | reuse common mapping authority and existing exact guard ownership | unknown lock/pin debts retain owner; no speculative decrement or forced unlock | known owner landing and coherent pin accounting | conditional-model |
| runtime-value | 0 runtime paths retired; no measured speedup | stable pool service, receipts and entry/landing adaptation remain | net benefit depends on avoided allocation, duplicate wrappers and bounded retention | design-only |

** Consumer

| key | source | access | lifetime | limit |
|---+---+---+---+---|

| cache-return | node-tail | qualified local cache stores or unqualified helper/debug/global branch | original Tcl native thread and selected allocator | metadata handoff does not migrate node release |

| map-reader | parent-model | pin stays after lookup lock release; return under matching authority | stable guard/lease operation through last payload access | unknown return is a debt, not a zero pin count |

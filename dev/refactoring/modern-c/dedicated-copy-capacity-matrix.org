** Claim

| key | mechanism | condition | result | gap |
|---+---+---+---+---|
| source | Validated union of old heap objects and old stack-frame footprints | Canonical disjoint source charges; old epoch immutable; strong and weak budgets combined | 64-bit U<=Q; 32-bit U<=Q+A<=2Q | Counter arithmetic and header-origin lookup do not establish source partition |
| packing | C=H-3; maximum grant G<=C; threshold charge T | Every no-fit closed section has distinct charge at least d=C-G+1 | If B=U+T and B<(K-P+1)d, K heap sections suffice | Source injection, all writers and threshold charging still need refinement |
| dedicated | Reserve P stack sections separately | R+J fits each dedicated section and all intervals disjoint | Physical target N>=P+K+E | Global request placement and source/target census remain open |
| semantic | Shared plan unsupported is internal outcome | Try dedicated or other qualified plan without changing program values/control | Cannot map conservative envelope refusal directly to Scheme OOM | Total fallback, precise OOM policy and emergency failure continuation open |
| growth | Detached reservation batch with stable owner and old source manifest | Actual destination count only; no native callback/GC during reserve | Partial success retained for retry or retired after collective result delivery | Current adjust_msections is not transactional detached reservation |
| unknown | Stable completion owner retains roots, plan and uncertain grant | No setup/free from unknown result; exact token resolution required | No timeout inference and no coordinator-only release | Native orphan delivery and no-fail coordinator service open |

** Memory

| key | publication | consumer | gap |
|---+---+---+---|
| source | Close source membership before ordinary reads | Pin old sections and copy manifest away from mutable header | Existing phase barrier not full C11 provenance proof |
| reserve | Private initialized grants -> release completion token | Owner acquire actual identities and counts | Unknown can own allocations absent from known lower-bound count |
| commit | Release immutable accepted plan; member acquires exact generation | Old metadata readers retired before replacement and setup | Header commit is not permission to release old payload blocks |
| failed | Known failure plus every last-reader/result acknowledgement | Only batch-private new blocks may be reclaimed | Never shrink below roots or other resize grants |
| copy | No-fit charge and source credit consumed exactly once | Separate forwarding CAS from initialized payload READY | Weak phase shares same budget; cancellations do not reset it |
| resume | Copy complete then post-GC fudge and executable headroom | Old roster completes same sync-op result before Scheme resumes | Failure after flip cannot reuse pre-setup rejection protocol |

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| snapshot | Use old source allocation envelope instead of exact liveness oracle | Validated extent/identity census and generation pins | No claim that current factor-two counters are already sufficient |
| dedicated | Protect continuation without allocating a second stack section | Reduced heap borrowing may require destination growth | Net benefit depends on live fraction and grant sizes |
| packing | Account for bounded fragmentation before forwarding | Potentially conservative N and reserved unused capacity | Tighter qualified G yields useful bound; generic cap yields d=1 |
| retry | Reuse known partial native allocation | Stable batch ledger and no ambiguous new attempt | Unknown attempt cannot be retried until resolved or separately fenced |
| transaction | Avoid unsafe in-place rollback with live readers | Candidate metadata copy and commit/retirement protocol | Modern C sufficient; existing adjust_msections not silently treated as transaction |
| concurrency | Reuse P current worker frontiers and existing allocation lock | Static packing headroom includes P private end sections | No measured speedup or net memory saving established |

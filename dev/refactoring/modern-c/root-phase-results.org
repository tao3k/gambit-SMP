[[file:root-worker-exit.org::#root-phase-realization][The native SysML projection]] owns the responsibility cut. The implementation
now dispatches preparation, strong roots, wills and still-object cleanup through
the actual frozen origin's task. A claim names epoch, incarnation, phase and
worker. Only exact predecessor completion followed by physical phase drain
allows the coordinator to publish the next phase. Strong-root completion alone
cannot thaw the origin.

The old collective still supplies physical writer stop, phase drain and
whole-round resume. The allocator still supplies collector space through the
stopped context. This is a qualified root-domain replacement, not completed
independent-worker retirement or a generational collector.

Sweep eligibility preserves foreign release thread affinity. It is not a proof
that arbitrary foreign destructors can migrate, block, reenter Scheme or create
late roots. Unknown cleanup/task results stay owned; no speculative duplicate
scanner or physical free is authorized. Phase fields use ordinary C accesses
only while the existing collective excludes phase-transition readers. Replacing
that collective requires a new, source-refined exclusion mechanism.

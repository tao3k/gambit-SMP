Safety-model closure does not certify native caller coverage, C23 execution or performance.

** Gain

| key | saved | added | condition | status |
|---+---+---+---+---|
| real-holder-classification | avoid treating all snapshots as native string/freeProc owners | nonempty legacy-to-object conversion already allocates n+1 bytes and copies n bytes; object/token references persist | native string conversion may free before modern save returns | source-bound |
| restore-escrow | 0 admitted loss of saved A or overwrite of protected C while B release unknown | simultaneous A/B/C custody and callout record | managed result interception or explicit refusal; raw Tcl not proven equivalent | conditional-model |
| completed-records | O(L) completed records after proven closed issuer/readers instead of keeping all history forever | stable generation anchor plus retained records for live producers/readers/result debt | L counts all not-yet-qualified identities; can remain unbounded without closure | conditional |
| unknown-disposal | 0 admitted blind retries or record retirement based solely on done | opaque OperationId/result/provider holds retained indefinitely if needed | known backend receipt and remaining payload roots are separate | conditional-model |
| runtime-retirement | 0 current runtime paths retired; no measured speedup | snapshot adapters, observer/issuer lifecycle and native receipts | all native refinement gaps must close | design-only |

** Issuer

| key | source | signature | gap |
|---+---+---+---|
| snapshot-owner | save | exclusive saved token and result identity across Restore/Discard | legacy struct can escape; no complete holder census |
| native-callback-owner | rewind-holder | NR callback data[0] or local trace owner keeps modern state until normal endpoint | callback deletion/abandonment and whole coroutine product unresolved |
| result-owner | restore | A snapshot escrow + B disposal identity + protected C owner | not implemented by raw Tcl_SetResult/ResetResult fields |
| completion-registry | parent-model | settled InvocationId then close ACK producers and observer gate; drain prior readers | guard counts alone do not prove old raw aliases disappeared |
| generation-owner | legacy-abi | stable lookup authority rejects old generation before accessing reused record | no safe first load from already reclaimed record; wrap/anchor retirement unresolved |

** Obligation

| key | status | condition |
|---+---+---|
| custody-safety | conditional-model | A held through B disposal; C cannot be overwritten without settlement; record readers/issuers drain |
| captured-holders | source-bound | real modern local/NR callback state holders; legacy definitions/API only in captured subset |
| legacy-holder-closure | unresolved | all external legacy snapshot callers, struct aliases and abandonment paths enumerated |
| reentrant-adapter | unresolved | intercept raw result writes/free hooks or reject unsupported reentry; protected C is not current Tcl semantics proof |
| record-retirement | unresolved | stable lookup anchor, closed ACK producers, drained observers and no raw TicketId pointer escape |
| native-completion | unresolved | same-operation cleanup/free receipt; unknown cannot retry |
| c23-refinement | unresolved | owner thread, loaded Tcl ABI, release/acquire and generation no-wrap |

* Tests and architectural learning
Exact one-path tree after tool-lifetime parent; native positive phase order and early/middle failure controls through actual Make loop; unchanged configure,generator and runtime artifact identities; completed parent original checks reused by input equivalence.

The owner of staged compilation must retain failed outcome instead of allowing a later successful child to overwrite it. Error propagation is build lifecycle ownership, not runtime concurrency repair.

* Gambit questions and exclusions
First failure reaches phases caller; no later phase launched; successful sequence unchanged; original core workflow untouched; no runtime,capacity,FFI or whole SMP claim.

The existing source compiler pipeline remains intact. This improves the
engineering ownership around Gambit's staged Scheme-to-C design without
claiming a new GC, continuation representation or scheduler. Explicit source
and output identities permit reuse; success on this cut does not qualify a
different pending tree. The failing historical eight-file resource aggregate
and parked tfib programme evidence remain failed/open in their own scopes.

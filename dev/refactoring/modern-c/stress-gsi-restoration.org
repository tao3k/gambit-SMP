The break handler in =vendor/gambit/lib/_kernel.scm= calls
=___stack_overflow_undo_if_possible= before copying a caller frame from a
physical stack address. In =lib/_mem/allocation-limits.inc= the helper checks
the first-break coordinates and the current stack/heap pointer inequality.
It then writes the intrusive free-list link to =base[0]= and switches to the
older stack. Both allocation-limit slow paths can pop that section into their
own allocation role. The free list is per carrier (=configuration.inc=), but
the fresh section cursor is shared by the VM (=heap-sections.inc=). The undo
path therefore authorizes a physical reuse even though its input marker
describes a logical predecessor.

| Physical case | Concrete producer and consumer | Admission obligation |
|---+---+---|
| Stack growth | =___stack_limit= can record the preceding section, break and frame in the first break of the new section. | A valid frame predecessor carries no independent grant to reissue the outgoing physical section. |
| Shared fallback | =next_msection_without_locking= can return the other role's section when the fresh suffix is exhausted. =set_*_msection_possibly_sharing_*= subdivides the current space. | Physical ownership must include both live intervals. Pointer inequality after a later role change cannot by itself certify retirement. Source reachability of such a stale same-round alias remains open. |
| Suffix growth | =resize_capacity_vote= first asks for GC when the current suffix is insufficient; =___reserve_resize= can adjust sections after that decision and has a distinct rollback cursor. | Do not infer a same-round escape from sharing by assuming resize grows the suffix before GC. Check whether any actual allocator path replenishes the suffix without retiring the old live view. |
| GC restore | =collection-round.inc= drains strong/weak work and obtains its resume grant, then calls =move_continuation= before publishing =restored=. | Keep source and destination grants through the move; clear the logical undo edge before publication. Physical retirement and reader exclusion remain separate premises. |

The full replacement boundary is section acquisition, optional sharing, first
break publication, undo, both free-list consumers and epoch retirement.
Reuse must be justified by exclusive interval ownership and drained readers.
An unknown result leaves the old holder responsible and the interval
unavailable to allocation. Only a transfer that closes all these callers can
retire the inferred authorization. The existing restore-admission and
copy-capacity QNT histories and Lean geometry remain their respective owners.
The source mapping above does not establish a native TFIB failure mechanism.

** First allocation after the restore

The allocator has two different bounds. The poll compares the local cursor
against =ps->heap_limit=. The physical end is =alloc_heap_limit=.
=___gc_arena_handoff= in =lib/collector.h= accepts one matching epoch and
transfers the worker's section, cursor and physical limit to the owner.
=___gc_resume_without_arena= instead installs the disjoint bottom loan.
The collector checks the remaining physical reserve and refills if needed
before =prepare_mem_pstate= publishes =context->hp= and the poll limit.
The latter leaves =___MSECTION_FUDGE= words before the physical end.

The configured host entry in =stack_operations.h.in= reloads =___R_ALL=.
Its heap component reads =context->hp=. The generated closure block at
=lib/_thread.c= L1 then uses that local cursor. The predecessor
=JUMP_CONTINUATION_CAPTURE3= builds the transient capture on the stack
through =CONTINUATION_CAPTURE= and jumps to L1. An intra-host jump can
retain the already loaded cursor. A return from GC reaches the host-entry
reload through the saved PC. L1 itself does not acquire a new grant. The C emitter charges the
sum of =targ-closure-space= before emitting the group. Its check-placement
rule includes float cache allowance and the generator's fudge constant.
For the emitted ALLOC_CLO(4UL), the bump is exactly
=4 + ___CLO_FREEVARS + ___SUBTYPED_BODY= words. The header and setup
writes fit that extent under the configured representation. The visible
check after this closure is the end of a bounded allocation region. It
cannot validate the preceding header store. The refinement obligation is that the first resumed region starts with the
new cursor and its complete emitted extent fits the same physical grant,
including when the last poll limit equals the initial cursor. Cursor
publication and host reload are distinct QNT steps.

The opt-in diagnostic now snapshots the actual destination msection and
semispace offset at cursor publication. It uses the collector's interval
predicate to admit the publication and checks that the context, section,
parity and interval still match at the generated reload and write boundary.
The two new native controls change just the section or just the parity after
reload while keeping the numeric cursor and bounds unchanged. The generated
write refuses both cases, and the parent observes all six sentinel words
unchanged. The same diagnostic image also passes the ordinary generated
write, short span, stale reload and restore-barrier bypass controls. Its
generated statements run with supplied registers and label storage, so
linked GSI execution of the full collection and resumed host remains open.

Physical retirement also consumes each frozen member's cleanup receipt.
The member publishes it after still/weak cleanup, and the existing

The check adds one roster walk per admitted collection.

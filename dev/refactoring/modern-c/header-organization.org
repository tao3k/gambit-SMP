* Namespace and responsibility boundary
** Private templates
The private source namespace is =vendor/gambit/include/_gambit/=.
Every module has a snake_case basename and a =.h.in= extension. Case-folded
names must be unique. The leading underscore distinguishes this implementation
directory from public Gambit entry points and other include directories.

Platform/compiler selection, representations, object access, GVM and stack
operations, temporary roots, module generation, FFI, context/collector roles,
processor state, VM state and global state have separate source modules.
Forward declarations have their own module; they are not mislabeled as complete
type definitions. Source order is preserved because these declarations and
macros have ordering dependencies. This split does not claim those dependencies
have already been eliminated.

** One configured public aggregate
=gambit.h.in= is the configure-probe driver. Autoconf's explicit multiple-input
=AC_CONFIG_FILES= mapping concatenates the private templates and substitutes
configuration values into the existing flat =gambit.h=. Runtime/generated-C/FFI
consumers still include that single aggregate. Conditional directives cannot
cross physical includes: guard slices are inline in the probe driver, while
each included fragment has balanced conditional scope. Driver reconstruction
is checked against the same ordered source partition.

=include/makefile.in= includes every template in revision-control and distribution
inventories and in the aggregate's direct prerequisites. The distribution rule
retains the private relative paths. Public install rules retain their existing
aggregate and version-mismatch sentinel; private templates are not public ABI.
An install execution is a separate obligation and is not inferred from a
distribution copy or unchanged install recipe.

* Evidence and conditional argument
The retained [[file:../../../evidence/research/header-organization/native-projection.json][native projection]] and [[file:../../../evidence/research/header-organization/partition.json][partition receipt]] bind the exact pre-split
native header. The baseline includes the intentional worker-role changes made
before this split. Byte equality proves the split adds no further text change;
it does not prove those preceding semantic changes correct.

1. Contiguous, disjoint ranges cover the entire baseline. Their ordered byte
   concatenation must have the baseline hash; each actual template must have its
   recorded hash. Missing, reordered or modified text defeats qualification.
2. The small probe driver is derived from the same parts. It must have the
   recorded hash, and each non-inline fragment must balance conditionals.
3. A real target config.status must transform the archived baseline to exactly
   the same bytes as the new flat public header. The output is isolated from the
   completed producer; this is an independent configuration comparison.
4. Every template edit must select header regeneration in make's dry run.
   Source distribution must preserve every relative path and byte sequence.
5. A compiled C23 consumer and full target bootstrap/continuation/GC observations
   carry their own source/profile identities. A source partition cannot stand
   in for these results, independent-worker admission or unknown-owner safety.

The first model attempt used a reserved SysML identifier and failed. That

An intermediate byte-correct partition had misleading type-domain boundaries;

records remain historical and cannot qualify the current inventory.

** Snapshot custody
Splitting at existing blank lines creates legitimate blank-at-EOF fragments.
Snapshot export/materialization preserves their exact whitespace rather than
normalizing source bytes. This opt-in uses Git's =--whitespace=nowarn=, never
=--ignore-whitespace= or =--whitespace=fix=. Path restrictions, contextual patch
application, source/patch hashes and post-application candidate hashes remain
mandatory. Other patch callers retain strict whitespace checking by default.
Negative controls require a wrong candidate hash to refuse publication.

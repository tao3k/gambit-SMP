This report describes the exact retained baseline named above. The subsequent
SFUN bank and concurrent-protocol work is recorded in
[[file:concurrent-protocols.org][the current protocol/evidence matrix]]. Its
whole native campaign is denied by a confirmed GC table-iteration failure;
the baseline PASS below does not qualify that later source.

This is a C23 runtime responsibility replacement on =modern-c=. Scheme keeps
its semantic compiler, shared objects, tail calls, multi-shot continuation
and =dynamic-wind=. Collector workers own copy requests and destination arenas;
execution contexts own RC root domains. A native carrier supplies neither
authority merely by its processor index.

The structural source is [[file:models/sysml/root-worker-exit.sysml][SysML]].
[[file:models/sysml/root-task-c-refinement.sysml][C refinement operations]] identify
the actual publication points and remaining premises. The generated
[[file:root-worker-exit.org][Org views]] and [[file:diagrams/root-worker-exit.d2][D2]]
derive from its native-tool projection; they do not define another architecture.

* Conditional complete envelope :capacity:
:PROPERTIES:
:AUTHORITY: GambitRootWorkerExit::cb0; GambitRootWorkerExit::cb1; GambitRootWorkerExit::cb2
:END:

For unique source intervals indexed by i, write s_i for source length and d_i
for destination length including its header and worst alignment. Current C
validates interval containment in the old half before reservation, with
=d_i <= s_i + 1= for the possible 32-bit heap alignment word and
=d_i <= s_i= for captured frames. Frame sizes are decoded by the existing
RETN/RETI consumers; they are not replaced by a selected compiler constant.

#+NAME: copy-capacity-composition-obligations
| Layer | Conditional obligation | Current disposition |
|-------+------------------------+---------------------|
| Source envelope | D = sum d_i <= sum s_i + A32 <= S_alloc + A32 | Local intervals implemented; complete disjoint census and S_alloc adapter open |
| Destination interval union | D + K + J + F + Hrestore - Qpre <= N * half | Placement/packing and overlap witnesses open |
| Contiguity | Every admitted d_i fits its assigned piece at that step | Actual reservation checks; full pre-flip piece plan open |
| Restore coverage | Every R context has stack, first-resume allocation and fudge coverage | Selected W<R cases pass; not every possible frame/native request admitted |
| Refusal | A common failure before flip keeps every source and has one outcome | Current exhausted-copy boundary is fatal; reversible common refusal open |

Here K counts every end marker, including empty, refill and final chunks;
J counts leading links; F includes reserved terminal words and stranded tails;
Hrestore includes all R restoration grants. Qpre is only overlap proved from
already reserved loan intervals. A refund after GC is not Qpre. Counting it as
a pre-GC saving would understate the whole-round requirement.

The legacy =words_movable_objs= doubles allocation accounting. Dividing or
multiplying that counter does not establish source identity, disjointness or
contiguous placement. The new request/settlement counters are observations,
not a live-object oracle or a proof of the complete envelope above.

The interval inequality concerns the destination halves. Native allocated
bytes additionally include whole msections with both halves, scan trailers,
still objects, RC blocks and VM descriptors. No measured peak reduction or
smaller admitted heap is claimed in this slice.

* Failure custody and synchronization :protocol:
#+NAME: copy-root-failure-matrix
| Boundary | Known refusal/return | Unknown result |
|----------+----------------------+----------------|
| Initial RC registration | Returns null without linking; caller owns its unregistered allocation; alloc_rc frees only its own refused block | No second registration or speculative cleanup of an unknown publication |
| RC payload store | BOOL refusal leaves prior root unchanged; source remains caller-owned | Raw concurrent aliases are outside admission |
| Borrow | Refcount and context debt under gate; normal last use returns both | Cell remains registered, debt retained; teardown refuses |
| Prepared copy | Current epoch/source interval recorded before arena mutation | VM request stays nonzero; worker completion refuses |
| Reserved copy | Known cancel refunds exactly private interval; known commit records source charge | Retain request and pending interval; no replay/reset from timeout or join |
| Root scan | Writers close before frozen publication; scanner owns same gate; reopen after all-R drain | No thaw from partial restore or logical owner exit |

Borrow holds a reference to the RC cell, not its gate. The collector may update
that root while the owner is waiting. Close never waits for borrow count zero;
doing so would create the GC/owner cycle this design removes.

The RC scanner holds the context gate through =mark_array= and private refill.
Other releases may wait for the root task. This is not a constant-latency
critical section. A custom allocator which enters RC/Scheme or waits for the
same owner is excluded; ordinary selected-profile allocation does not grant
that extension authority. Incoming native pointers must already be owned;
locking after dereferencing an unowned ClientData cannot repair its lifetime.
First registration requires exclusive custody of the unregistered allocation;
two concurrent first registrations of the same raw block are not admitted.

* Benefit, cost and peak accounting :decision:
#+NAME: copy-root-net-benefit-matrix
| Change | Work/risk actually removed | New necessary work | Quantitative boundary / refutation |
|--------+----------------------------+--------------------+-------------------------------------|
| Source-owned arbitration | Managed forwarding loser makes zero reservations/refills | Section gate and revalidation | One word per allocated section; same-section contention may outweigh removed speculation |
| Persistent bounded request | Unknown pre-refill source custody is no longer only a C local | Per-request interval/epoch validation, two CAS and one fetch-clear, source counter addition | Per stored worker: sizeof(gc_copy_request) + sizeof(SIZE_TS); no throughput saving measured |
| Closed RC domain | Chain/payload/scanner races in admitted endpoints | Gate operations and RC scanner serialization | Per RC block: one pointer; per context: sentinel pointer + SPINLOCK + two WORDs, plus layout padding |
| SFUN root borrow | Unregistered procedure root across marker allocation | Two borrow refcount updates; explicit-procedure entry also allocates/frees one temporary zero-payload RC block and drops its creator reference | Existing C-closure entry reuses its RC cell; rooted startup avoids the temporary block. Frequent explicit-procedure callbacks may cost more |
| Failure retention | No silent reset/replay of an unknown copy/root owner | Retained cells/requests; blocked teardown or round | Fixed control records do not bound retained payload memory or guarantee recovery |
| Exact build reuse | Repeated configure and Scheme generation avoided for body-only C retry | Native Make dependency work and source/identity validation | Same source workspace, zero copies, 51 generated C files unchanged; no larger heap or watchdog |

Both worker and context descriptors are embedded for =MAX_PROCESSORS=, not
merely active W or R. Under LP64 with the two-word ticket lock and ordinary
8-byte alignment, the declared additions imply 64 bytes per worker and
40 bytes per context, plus 8 bytes per live RC block. Those are conditional
layout calculations, not measured peak memory. =sizeof= on each qualified ABI
is authoritative; a mutex lock or another target changes the calculation.

Correctness improvement is demonstrated for the selected paths. Positive
throughput or whole-round peak benefit is not established. The full capacity
and writer-closure conditions remain prerequisites of whole SMP admission.

Three root domains exercised W=1,2,3,1; borrowed RC cells were the sole native
references to moving cyclic values. Cleanup rejected new RC root publication
and SFUN marker entry before Scheme effects. The actual callback tested the
current call ABI. Independent C Generic checks covered RC declaration/table
signatures. Multi-shot map, wide roots and unknown unpublished startup join
isolation also passed; three healthy members completed three GC rounds.
The final source-envelope check permits a worker with zero copied objects and
requires each worker's actual copied words not to exceed its settled source
spans. Requiring every worker to copy something would introduce an invalid
fairness/partition premise into the decoupled scheduler.

The first campaign failed because the added fixture omitted the temporary
required by =VECTORP=. Its compile failure and denied verdict remain retained.
No timeout or heap was enlarged. An independent SysML input-drift rejection
is [[file:../../../evidence/research/copy-root-admission/model-input-drift/receipt.json][also retained]];
native-tool success without stable source inputs is not a current-model
credential. The projector now selects the queried packages' namespace closure
from repository SysML, validates it with the strict native tool, and checks
source hashes before and after parsing and again before ASCENT. Unrelated
work-in-progress packages are not grounds for claiming this component changed.
The final closure contains 78 input models, seven realizations and 21 C
refinement operations; native validation reports zero errors and warnings.
ASCENT passes the positive composition and all 17 guard-removal controls.
Five capacity premises, three native aggregate boundaries and all six complete
writer-family enforcement obligations remain open. A source replacement is
not the same claim as complete family enforcement.

* First patch boundary
MC-SCOPE is the first source edit: bounded resident control schema plus no-effect lifecycle operations. It cannot activate a raw marker or new GC path. MC-GENERATE through MC-THREAD form the connected ownership slice; MC-SELECT is the first behavior switch. MC-RETIRE follows complete caller and native evidence. No second Zig ownership implementation is required.
Future acceptance must independently check exact-source generation, clean bootstrap, selected GCC/Darwin profiles, GC during marker allocation, nonzero processors, nested continuation/exception escape, failed/unknown join, helper interruption and shutdown draining. These are planned checks; none was run here.

** QUALIFIED_C_TARGET Frozen root population and writer lifetime
:PROPERTIES:
:CUSTOM_ID: MODERN-C-RESULT-frozen-roots
:RESULT_ID: frozen-roots
:STATUS: QUALIFIED_C_TARGET
:END:

Generated/reflected globals, RC nonzero processor, stack/bank/multi-shot continuation, symbol/keyword and VM roots, real close/store races, root relocation, exit/failure custody and real implementation replay/shrink. Run complete applicable original GSI/GSC consumers; any scoped baseline disposition requires its own actual source proof.

Benefit: An explicit frozen root union can be scanned independently of a running carrier; no completed leaf count proves that union.

Cost: Actual authority acquisitions, root metadata, retained borrows and scan work must be counted; throughput and RSS remain unmeasured.

Falsifier: A raw admitted writer, unpinned alias, incomplete frame or late store remains; a missing or related failure cannot be dismissed as baseline.

** QUALIFIED_C_TARGET Physical copy capacity and independent collector/restoration
:PROPERTIES:
:CUSTOM_ID: MODERN-C-RESULT-independent-collector
:RESULT_ID: independent-collector
:STATUS: QUALIFIED_C_TARGET
:END:

W<R and other declared topologies, reserve/refund/CAS-loss, batch/Tail custody, GC/root relocation and real map multi-shot restore. Bound physical peak and every failure/unknown result without adding heap or waits.

Benefit: Worker count becomes independent from execution contexts and root sources; remove repeated scanning/copy work only with measured counts.

Cost: Census/packing, reservations, physical slack and root/restore metadata; no invented peak-memory or throughput gain.

Falsifier: A worker still borrows carrier-local allocation identity, one object scans twice, a copy lacks contiguous capacity or a context lacks its first restore interval.

** QUALIFIED_C_TARGET Startup, retirement and deferred effects
:PROPERTIES:
:CUSTOM_ID: MODERN-C-RESULT-owned-lifetime
:RESULT_ID: owned-lifetime
:STATUS: QUALIFIED_C_TARGET
:END:

Partial create/rollback/retry, join failure/unknown, nested entry/exit, delayed destructors/shutdown drain and healthy VM continuing GC under an isolated unknown join; full registry/lifecycle/GC-FFI inventories.

Benefit: Local uncertainty retains explicit custody and need not stop unrelated healthy VMs.

Cost: Retained unknown-owner storage, queues, tickets and accounting; quantify bounds from actual usage.

Falsifier: Unknown join is treated as death, metadata is freed with remaining roots/readers, or healthy VMs wait for an unrelated unknown owner.

** OPEN_INTEGRATION Request execution and complete product qualification
:PROPERTIES:
:CUSTOM_ID: MODERN-C-RESULT-request-product
:RESULT_ID: request-product
:STATUS: OPEN_INTEGRATION
:END:

Complete original interpreted/compiled, PR and stress manifests, ordered shared values, repeated multi-shot control, complete Gerbil build/tests and matched release latency/throughput/peak populations on the final source.

Benefit: Amplify Scheme/tail-call/multi-shot control with owned service execution and actual parallel consumers; prove reductions in repeated work on matched populations.

Cost: Queue/admission/GC/control overhead remains explicit; performance stays unmeasured until matched evidence exists.

Falsifier: Repair9 work merely moves, repeat continuation materialization persists, original populations shrink, or final product/CI/performance evidence is absent.

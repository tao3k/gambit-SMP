** Complete implemented path

1. Each participant materializes its existing stack/heap/context view and joins
   the GC collective before the coordinator captures the complete roster.
2. One VM round supplies every member's epoch, including a newly created RC
   domain. The union owns VM and symbol/keyword tasks plus each member's RC,
   globals, stack and bank tasks and immutable global descriptor.
3. Joining the union closes RC registration, rebinding and new root borrowing.
   Existing loans remain scanned and reloadable. Ordinary generated,
   reflective and module-init stores use the actual canonical cell and a
   noncollecting current-owner check. No per-store mutex is added.
4. Existing source scanners preserve VM/symkey, RC, globals, stack, bank order,
   actual frame repair and precise-root coverage. No copied frame snapshot or
   one-shot continuation limitation is introduced.
5. Strong completion joins every source, including empty global shards.
   =joined_round= still forbids domain cleanup after local DONE. Only the
   restored collective drops those leases and retires the union.
6. The actual SFUN emitter registers raw Scheme parameters before marker or
   conversion allocation, reloads the GC-updated cell at argument transfer,
   and releases the banks at physical exit/catcher propagation. =___run=
   marker cleanup also follows its catcher rather than only normal return.

** Logical continuation transfer is not physical C exit

=___call= runs a trampoline, compares the returned frame's marker with its own
marker, and propagates an unwind when the markers differ. A restored Scheme
continuation can therefore run while an inner C invocation remains physically
on the stack. Its parameter roots must stay registered during that interval,
including subsequent GC. Declaring them leaked at the Scheme =call/cc= return
point would be an incorrect oracle; releasing them there would be unsafe.

The native test requires both cuts: roots remain present after logical escape
and moving GC, then both banks drain after return to an actual outer host
marker. This learns from Gambit's own multi-shot control protocol rather than
imposing a one-shot or immediate C-stack-unwind model.

*** Shared primitive ownership :decision:counterexample:
:PROPERTIES:
:CUSTOM_ID: SHARED-PRIMITIVE-OWNERSHIP
:STATUS: VM_LOCAL_OVERRIDE_SELECTED
:END:

The real =GLOBALVARPRIMSET= / =GLOBALVARPRIMREF= path stores a captured closure
in =glo_struct.prm=. The moving-GC probe checks three independent bits:
the input is movable (1), the caller's precise root is relocated (2), and the
primitive cell equals the relocated closure (4). The observed result is3;
required is7. The probe restores the previous primitive before returning and
never dereferences the stale closure. It is an actual missing-cell witness,
not a new model counterexample or a waived SMP scheduler failure.

The original root and marker populations still execute in full. This small
admission witness uses the existing fixture's feature mechanism, as the Tcl
and marker variants do, with the same runtime/profile and compiler limit.

| Preserve cross-VM mutable primitive binding | Define who may read a foreign movable closure, which collector owns it, and how swaps/readers/VM exit retain it | Requires a shared-root/read-barrier or shared-heap protocol. The user selected VM-local mutable overrides plus shared code templates.
The runtime now implements that selection through existing names. This is an
intentional cross-VM binding semantic choice, not an inferred compatibility
promise. =GLOBALVARPRIMSET= writes the owning VM; =PRM= reads its override or
the image template. =DEF_MOD_PRM= publishes permanent image code and resets
only the loading VM's override. Other VM overrides remain independent.

One multiple-VM allocation contains ordinary cells, override cells and presence
bits. The owning globals task scans canonical ordinary and active override
cells; no collector traverses another VM's movable closure through a shared
image field. A cleared bit leaves the old value physically intact until the
owning stopped scan, so a concurrent reader that previously saw the bit cannot
load a cleared cell. Global publication serializes bitmap read/modify/write.
Readers use acquire loads and publications use release stores. No Scheme
allocation, callback or GC wait occurs inside that publication interval.

Single-VM builds retain their existing unbounded global list and add local
override/value fields to each record. The existing multiple-VM20000 capacity
is reused; this REV does not invent another identity table or capacity policy.
VM setup checks storage allocation before publishing a usable VM. Failure
rolls back linked VM storage and OS state; successful cleanup frees the whole
block after source leases/borrowers drain. Native qualification is still
required for the selected representation and each lifecycle cut.

Raw address escape is a real boundary, not a promise that a modern-C macro
silently makes every private extension safe. Managed C code uses value/store
interfaces. The CPU backend needs a later explicit borrow/read/write lowering;
its old fixup cannot select a VM override through one raw address. Rejecting
that unsupported operation avoids both a compile-time lvalue error and unsafe
execution, without a legacy alias namespace. Public Scheme names remain.

The locked Gerbil default-build cohort has its own retained1778-file source
manifest. Its native/private primitive/global-field census must match those
bytes; arbitrary native extensions, custom load roots and whole Gerbil product
acceptance remain outside this source admission.

** Native control meaning

The historical closure witness ran the actual pre-override runtime and observed
3 rather than7. The selected implementation must produce7 on the same profile.
The new retirement control executes the selected043a9341 =rc_can_close= and
=rc_prepare_cleanup= predicate/body against the same real domain. A fresh
source first permits cleanup as a positive control, then joins an actual
=RootRound=. The old body permits cleanup while the new production entry
refuses. Neither destroys the retained source; the child exits with that
partial round still in custody. It never resets or requeues unknown work.
This is distinct from the composed history's labeled observation mutation,
which calibrates only the history oracle and shrinking.

The original Make consumer includes its actual compiled GSC/mixed-C entry
checks and every current original prerequisite. The separate twelve-family
GSC criterion is compilation/execution of all408 unit files. Passing the former
does not claim the latter, independent collector admission, or any Repair9
workload improvement.

** Footprint

| key | required | reuse | premise |
|---+---+---+---|
| ordinary closure symbol | Same named/freevar/ordinary fields in strong and weak | DONE may be reused after original scanner completes | Tail and frame fixup obligations remain separate |
| strong-scanned will | Strong action only; NEXT flag records deferred testator | process_wills repairs testator through destination body; DONE unchanged | Unique list ownership and flag preservation through list rewrites |
| fresh weak will | Weak scanner traces action and testator together | READY to OWNED to DONE normally | List/root update and queue publication must retain storage |
| strong hash fields | Keys iff !WEAK_KEYS and MEM_ALLOC_KEYS; values iff !WEAK_VALS | Same generic footprint in either phase; register reached list once | Flags stable and scan owner unique |
| weak hash fields | Not tracing roots; cleanup rewrites live references or deletes entries | Cleanup consumes retained reached list after weak closure | All four weak-flag cases plus non-heap key mode; no ephemeron claim |
| new weak hash table | Generic scanner sees it first in weak phase | Strong-field policy plus reached-list registration unchanged | Existing reached list must not be reset at weak entry |
| captured frame | Descriptor root runs plus RA; link temporarily hidden/restored | READY requires overlapping copier fixups settled or synchronized | Current post-READY write is not excluded by scan bitmap |
| still objects | No movable scan-state bitmap in scan entry | Still-mark/list ownership remains separate | Not covered by movable DONE uniqueness proof |

** Claim

| key | mechanism | condition | result | gap |
|---+---+---+---+---|
| closure | Separate external creation gate, weak eligibility, invocation and restoration authority | Already accepted producers and descendants remain accounted | Closing registration neither drains execution nor cancels legal Scheme behavior | No unconditional global termination claim |
| capture | Action is strongly marked; zapped fields no longer own operands | Loaded root carrier and captured action/caller frames admitted | Model permits repeated resume after return and close | Actual root maps and capture enumeration incomplete |
| rights | SRFI124 stock body touches two fields | Type/primitive identity and no forged native aliases | Holding datum/resource keeps it alive but does not itself mutate resource | Arbitrary macro action can have broader authority; session inventory open |
| scope | Track only metadata-relevant work for optimization receipt | Disjoint complete effect closure for excluded wills | Unrelated wills need not die or be forced during compilation | Effect-disjointness is an external proof, not a name-based rule |
| retire | Quiescent relevant obligations and immutable plan | Same entry, named-writer law, no post-cut legacy observer divergence | Second helper condition can narrow to write authority rather than global GC shutdown | Full observable equivalence still required |
| identity-gap | Counts conserve aggregate obligations, not TicketId or capability graph identity | Each real settlement and resume needs a unique provenance-bound receipt | A wrong-ticket duplicate settlement can evade aggregate conservation | Per-ID exactly-once and capture-identity source refinement remain open |
| self-wait | A relevant active callback cannot synchronously wait for its own active count to become zero | Reentrant normalization falls back or is deferred to the outer owner | Avoid self-deadlock without suppressing Scheme continuation semantics | Non-owning audit identity and actual scheduler/GC progress proof remain open |

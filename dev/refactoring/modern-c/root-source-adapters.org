** Caller and address equivalence :source:refinement:

All six private visitors have one actual callsite each in
=garbage_collect_mark_phase=. The phase caller now selects their root source.
The existing =___ps= argument still supplies collector allocation/copy cursors,
marking resources and diagnostics. It no longer implicitly selects those roots
inside the six visitors. This is source-selection ownership, not independent
collector eligibility or an arbitrary cross-context scan permission.

The RC call remains inside the original processor0 branch. This REV does not
repair nonzero-processor RC omission. VM, global-variable and symbol/keyword
visitors retain their previous implementation and ordering; no claim is made
about concurrent GSTATE writers.

The frame coordinate arguments are selected at the original strong-mark
callsite. =mark_frame= still delegates root runs to =mark_array=; it does not
rebind the execution context. =move_continuation= occurs in the subsequent
weak phase, after strong roots/reachable objects have been scanned. Thus
snapshotting the break coordinate does not cross a relocation boundary in
the admitted path. Arbitrary source migration during this call is excluded.

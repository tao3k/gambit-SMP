** Identity

| key | structure | rule | caveat |
|---+---+---+---|
| source | VM SourceSlotId + generation + payload lineage | Stable metadata exists before client_data dereference | Do not CAS a freed native header |
| pin | SourceId + PinId + owner generation | Exact return is idempotent; nested pin distinct | Lifetime pin is not an immovable-object pin |
| carrier | ReservedSlotId + registration generation + GC round | Private candidate cannot become authoritative until enrollment acknowledged | Release/acquire alone does not enroll frozen root set |
| handoff | PinId + CarrierId + GuardId + commit identity | Source pin drops only after exact commit outcome and target custody known | Unknown reply is not failed reservation |
| payload | Semantic payload identity plus GC relocation revision | GC relocation preserves identity; managed semantic replacement changes generation | Two fixed leases model no arbitrary mutable payload replacement |

| key | proposedIssuer | actualSource | status | responsibility |

** Claim

| key | mechanism | condition | result | gap |
|---+---+---+---+---|
| close-pin | One metadata gate/count or serialized owner decision | Stable control record and no overflow | Pin linearizes before close or is rejected | Raw header lifetime and actual C23 primitive selection open |
| gc-private | GC leaves private candidate unregistered; enrollment compares relocation revision | Source lease stays scan-visible; freeze excludes root mutations | Stale candidate cannot enroll without refresh | Source-to-native moving-GC simulation open |
| nested | Two independent exact pin records | Real source adapter covers entry and deletion | Returning outer pin cannot settle nested pin | Arbitrary nesting, exhaustion and finite generation open |
| unknown | Reserved/unknown guard retains both source pin and carrier | Exact commit-owner lookup | No blind retry or early source retirement | Actual non-abandonable owner and eventual reconciliation open |
| bridge | CarrierAdmission relation to prior bootstrap model | Same carrier revision and supplied prior safety | Prior guard reservation remains safe | Not a complete runtime source simulation |
| storage | Separate root liveness from still backing storage | All arenas and source context retirements accounted | Root receipt alone never permits freeing backing memory | VM-wide storage freeze and foreign cleanup closure unresolved |

** Memory

| key | publication | observation | obligation | overhead |
|---+---+---+---+---|
| gate | Close/pin serialized on stable SourceControl metadata | Acquire sees generation and admission outcome | No check-open then later increment; no count wrap; no lock across GC | Bounded atomic or owner-thread metadata operation |
| candidate | Source read under registered root-access interval | Private copy may become stale when GC runs | Pin prevents owner deletion, not relocation or concurrent raw setter | Nonallocating root-access and refresh |
| enrollment | Register target under same GC round or defer until source refresh | Collector acknowledges target slot coverage | Do not release source when target missed frozen origin set | Root-origin ack and one slot per admitted ingress |
| guard | Allocating reservation reads enrolled target after GC | Commit response or keyed query names same carrier | Unknown keeps pin and target; no owner lock while allocating | Stable record and retained query result |
| source-delete | After gate closed and all source pins gone, outside scan interval | Native block and Scheme ownership released separately | Retain scan descriptor and storage if any maintenance reader remains | Deferred deletion and scan-drain coordination |
| nested | Each invocation owns its PinId and carrier | Outer return cannot decrement child custody | No mutable ambient source retarget | Depth-dependent reserved capacity |

** Gain

| key | avoided | added | condition |
|---+---+---+---|
| root-reuse | New generic roots where an admitted existing RC slot already suffices | Source pin, GC participation and root-domain proof | Keep source registered if safe; do not mandate carrier copy for every static/owner path |
| carrier | Ad hoc per-wrapper roots and lost-outcome recovery | Reserved slots and registration acknowledgements | Retire actual duplicated support instead of retaining two paths |
| no-block-delete | Delete/GC/callback cycle caused by synchronous wait | Deferred logical deletion and owner polling/query | Old owner remains participant; no drain while holding needed lock |
| nested | Duplicate settlement or parent-child custody corruption | Exact pin record and carrier per nested activation | Capacity/overflow and arbitrary nesting remain admission obligations |
| normalization | At most one redundant metadata traversal | Pin, enrollment, refresh, scan and unknown-retention costs | Positive only after real source/guard/writer/storage gates and all marginal costs |

** Contract

| fromNode | toNode | custody |
|---+---+---|
| Stable source adapter | Admission gate | lookup stable generation before raw payload access |
| Admission gate | Exact source pin | pin before close or reject; no allocation |
| Exact source pin | Private carrier | read under root access; source remains scanned |
| Private carrier | Enrollment owner | same round or refresh after source moved |
| Enrollment owner | Stable guard owner | target scan coverage acknowledged before allocating |
| Stable guard owner | Commit lookup | reply lost queries same operation |
| Commit lookup | Source pin return | release only after target and guard outcome known |
| Stable guard owner | Nested callback | independent pin and carrier |
| Source pin return | Deferred source deletion | all source pins gone and scanners drained |
| Deferred source deletion | VM storage owner | root liveness and backing arena lifetime separate |
| Stable guard owner | Unknown escrow | retain source pin plus enrolled carrier |
| Unknown escrow | Commit lookup | exact owner resolves; no blind re-execution |

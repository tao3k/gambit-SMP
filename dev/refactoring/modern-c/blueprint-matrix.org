* SysML-owned benefit and migration design

Every original pressure has one benefit case. Benefits are conditional work/cost arguments; none is a measured speedup or accepted retirement. The migration DAG is validated as a graph, not executed as a build or runtime plan.

#+BEGIN: sysml-view :kind modern-c-blueprint-benefits :source refactoring/models/sysml/adoption.sysml
#+NAME: modern-c-blueprint-benefits
| Pressure | Migration nodes | Eliminated work | Added cost | Positive condition / measure | Refutation | Open obligations |
|---+---+---+---+---+---+---|
| exit | exitLifecycle | Duplicated admission/result-disposition decisions across error, join and cleanup paths; runtime work savings not yet established | Independent result/carrier, admission and last-use synchronization | Lost admitted outcomes = 0; duplicate final release = 0; retained descriptors and exit latency bounded by declared users | If retained users never finish or memory grows without bound, safety alone does not establish positive benefit | BF-EXIT |
| work | workCore | Separate implicit phase/exit custody interpretations replaced by one explicit work census; wait/scan savings remain conditional | Context descriptors, census/epoch checks, handoff and accounting | Accounted tasks = accepted outstanding work; compare rendezvous wait plus handoff cost under equal work | Added handoff/cache traffic may outweigh imbalance savings; forced single-processor execution is not a gain | BF-WORK |
| copy | workCore | Lost-progress rescans and duplicated Tail/child dispatch in a proposed worker split | Materialized subframes at admitted cuts, task IDs and retained source/destination regions | One canonical initializer and one execution per owned Tail; measure descriptor bytes and stores per copied live word | Do not count a hypothetical migration defect as existing baseline overhead; per-word materialization may be unjustified | BF-WORK |
| ffi | entryPark | Duplicated callback root protection, owner restore and cleanup plans | Root slots, grants, publication/reload, nested-entry checks | All legal entry roots protected before allocating; enumerate publications and entry/park overhead | Raw untracked mutation or callback escape prevents fast-path admission; slower sound handling remains necessary | BF-PARTICIPATION |
| release | releaseDrain | Repeated inline blocking and ad hoc shutdown rescans across resource producers | Release queues, WaitContext synchronization, rooted payload retention and descendant counts | Accepted = queued + running + completed/disposed; compare GC pause reduction against queue/retention costs | Moving work later does not remove total release work; external thread affinity or unbounded blocking can defeat gain | BF-RELEASE |
| frames | schema | Duplicated frame/root/return-label decisions and unnecessary mature continuation traversal | Generated metadata, safepoint spill/reload and barrier/remembered scans | One semantic owner per decision; avoided mature visits exceed writes/logs/revisits/promotion costs | Opaque mutation or incomplete origins forbids skipping graph scan; one-shot restriction is not equivalent Gambit support | BF-SCHEMA; BF-GENERATION |
| profile | buildGraph | Repeated full planning and over-broad rebuilds; nested CPU oversubscription | Input hashing, memo invalidation, dependency records and shared CPU/memory tokens | No-op eligible native actions = 0; active token demand <= host grant; exact affected graph for each declared delta | Hash/planner cost can dominate small builds; keys excluding real inputs are invalid speedups | BF-BUILD-CUT; BF-BUILD-BUDGET |
| generation | schema; buildGraph | Redundant Scheme-to-C generation, unchanged downstream C compilation and manual linkage synchronization | Plan/action manifest and output digests; ABI/schema invalidation; staging publication | Identical valid output cuts off descendants; relink ordered closure only when its inputs change | Bootstrap stages using different compilers or dynamic semantic effects cannot share merely by source filename | BF-SCHEMA; BF-BUILD-CUT |

** Migration dependency and retirement
#+BEGIN: sysml-view :kind modern-c-blueprint-migration :source refactoring/models/sysml/adoption.sysml
#+NAME: modern-c-blueprint-migration
| Stage | Requires | Deliverable | Admission | Owner | Old responsibility retirement |
|---+---+---+---+---+---|
| sourceCut |  | Bind source, capability, writer/consumer and failure inventories | No native count reset; every legal boundary named | dev/refactoring | none: evidence is preserved, not retired |
| schema | sourceCut | Scheme semantic completion and generated frame/root/entry schema | All consumers and relevant target projection mapped | dev/architecture/compiler | Duplicated semantic decisions only after generated/native consumer parity |
| buildGraph | sourceCut | Semantic dependency graph, memoized planning, action cut and shared budget | Correct semantic units, dynamic dependencies and bootstrap compiler lineage explicit | dev/architecture/toolchain | Coarse string-only invalidation and uncoordinated nested schedulers after equivalent graph qualification |
| entryPark | schema | Root-safe host entry, callback origin, park/reload and acquired-effect plans | Marker inputs protected before allocation; every nested and exceptional exit accounted | dev/architecture/runtime/ffi | Handwritten root/entry choreography for fully covered callers |
| workCore | schema; entryPark | Collector work context, producer close and parent/Tail handoff | Complete phase/resize/root census and transfer failure custody | dev/architecture/runtime/gc | PSTATE-owned collector aliases only after all task and scan consumers migrate |
| generation | workCore; schema | Nursery/promotion, barriers and mature continuation scan policy | Every managed/FFI mutation covered or assigned a sound explicit fallback; promotion capacity reserved | dev/architecture/runtime/gc | Repeated mature scans only for admitted writer-complete classes; full scan remains an explicit capability route |
| releaseDrain | workCore; entryPark | Resource classes, release acceptance, WaitContext and descendant drain | Payload remains rooted; owner thread and failure/result policies closed | dev/architecture/runtime/ffi | Inline GC release only for eligible resource classes; arbitrary existing C callbacks retain explicit supported handling |
| exitLifecycle | releaseDrain; workCore; entryPark | Outcome owner, participant removal, OS-user drain and final reclamation | Late errors/callbacks and unknown transfers retain one legal custodian | dev/architecture/runtime/execution | Implicit catcher/context/container lifetime only after last-user and error-disposition coverage |
| nativeClosure | buildGraph; schema; generation; exitLifecycle | Build one selected modern-C runtime with exact semantic/native ABI closure | Affected source/generated/header/object/link dependency closure complete | dev/architecture/toolchain | Stale generated/archive/link routes after all actual callers use the manifest boundary |
| qualification | nativeClosure | Separate semantic, native stability, weak-memory and cost qualification | Same workload/capability/source controls; failures retained; no global-lock or single-processor substitute | dev/research | No retirement follows from documentation, structural models or finite safety alone |
| retirement | qualification | Remove each named old semantic or mechanism owner | Per-route consumer coverage plus correctness and benefit receipts; preserve C-facing capability | dev/refactoring/modern-c | Exactly the named migrated paths; no default permanent duplicate runtime |

* Relation to the new architecture

This cut realizes a frame/root sub-contract. Inherited fixes are validation baseline, not modernization benefit. Source divergence alone proves neither replacement nor failure.

| Cut | Existing architecture decision | Required replacement | Old responsibility to retire | Whole obligation |
|---+---+---+---+---|
| roots | heap | Context-local nurseries, shared mature heap, parallel STW minor, generated remembered writes and explicit promotion budget; isolate major algorithm behind heap/phase contract | Retire full mature-graph minor scanning only after all roots, continuation/denv/FFI writers and sparse/promotion layouts close | Prove no omitted mature-to-young edge, root-complete minor cut, promotion failure custody and capacity conservation |
| control | control | One precise frame/root format for running, captured and resumed computation; persistent or copy-on-write captured frames; one-shot optimization only with proven use | Retire carrier-local C control assumptions after repeated resumption, dynamic-wind, exceptions and supported FFI escapes are preserved | Capture map continuation, collect/promote, mutate legal frames/denv and resume more than once with same observable semantics |
| binding | domain | VM owns membership/heap epochs; ExecutionContext owns Scheme state; GCParticipant freezes roots; CollectorWorkContext owns scan work independent of OS/PSTATE lifetime | Retire implicit PSTATE ownership of collector queues, allocation state and cleanup after exact producer/consumer/lifetime replacement | Compose safepoint progress, membership closure, root leases and task termination; exclude collector/owner wait cycles |
| build | build | Scheme frontend/session -> semantic module artifacts -> generated C/runtime ABI artifacts; phase-ready dependency DAG, stable snapshots, incremental/parallel scheduling and reusable AOT interface programs | Retire repeated expansion and regenerated/recompiled unaffected units after clean-versus-incremental observational equivalence | Prove dynamic dependency closure, stable input snapshot, output encoding/consumer reflection and failure invalidation |

* Scoped obligations

| Obligation | Method | Scope | Premise / limit |
|---+---+---+---|
| FR-Q | quint | frame-roots:finite-word-stream | Width-four abstraction; prefix coverage, unique visits, terminal guard and tail-index counterexample |
| FR-L | lean | frame-roots:coordinates-and-prefix-induction | Seven natural-coordinate/prefix laws; C bit operations, run batching and metadata lifetime are separate |
| FR-NATIVE | native | frame-roots:configured-64bit-native-cursor | Generated 306 physical plans; independent bit/run enumeration, terminal guard, unsigned high-bit and sanitizer controls |
| FR-MAP | native | frame-roots:coherent-map-multishot | Fresh compiled map and 80-root non-tail frame; winding/effect/value and materialized-frame root-query agreement |
| FR-COHORT | native | frame-roots:source-self-bootstrap-profile | Actual source and self passes under the existing Bazel profile and explicit threaded-VM goal overlay; original budgets and complete source/header/tool/config identities |
| FR-PROFILE | source | frame-roots:bazel-profile-and-patch-correspondence | Exact current script hash, four reverse-apply imports and explicit VM replacement; not configure or native qualification |
| FR-CONSTRAINTS | source | frame-roots:repair-behavior-to-architecture-refinement | Old repairs constrain legal behavior and retained failures, not the replacement layout; bind each new owner and old-owner retirement; no source-equality or automatic 8/12 inheritance |
| FR-FULL | lean | frame-roots:whole-runtime-refinement-open | No claim of generational GC, full FFI/scheduler refinement, arbitrary processor count or 12/12 acceptance |

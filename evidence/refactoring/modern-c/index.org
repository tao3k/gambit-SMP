** Complete replacement and conditional proof
The managed key-update adapter replaces the convergence loop, its representation
premise and its effect-publication protocol together. Public base/boost payloads
retain NaN. Only the effective scheduling key maps NaN to ordered bottom. This is
an explicit ordering policy for a formerly unordered value, not an input error.
The first attempt to normalize a returned floating value introduced boxing;
normalization now writes the private or fully leased F64 slot before publishing it.
Every managed producer, including inherited thread initialization, uses that path.
The non-SMP branch is outside this change.

A thread has at most one owner edge. A discovered finite graph is therefore a
prefix followed by at most one cycle. Under the validated unique thread/queue
leases, each node constant joins its normalized boosted value and external waiter
keys. Planned waiters are excluded: their old inherited keys must not sustain a
cycle after its source is lowered. Prefix joins and the single cycle maximum
form the least fixed point. Publish each solved key once, reposition BTQ/TOQ,
release all leases, clear borrowed graph roots, then retire the workspace claim.
This removes convergence as a commit-termination assumption. It adds graph
preparation and complete lease validation; it does not claim less work on every
acyclic update.

The proof assumes valid finite managed owner/queue topology and all managed key
producers. [[file:../../../vendor/gambit/lib/_thread.scm][The runtime source]] contains discovery, external-head,
prepare, apply, try and release endpoints;
[[file:../../../vendor/gambit/lib/_thread#.scm][the Scheme macros]] own the representation. Existing automatic
insertion/unlock inheritance hooks remain disabled; this delivery does not enable
them or claim every native/private writer is governed. Arbitrary carrier death or
unknown physical stores inside the lease are not recoverable by this proof.

GC is not forcibly entered during partial red-black mutation. The source-bound
operation is finite, then existing safe participation resumes. This establishes
neither constant GC latency nor mid-edit preemption. Source scanning finds no
boxing/allocation/poll/unknown Scheme jump witness in the sixteen generated direct
helpers. That scan is a reusable Python Evidence check, not a general C parser or
proof of every expanded macro.

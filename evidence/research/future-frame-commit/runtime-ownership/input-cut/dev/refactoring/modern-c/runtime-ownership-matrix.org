** Alternative

| key | choice | benefit | cost | decision |
|---+---+---+---+---|
| coupled | PSTATE owns all lifetimes | Few explicit descriptors | Departure can invalidate roots/work/control interpretation | Rejected as target ownership architecture; no allegation that every current path fails |
| ownership-separated | Distinct logical custodians; replaceable physical realization | Carrier/context may leave without losing rooted work or captured control | Root-domain publication, task accounting, layouts and restoration grants | Selected architecture research; old authority must actually retire |
| worker-pool | Dedicated independently scheduled GC workers | Potential scheduling flexibility and carrier-independent work execution | Native host enrollment, capacity, root interpretation and extra synchronization | Optional physical realization; not implied by logical separation or admitted by this model |

#+TITLE: Research Artifact Layout
#+PROPERTY: header-args :eval never

This directory does not store execution output. Historical generated files were
moved to the ignored task cache under
=.cache/tasks/future-frame-commit/runs/research/=. That local path is not a
portable proof or native-admission receipt.

Maintained models, DSL, programs and deterministic documentation views live in
=dev/=. Curated pinned source material lives in
=evidence/research/source-references/=. Publication policy is defined by
[[file:../../../dev/modeling/models/sysml/research-storage.sysml][SysML]] and explained in
[[file:../../../dev/modeling/research-storage.org][the storage policy]]. Runtime logs, command/status records, IR,
snapshots and model samples must remain outside Git.

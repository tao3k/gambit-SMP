** Why this is a responsibility replacement

The published native_scope table reserved64 words per VM and initialized them,
but production code never acquired/released those synthetic permits. Renaming
it write_authority would preserve unused parallel state without guarding any
actual root. The selected complete source instead centralizes primary/span
mutations under the existing RC source gate and retires the unused table,
initializer, build object and synthetic test. The existing real generated-entry
test becomes the check consumer and its Scheme/C inputs enter distribution.
Official test1--12 names, workloads and limits remain intact.

No new storage, allocation, collector phase or implicit GC is introduced by a
store. Existing native metadata allocation remains noncollecting; callers own
valid storage before entry and reload moving values after any GC. Ordinary
primary identity cannot rebind while borrowed; equal identity is an actual no-op.
Span mutation requires exactly one activation borrow. Unregistered foreign-thread
entry, raw arbitrary casts, asynchronous owner death and unsupported ARM native
C-closure machine trampolines remain outside this profile.

** Validation boundary and proof division

Production SFUN histories cover GC, aliases, normal/exceptional/nested return,
multiple continuation restoration, real conversion failure and processor1. The
existing RC stateful tests exercise registration, references, borrowing, root
writes and GC on both owners. Frozen-phase refusal is explicitly a confined,
nonallocating control; it does not fabricate a completed GC or stop credential.
The existing moving-GC histories provide the independent real scan evidence.

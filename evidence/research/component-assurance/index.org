* Reproducing the research checks
Copy the retained adapter scripts to .cache/tasks/component-assurance/ in a
matching checkout and retain the entry snapshots. The active sequence is:

#+BEGIN_SRC sh
bash .cache/tasks/component-assurance/read-native.sh
bash .cache/tasks/component-assurance/prepare-scopes.sh
bash .cache/tasks/component-assurance/check-formal.sh
bash .cache/tasks/component-assurance/compose.sh
bash .cache/tasks/component-assurance/split-requests.sh
#+END_SRC

compose requires source-bound successful producer records and exact namespace
scopes. It creates a source-bound hypothesis registration, not an observation.
Submit only a new claim identity; an already retained identity must be read
rather than re-submitted. Use the single gambit-smp dispatcher with task
component-assurance for the generated registration and each bounded query.
run-queries.sh executes one scenario at a time and decodes the complete read.
assert.sh checks sixteen scenario closure sets and five structural controls.

No runtime build, native test, deployment or performance command belongs to
this sequence. Source scopes and third-party Lean/stdlib qualification remain
explicit trusted inputs; these receipts do not prove their entire toolchain.

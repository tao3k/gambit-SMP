The retained candidate header defines `___WORD` as signed `___S32`/`___S64`
(`include/gambit.h.in:2316,2336`), with `int nb_sections` (:11375) and

a true shrink makes the right side negative; the nonnegative left side is not
less. This rejects mandatory collection as a universal source argument. It does
not establish those arithmetic/heap invariants for every native execution, nor
prove that any particular observed failure retained a raw donor continuation.

premise. No forced collection or new runtime mechanism follows from the audit.

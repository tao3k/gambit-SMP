# TclReuseService: Modern C and Zig Net-Benefit Matrix

Same request semantics, producer domain, root/control behavior and outcome custody
are required on both sides. Source evidence and conditional proofs are separate
from installed/native admission. No human-day estimates or invented speedup.

SV01. The modernization value is a reusable native contract around a real private
library boundary: stable provider binding, producer authority, actual owner
idleness, pending disposition, clear-state witness and synchronized publication.
Modern generated C can implement it; optional Zig must add value beyond it.

| Necessary support | Modern generated C | Optional Zig | Work retired / cost retained |
| --- | --- | --- | --- |
| Stub binding and image lease | One isolated C facade with stable captured entries | Consume that facade; private import adds another ABI mapping | Duplicate ad hoc binding may retire; matching core/header/archive/image qualification remains |
| Producer/child closure | Common registry, source-scope coverage and native lifecycle hooks | Same registry/hooks and closure | Public wrapper alone cannot cover internal child creation or raw extensions |
| Owner/control scope ledger | Register before native effects; settle after real return | Same exact return frontier | New per-entry bookkeeping is real work; zero Scheme-thread count is not enough |
| Existing thread-wide settlement | Use Tcl machinery under qualified handler domain | Same machinery and handler policy | Avoid writing a second executor; scans, callbacks and descendant closure remain |
| Targeted settlement candidate | New Tcl-owned source integration, lock/order/receipt contract | Same library integration or additional C bridge | Could avoid unrelated barrier callbacks; new helper and upgrade obligation are added costs |
| Reset witness | Owner-exclusive private reset plus postcondition | Same flags/idle/ABI requirements | Reset return-code shortcuts can retire; slot access itself is insufficient |
| Outcome/root/image custody | Reuse common native/root/delivery services | Same Gambit GC roots and native lifetime support | No second-language GC eliminates required roots or callback/string leases |
| Next epoch and failure | One synchronized receipt graph and sealed failure state | Same graph, synchronization and failure responsibility | Per-adapter reuse rules may consolidate; Zig adds cost unless a necessary maintained support path disappears |

SV03. Account concrete runtime work, not language syntax. With E admitted native
entries, R request submissions, B provider bindings, I affected interpreters and
Q invoked handlers, common costs include per-entry scope work proportional to E,
request authority/lease work proportional to R, binding work per B, each target's
reset/validation, owned snapshot bytes and delivery/retirement work. Do not charge
a scope counter on every Scheme allocation or instruction unless the actual
implementation requires it; its coverage is native/control entry.

Existing AsyncInvoke rescans from the list head. For finite maximum encountered
handler count H and Q invocations, scan overhead is O(H*(Q+1)) plus actual callbacks
and derived work. The proposed targeted path instead visits target tokens with
validated lookup, token-state and reset costs. Do not assume constant hash lookup
or a measured token cost:

```text
W_target = sum_i(target_lookup_i + token_settlement_i + reset_validation_i)
         + receipt_and_publication_work
candidate_barrier_gain = old_barrier_work_actually_removed - W_target
```

Unrelated handlers remain ready for normal service; delaying their work does not
mean it vanished from total application cost. Bounded latency needs finite
cooperative callbacks and fair owner service in either design.

SV04. Reuse savings compare equivalent histories. Avoided interpreter creation,
Tcl/Tk initialization and application-state reconstruction are eligible only
when that alternative preserves the required state/capabilities. Subtract the
common binding/entry/request/snapshot/settlement/reset/publication and retained
root/image work. Discarding a raw idle cancellation intended for the next script,
skipping required cleanup or excluding useful plugin behavior cannot count as a
positive saving under unchanged semantics. An explicit smaller epoch-bound API
is a contract decision, not free speedup.

SV05. Retained space is the union of rooted Scheme/native payloads plus distinct
provider/image leases, interpreter records, live native scopes, request receipts,
handler metadata, snapshots and charged descendants. Settled archives may persist
without old execution authority. Source/ABI binding metadata can be shared for a
provider image; per-interpreter identity and per-epoch request custody cannot be
amortized away by sharing a C helper or a Zig allocator.

SV06. Maintenance units are independent policies/representations/ABI mappings.
One C facade centralizes private headers/table/reset facts; one Scheme-derived
plan centralizes lifecycle and effect policy. This can consolidate per-adapter
public-pointer assumptions and reuse decisions only after real caller migration.
A targeted helper adds Tcl source/lock/upgrade responsibility. Zig consuming the
facade retains these costs; importing private tables again increases them.
LLVM/MLIR remains decoupled from this control/GC ownership contract.

SV07. Incremental Zig balance:

```text
Zig increment = necessary C support actually retired
              + separately qualified native/provider capability gained
              - retained C island / duplicate representations
              - extra toolchain, ABI, control and library-upgrade obligations
```

No positive numerical lower bound follows from no automatic Zig GC, tagged unions,
ordinary defer or LLVM access. C can already share these services. The whole
modernization fails its claimed domain if one untracked creator/mark/cancel source,
stale table or post-reset hook invalidates the receipt chain. The targeted
candidate fails if it loses another handler's mark or changes priority without
an explicitly accepted contract.

SV08. Decision: continue the common native plan and generated-C mainline, isolate
private Tcl binding in one capability-bearing provider, and require explicit
owner/pending/reset/publication receipts. Current thread-wide service needs a
qualified loaded-handler domain; a broader targeted service requires actual Tcl
integration and its own proof/qualification. Installed Tcl/Tk, raw external
producer closure, native owner/ABI behavior, finite progress and positive Zig
increment remain unresolved. Retire old recipes only after all callers and
failure exits migrate, with no silent weakening of raw Tcl or Scheme semantics.

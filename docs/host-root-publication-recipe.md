# Host Roots: Publication Through Last Use

## Current Repair Scope

This is a bounded source/refinement Recipe for the existing 9/12 repair, not
general foreign-thread attachment or another native test plan. It preserves the
C backend, generated maps, continuations and supported FFI. The implementation
owner's exact candidate and native inventory remain authoritative. No runtime
source, current qualification input, watchdog or native test is changed here.

Pinned references remain Gambit `7c490c3ab5b5a4238b26f4a59d8cd9fd4b085882`,
Chez `41d5ffca7a07cbfc8807e719dedcc70ed74811cd` and OCaml
`46e1c324fb9e9f21f52c9cc3399020f7ef8b9b91`. Baseline source observations do
not establish the current overlay's behavior or diagnose its remaining failures.

The missing composition is specific: an initialized, coherently published root
record can still be reclaimed too early after its collector reader finishes,
because the returning host is a different consumer. Conversely, retaining the
record does not make an incomplete or unordered root publication correct.

## Bind To Existing Gambit Mechanisms First

The [current root inventory](current-repair-research.md#root-and-private-work-inventory)
already separates continuations/maps, registers/saved/cache, VM/global/symbol/RC,
still/private work and weak/cleanup duties. That is the source census to close;
the two logical roots in the new model are not a substitute for that inventory.

Pinned `c_intf.c`:6510-6570 and `setup.c`:3294-3422 distinguish marker allocation,
live C return origin, marker invalidation and the remaining C tail. Pinned
`mem.c`:3969-3989 traverses RC roots, :6508-6663 traverses other execution/VM
roots, :6938-7038 supplies existing GC phase barriers, and :4525-4564 publishes
post-GC stack/heap state. These are different parts of the required bridge.

The already inspected candidate's RC/still transfer and per-processor RC marking
must not be reimplemented from this Recipe. The [RC caller audit](experimental/root-registry-retirement.md#actual-rc-callers-and-counterevidence)
also keeps architecture-disabled C trampolines distinct from actual supported
entries. A helper without an internal lock is not proof of a reachable race.

## Composed Model And Falsification

The new current model imports the publication and admitted-reader machines
unchanged, using separate state identities. An already-owned host saves two
declared root roles, publishes and blocks; a collector borrows and scans the
record; the host resumes under the assumed existing reload contract; cleanup
waits for both consumers. It adds no general attachment or independent carrier.

Three omission controls isolate an incomplete root census, one-sided publication
and mistaking collector completion for host completion. The latter must expose
dead storage while the returning host is still live even though the imported
scanner-lifetime/publication invariants remain satisfied. Completion witnesses
must show an inactive host's roots can be scanned and the full record can later
be reclaimed. No all-time retention or permanent host suspension earns a pass.

The [Lean companion](../models/gambit/lean/HostRootPublicationLifetime.lean)
quantifies over arbitrary consumer/slot types. Its coverage and last-use
consequences require explicit source census/publication/lifetime premises; its
counterexamples separate collector completion from host completion and visible
publication from liveness. It reuses `WorkAccounting` for root/mutation authority.
These are conditional contracts, not model-to-C refinement proofs.

## Reproduction And Promotion Boundary

The [manifest](../evidence/research/host-root-publication/manifest.json) runs only
this composition through the existing `verify` command with host-auto resources.
The focused test runs the real Scheme relations and guarded Lean process. Exact
commands and results belong in the [validation](../evidence/research/host-root-publication/validation.md).
No bootstrap, original stress test or unchanged failed native route is rerun.

General host registration, collector-visible independent carriers, source-defined
registration epochs and resumable attachment after VM retirement remain
[Experimental](experimental/host-root-registration.md). Formal closure of this
bounded composition must not be promoted into proof of those mechanisms or a
9/12 native increment.

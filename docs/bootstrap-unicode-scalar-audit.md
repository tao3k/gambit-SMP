# Bootstrap Unicode Scalar Audit

## Source Question

The completed two-pass bootstrap changed `lib/_std.c` table representation.
`lib/gambit/char/char.scm` invokes `macro-define-unicode-tables`.
In the pinned source, `char#.scm` assigns indices by descending frequency
without a tie breaker, then constructs corresponding displacement vectors.
This permits a representation-order explanation; it is not proof that this
mechanism caused every changed generated byte.

## Actual Observation

The seed and rebuilt candidate each compiled and ran
`models/gambit/native/unicode_scalar_semantics.scm` with GNU GCC and the
existing SMP/multiple-VM configuration. Shared available CPU capacity selected
the two runtime populations; the observed population was six per runtime.
Native generation completed in 3.262 seconds within the original 90-second
campaign budget. Record validation took a separate 6.325 seconds.

All 1,112,064 Unicode scalars were present in order, excluding surrogates.
Each runtime produced 24,465,408 bytes of typed records. Classification flags,
digit values and simple upper/lower/fold/title mappings agree across the two
runtimes. The combined semantic digest is
`76aba3e1c33b11729e26f9c0baacc299d7dc186289b8c4d5fe47527d69f59eb9`.
Truncation, duplicate inventory and a valid but changed mapping were all
rejected by the record verifier. These are verifier mutations, not GC faults.

## Retained Denials

Earlier adapter use supplied the wrong capture environment keyword and launched
no native process. A subsequent fixture used unavailable `write-u8vector`;
both native executions failed with exit70. After correcting output, both
runtimes completed but record validation rejected titlecase for scalar305:
the fixture had treated an encoded full-casing displacement as a simple
displacement. The pinned generator requires arithmetic right shift by one.
Equal invalid outputs were not accepted as equivalence. The corrected fixture
was compiled and executed afresh; the prior typed denial is retained.

## Evidence Boundary

Portable receipts, fixture and verifier snapshots are under
`evidence/source-results/fixtures/sfun-owned-unwind/unicode-scalar-bootstrap`.
Raw binary records remain diagnostic artifacts, not Git dependencies.
`tests/test_unicode_bootstrap_evidence.py` checks archive identities and scope;
it does not rerun the native campaign.

This is complete scalar-domain equivalence for the listed operations only.
It does not cover multi-character string casing, generated-byte parity,
whole GC composition, native suite completion or production performance.
Full runtime, release and performance admission remain false.

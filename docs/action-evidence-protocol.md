# Action Evidence Protocol

## Four Boundaries

| Boundary | Executable contract | Checks |
| --- | --- | --- |
| Evidence-driven actions | Full source/backend revision rechecked before reservation; changed and withdrawn sources recompute ASCENT answers | ResearchActions stale/duplicate controls; actual source and observation withdrawal tests |
| Traceable explanation | Need/Missing/Supported/ReusedEvidence/ExistingFailure/FailedEvidence/ExplanationGap retain exact references | ActionEvidence missing-reference mutation; real SIGBUS exit -10 SHA/pointer and restored-owner tests |
| Inquiry versus permission | Preliminary eligibility and recorded proposals never grant host authorization or bypass the sealed kernel | ResearchActions unauthorized/false-cause mutations; no-launch transport controls |
| Scientific uncertainty | OpenPrediction is a declared, study-scoped binding gap; observation presence never proves or refutes a hypothesis | ActionEvidence false-refutation mutation; unbound/withdrawn observations reopen predictions |

The QNT models are finite abstractions of the transport and selection protocol.
The relation tests execute actual Scheme DSL through the Library ABI. Neither is
a formal refinement proof from QNT to the entire implementation. Scheduler and
callback fairness, authentic host review, measurement validity and experimental
coverage remain independent obligations. The interface does not rank hypotheses
as true or assign information-gain scores without measured grounds.

The current review separately joins exact failure, claim and receipt identities;
see `failure-claim-receipt-contract.md`. An explanation can expose those records
without elevating finite-model or local-control evidence to causal review.

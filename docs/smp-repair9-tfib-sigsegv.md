## What the workload actually exercises

`vendor/gambit/tests/unit-tests/06-thread/tfib_stress.scm:12–31` computes each non-leaf by starting a child for `n-2`, evaluating `n-1` itself and joining the child. `go` first constructs the whole list of top-level threads, starts that list, then joins it. The original expression is `(go 15 5000)`; the file has no direct `##vector-inc!` call. The two-argument primitive correction in interrupt2 therefore supplies no demonstrated causal fix for TFIB.

For normal completion let `I(0)=I(1)=0` and `I(n)=1+I(n-1)+I(n-2)` count internal calls/new child threads. Then `I(15)=986`; total TFIB invocations per top-level thread are `2I+1=1973`, and each result is 987. Counts below include top-level creation/start/join:
